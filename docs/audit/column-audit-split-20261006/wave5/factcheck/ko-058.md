- L34 마지막 문장 「소송을 제기하기 위해 민원과 조정을 반드시 먼저 거쳐야 하는 것은 아니다」는 소비자 행정 절차(민원·소비자분쟁조정위원회)에 관해 정확하다. 다만 같은 문단·다음 문단이 소액소송을 권하는데, 民事訴訟法 §403① 十一 「其他因財產權發生爭執，其標的之金額或價額在新臺幣五十萬元以下者」는 起訴前 法院調解 전치 대상이고, §424 「其無該項所定事由而逕行起訴者，視為調解之聲請」, §406①二 「經其他法定調解機關調解未成立者」(消費爭議調解 불성립 시 면제). 독자가 직접 제소해도 손해는 없고 법원이 조정 신청으로 처리하는 정도라 MISSING-COND로 세지 않음. 추가한다면: "소가 50만 대만달러 이하 재산권 분쟁은 법원 조정이 소송 전 단계이며, 직접 소장을 내면 조정 신청으로 처리됩니다(민사소송법 제403조·제424조)."
