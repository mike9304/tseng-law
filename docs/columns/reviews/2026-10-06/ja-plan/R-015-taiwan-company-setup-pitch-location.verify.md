# R-015 검증 메모 — 営業場所の事前照会 (slug 유지: taiwan-company-setup-pitch-location)

원본: columns-ja/015 (한 줄씩 끊는 블로그체, 「2023年1月1日から全業種 添付 의무」 서술, 이미지로 업종 목록). 재작성 방향은 PLAN-FINAL §2(営業場所の事前照会: 台北市 사전조회·建物謄本·전 업종 첨부 의무).

## 확인한 원문
- 臺北市營業場所協助查詢服務作業須知 (法規類號 北市04-03-2003, 修正日期 民國113年8月27日, 113年7月1日 生效) — laws.taipei.gov.tw FL080687, 2026-10-06 curl 전문 확인.
  - 第3点: 商業處·都發局·建管處 공동 「營業場所預先查詢服務平台」, 각 기관 직장.
  - 第4点: (一) 預先查詢服務 (二) 隨案主動查詢服務; 「申請人向本府申請相關登記時，應檢附已依前項第一款規定之查詢結果文件」.
  - 第5点: 主動查詢 업종 목록(舞廳業…休閒活動場館業, 餐館業·其他餐飲業 포함); 商業處가 조정·공고 가능.
  - 第6点: 符合 시 八大行業 별도 流程, 그 외 核准函에 附載; 不符合 시 商業 7日·公司 20日 내 변경 또는 삭제.
  - 第2点 「相關登記」 정의: 設立·遷址·新增營業項目; 分公司·分支機構 포함.

## 바꾼 것
- 원본의 「2023年1月1日から…必ず添付」: 須知 원문에 날짜 없음(생효 113-07-01, 수정 113-08-27). 날짜 삭제하고 「登記の申請には照会結果を添付することになっています(第4点第2項)」로.
- 원본의 「すべての業種について必ず確認することをお勧めします」와 「実際には会社登記の際にすべての業種を照会する必要はありません」의 모순 → 須知 구조(添付 의무 + 第5点 업종만 職権 조회, 일람 외 업종도 면제 아님)로 정리.
- 업종 목록을 이미지 대신 본문 텍스트로(須知 第5点 원문 번역).
- 「いつでも台湾の弁護士にお問い合わせください」 삭제, 상담 단락 규격화.
- 「建物登記第二類謄本 업로드」: 須知 원문엔 없고 사전조회 사이트 안내(businesslocationinfo)에 근거(원본 승계). 사이트 원문은 이번에 미대조(이전 기록: 이 맥에서 접속 실패) → 「照会の入口は…」로 링크만.

## 미확인
- businesslocationinfo.gov.taipei 접속 불가(이전 기록). 謄本 업로드 요건은 원본 서술 승계.
- 「後に所管機関から処分を受けることがあります」: 都計·建管 법령 위반 처분의 조문 미인용(일반 서술).
- 일본 제도 언급 없음.
