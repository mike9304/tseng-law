## 공개 CMS 경로

관리자 저장본이 정적 파일보다 우선하는 경로가 있어 공개 칼럼 읽기에도 정리를 적용했다. 칼럼 CMS 공개본, 사이트 칼럼 컬렉션의 카드·SEO·직접 데이터 연결, 블로그 피드의 제목·요약·본문을 포함한다. 저장된 CMS 문서 자체는 덮어쓰지 않는다.

공통 함수는 Markdown의 강조와 문법이 깨진 별표를 제거한다. 코드·인용 기호의 이스케이프·링크 목적지·HTML 속성값·단어 내부 밑줄은 보존한다. 다른 CMS 컬렉션은 바꾸지 않는다. 링크·코드 손상과 공개 경로 누락에 대한 독립 검수 지적을 수정하고 재현 사례를 테스트에 추가했다.
