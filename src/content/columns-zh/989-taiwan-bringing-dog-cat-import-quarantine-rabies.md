# 在國外養的狗貓要帶回台灣，一定要隔離嗎？犬貓輸入檢疫條件與罰則

在首爾養的狗，跟著主人調回台北，一下飛機能不能直接帶回家？看出發地。韓國不在我國公告的狂犬病非疫區名單上，文件再齊全，原則上也要到指定隔離場所隔離檢疫7日。同一隻狗如果是從東京出發，結果就不一樣了。

## 先看出發地在不在名單上

農業部動植物防疫檢疫署（以下簡稱防檢署）公布的狂犬病非疫國（區）是：日本、新加坡、澳大利亞、紐西蘭、美國夏威夷州及關島、英國、瑞典、冰島、挪威（Svalbard群島除外）、愛沙尼亞、捷克。名單以外的國家、地區，一律適用狂犬病疫區的規定。美國本土、加拿大、中國大陸、韓國都在名單外。

具體要求寫在「犬貓輸入檢疫條件」。現行版本是農業部113年2月27日農防字第1131867278號公告修正，113年2月29日起施行。母法是動物傳染病防治條例；[第33條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=M0130003&flno=33)第1項要求中央主管機關公告外國動物傳染病疫情，並採取輸入前申請檢疫同意文件、繳驗輸出國檢疫證明書、隔離檢疫等措施。

認定的時間點寫在檢疫條件第二點：以犬貓離開原所在國家、裝上運輸工具時的公告狀態為準。第三點再把能適用非疫區規定的情形限縮為三種：

- 未滿180日齡，出生後一直養在非疫區
- 滿180日齡，輸入前180日內一直養在非疫區
- 從台灣出去的犬貓，出國後到回台前一直養在非疫區

在韓國養了三年、三個月前才搬到日本的狗，從東京起飛仍要依疫區規定辦理（虛構情境）。180天還沒滿。

## 從日本這類非疫區帶回來

依檢疫條件第四點，犬貓要植入晶片，並在輸入前1年至輸入前30日之間完成狂犬病疫苗注射；注射時須滿90日齡，疫苗限不活化疫苗或我國核可使用的狂犬病疫苗。打的是三年效期疫苗也一樣，防檢署問答集說得很清楚：最近一劑的注射日必須落在輸入前30日至1年之間。

輸入20日前（或從台灣出境前），向預定到達港、站的檢疫機關申請輸入檢疫同意文件，附上身分證明文件與獸醫師簽發的狂犬病疫苗注射證明影本；已領國民身分證的人要附身分證（第五點）。注射證明須以中文或英文載明物種、性別、年齡、晶片號碼、注射日期、疫苗廠牌或種類。防檢署建議在「輸入犬貓檢疫資訊網」線上申請。

出發前還要向日本的動物檢疫機關申請輸出國檢疫證明書。證明書要記載無狂犬病臨床症狀、疫苗注射日期與廠牌，以及輸出前180日或出生後均飼養於非疫區（第六點）。犬貓抵達時，檢附同意文件影本、證明書正本和空運提單或海關申報單影本申請檢疫（第七點）；查驗相符、無感染法定動物傳染病之虞，就簽發輸入動物檢疫證明書，不必隔離（第八點）。

轉機地點常被忽略。防檢署問答集舉的例子正是「日本出發、經由韓國轉機」。這時運輸籠須由輸出國檢疫機關以印有編號的封條封妥、號碼記載於證明書，或者由轉機地的檢疫機關、海關、航空公司出具犬貓未出港站、未接觸其他感受性動物的證明。兩者皆無，隔離7日（第九點）。

## 從韓國這類疫區帶回來

疫區輸入的一般犬貓適用第十點。晶片和疫苗的要求相同，多了一項狂犬病中和抗體力價檢測。

抽血後要送世界動物衛生組織（WOAH）狂犬病參考實驗室或防檢署指定實驗室，力價達0.5IU/ml以上才算合格（第一點）。抽血時間有三種算法：輸入前90日至1年；前次合格報告抽血日起90日至1年，且在輸入前1年內；或從台灣輸出前抽血，且在輸入前1年內。

換句話說，抽血日到入境日至少要隔90天。等搬家日期確定才去抽血，往往來不及。

申請同樣在輸入20日前，同時排妥隔離場所（第十一點）。問答集提到，拿到輸入檢疫同意文件，就表示隔離籠位已經訂好。入境後由檢疫人員押送到指定隔離場所，隔離7日期滿、無感染法定動物傳染病之虞，才簽發輸入動物檢疫證明書（第十四點、第二十四點）。

7天能不能省？113年修正後可以，但條件嚴格。輸入前180日至1年內抽血檢測合格，再符合下列任一項，即免予隔離（第十一點第二項）：

- 在輸入120日前提出申請
- 由輸出國動物檢疫機關直接提供檢測結果聲明書影本，或由檢測實驗室直接提供合格報告影本給防檢署

抽血日在輸入前180日內、但距前次合格報告抽血日180日至1年者，也能用同樣方式免隔離。對台灣飼主更實用的是另一條：犬貓出國前已在台灣抽血檢測合格，於抽血日1年內回台，免隔離。問答集也列出可在實驗室網站直接查詢報告的實驗室，其中包括韓國的Choong Ang Vaccine Laboratory（CAvac）。

## 隔離場所與費用

防檢署目前公布的隔離場所有三處。自桃園機場、松山機場、臺北港或臺中國際機場輸入者，送桃園分署觀音檢疫站；自高雄機場輸入者，送國立屏東科技大學附設獸醫教學醫院。國立中興大學獸醫教學醫院標示為暫停服務。

錢由輸入人付。留置、運送、臨床檢查、隔離期間的飼養管理與醫療、採樣送驗、植入晶片、注射疫苗，連同退運、撲殺銷燬的費用，都由申請輸入人負擔（第二十三點）。疫苗注射日在隔離期間超過一年，要補強一劑（第二十五點）；問答集提醒，入境日貼近疫苗到期日的犬貓，可能就在隔離中多出這筆費用。防檢署另公告，例假日、國定假日無法派員押運及點收，入境日最好避開。

行程變了怎麼辦？要在同意文件所載有效期間屆滿前、且變更後輸入日期的10日前申請變更，以一次為限（第五點第三項、第十一點第六項）。第二次就得重新申請。

## 文件不符的後果

動物傳染病防治條例[第34條之2](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=M0130003&flno=34-2)規定，未繳驗檢疫證明書或記載不符時，檢疫機關可以延長隔離、施行診斷試驗、補行預防注射、限期補正文件，無法補正就退運或撲殺銷燬。檢疫條件第十五點把疫區輸入一般犬貓的情形換算成天數：

| 情形 | 處理 |
|---|---|
| 無晶片；證明書未載抗體檢測且未附報告正本 | 退運、撲殺銷燬或隔離。隔離者滿90日齡後注射疫苗，30日後抽血，合格後隔離至抽血日後滿97日（無晶片者送達隔離場所後立即植入）；不合格則重複程序或隔離180日 |
| 沒有證明書正本；晶片號碼未登載或不符 | 同上。但自台灣輸出後1年內回台，檢附台灣輸出檢疫證明文件，及台灣輸出前且輸入前1年內抽血檢測合格的報告正本者，隔離30日，免注射與抽血 |
| 物種、性別、年齡未登載或不符，或未載無臨床症狀 | 退運、撲殺銷燬或隔離30日 |
| 疫苗注射資訊不符規定 | 退運、撲殺銷燬，或依規定補行注射後隔離至注射日後滿30日 |
| 抽血日期不符規定 | 退運、撲殺銷燬或隔離至抽血日後滿97日 |

非疫區也一樣嚴。第九點同樣是退運、撲殺銷燬或隔離三選一：無晶片、沒有證明書正本、晶片號碼未載或不符，或證明書沒寫輸出前180日（或出生後）飼養於非疫區，走97日的程序，其中證明書正本與晶片號碼兩種情形也適用上表的30日但書；疫苗資訊不符，補打後隔離至注射日後滿30日；物種、性別、年齡或無臨床症狀漏記，以及途經疫區，隔離7日。

補償也有限制。輸出入檢疫時因傳染病疑慮撲殺的動物，或在隔離留檢期間死亡的動物，不發給補償費（[第40條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=M0130003&flno=40)第3項）。

## 沒申報就帶進來

應施檢疫物到港時，輸入人要向檢疫機關申請檢疫；旅客攜帶入境，也要在入境時申請（[第34條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=M0130003&flno=34)第1項、第2項）。郵寄輸入一律禁止，寄進來的應退運、沒入或銷燬（同條第3項）。

罰則依行為分開規定。旅客未申請檢疫，罰新臺幣1萬元以上100萬元以下（[第45條之1](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=M0130003&flno=45-1)）。輸入人抵達港站未申請檢疫，罰5萬元以上100萬元以下（[第43條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=M0130003&flno=43)第11款），檢疫機關並應令其採取必要處置（第35條第4項）。沒有事先申請輸入檢疫同意文件，或沒排妥隔離場所就輸入，各罰3萬元以上15萬元以下（[第45條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=M0130003&flno=45)第12款、第15款）。

擅離隔離更重。未依指示在期限內把動物送到隔離場所，或未經許可把動物移出，罰5萬元以上100萬元以下；因此導致疫情蔓延或散播的，處三年以下有期徒刑或拘役，得併科100萬元以下罰金（[第42條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=M0130003&flno=42)）。

飼料零食也別順手塞進行李。問答集說明，含偶蹄目（豬、牛、羊等）或禽鳥類成分、供犬貓食用或嚼咬的產品須經檢疫；成分不確定，請保持完整包裝，到檢疫櫃檯主動申報。

## 不能帶進來的狗

動物保護法[第8條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=M0060027&flno=8)授權中央主管機關公告禁止飼養或輸入的動物。前行政院農業委員會110年10月26日農牧字第1100042728號公告，自111年3月1日起禁止飼養或輸入比特犬，包括美國比特鬥牛犬與美國史大佛夏牛頭犬。違反者處新臺幣5萬元以上25萬元以下罰鍰（[第26條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=M0060027&flno=26)第1項第2款），主管機關並得沒入動物（[第32條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=M0060027&flno=32)第1項第5款）。防檢署說明，111年2月28日或之前已飼養的比特犬不在禁止輸入範圍；但要先把佐證資料交給動物保護法主管機關（中央為農業部，地方為各直轄市、縣市政府）確認，才能續辦輸入檢疫。

從中國大陸來台的犬貓，若沒有台灣的輸出檢疫紀錄，須先向經濟部國際貿易署申請專案進口，拿到許可公文再上傳申請檢疫同意文件。陪同來台的外籍家人要辦哪種簽證或居留，可參考[來台工作、讀書或依親的簽證說明](/zh-hant/columns/taiwan-visa-residence-work-study-family)。

## 律師可以處理的部分

出發前，律師可以逐項比對獸醫師注射證明、抗體檢測報告、輸出國檢疫證明書與檢疫條件的要求，並依轉機路線與時程判斷能否走免隔離。入境後若收到退運、撲殺、延長隔離或罰鍰處分，訴願須自處分書送達的次日起30日內提起（[訴願法第14條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=A0030020&flno=14)第1項），律師可在期限內整理事實與法律依據提出書狀。昊鼎國際法律事務所諮詢信箱：[wei@hoveringlaw.com.tw](mailto:wei@hoveringlaw.com.tw)（[服務說明](/zh-hant/services/civil)）。台北所：103 臺北市大同區承德路一段35號7樓之2；台中所：40453 臺中市北區館前路19號6樓之1。

從首爾帶回來的狗，抽血日到回台日至少要隔90天，想免隔離就得拉到180天。先排抽血，再排搬家。
