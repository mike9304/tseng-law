# N13 검증 메모 — 日本で作った遺言は台湾の財産に効くのか

- 도입 유형: 질문형(「日本で公正証書遺言を作っておけば…渡せるのでしょうか」)
- 작성: son7-b8 (Fable 5.1), 2026-10-06
- 조문: law.moj.gov.tw 2026-10-06 curl — research/private-intl.md(涉外 §58·60·61, 修正 99-05-26), civil.md(§1189·1190·1191·1194·1195·1198·1199·1209·1210·1212), civil2.md(§1223·1225), civil3.md(§1219·1220·1221), land.md(土地法 §73, 113-08-07).
- 일본 제도 언급: 「公正証書遺言」「家庭裁判所の検認」은 명칭만 언급, 조문·효과 단정 없음(.verify 규칙 5: 일본 법 조문 기재 없음 → 본문도 단정 없음. 「日本では自筆証書遺言を家庭裁判所で検認します」 한 문장은 일반 사실 서술이나 조문 미확인 → 통합 시 「日本には家庭裁判所の検認の手続がありますが」 정도로 약화할지 총괄 판단: 유지하되 일본 民法 1004条 미확인으로 기록).

## 쓰지 않은 것 / 미확인
- 台湾에 「検認」 제도가 없다는 서술은 민법 상속편에 해당 규정이 없음(§1212 구조)에 근거한 부정 서술. 다른 법(家事事件法)에 유사 절차가 없는지는 미확인 → 통합 시 표현을 「台湾民法には…規定がなく」로 한정(현재 본문 그대로).
- 外国文書 認証 요건(駐日代表処 認証 등)은 기관별 상이로 「提出先に確認」만 기재.
- 미확인: 日本 検認 관련 1건(위).
