# 与台湾配偶离婚后，孩子在哪里生活：跨境照顾与探视计划

孩子搬到另一地生活，上学、看病以及和另一方家长见面的方式都会随之改变。讨论新住处之前，先要弄清谁有权决定孩子住在哪里，需要哪些同意或法院裁判。即使孩子一直主要由一方照顾，或者由该方单独行使亲权（大陆通常说“抚养权归一方”），也还要看其是否有权决定迁居，以及需要哪些同意、受哪些限制。

## 孩子的生活，怎样接得上？

假设双方约定每周日晚上通话，搬家后两地却有时差。这时要写清是哪一地的晚上，并考虑孩子上课、睡觉和家长上班的时间。新住处有家人帮忙的，也要想好家人不在时由谁照顾。

平时谁接送、谁带孩子看病、谁管吃饭、谁在什么时段上班，能说明现在主要由谁照顾孩子。再对比搬迁后学校的教学语言、医疗资料怎样交接、托育怎么安排，就能看出孩子需要的照顾哪些可以延续、哪些还没有着落。不要诱导孩子表态，也不要让孩子拒绝见另一方家长。

适用台湾法时，民法第1055条处理离婚后由谁对未成年子女行使权利、负担义务，以及会面交往（相当于大陆所说的探望）；第1055条之1要求法院依子女最佳利益综合考量。孩子的年龄、健康、意愿和成长情况，父母的照顾能力、态度以及与孩子的感情等，都可能影响判断，法院不会只凭收入高低或谁导致婚姻破裂来决定。条文见[法务部民法原文](https://mojlaw.moj.gov.tw/LawContent.aspx?TypeSort=3&lawNumber=1049&lsid=fl001351&media=print)。

## 定行程之前，先弄清谁有权决定

有关子女的协议或法院已经作出的裁判，可能对居所、旅行等作了限制；有案件正在进行的，也要把进度和已作出的决定告诉律师。孩子的国籍或户籍、证件、现居地和学校，也是律师判断的基础。行程确定之前，要弄清需要取得谁的同意、还要办完哪些程序。这些要求还没理清时，不宜单方面把孩子带走、抢先改变现状。遇到暴力或紧急危险时，安全和保护措施优先。

哪个法院可以受理、适用哪里的法律，以及已有的协议或裁判在两地怎样生效和执行，是几个不同的问题。涉及大陆、香港或澳门的，要按当事人身份和文书来源审查相应规则；大陆法院作出的民事确定裁判，可以向台湾法院申请裁定认可（两岸人民关系条例第74条）。可参阅[离婚问答](/zh-hans/columns/taiwan-divorce-lawsuit-qna)和[家庭法律分析](/zh-hans/columns/taiwan-inheritance-custody-analysis)。生活计划能帮助评估搬迁后谁来照顾孩子，但家长有没有权决定迁居、需要哪些同意、现有限制怎样解除，还是要按上面这些规则来确定。

## “假期见面”还需要哪些安排？

假期从哪天到哪天、在哪里交接、谁陪同，决定了能不能订票、请假。返回日期也要写明，免得只约定了出发却没有回程。学校和健康方面的信息怎样共享，关系到不在一起生活的一方能否继续了解孩子的日常。孩子生病需要照顾、航班取消，都可能打乱计划，所以要约定怎样通知、怎样改用其他方式联系。如果见面存在安全风险，见面方式和保护措施也要相应调整。日后能否在另一地要求对方遵守约定，还取决于条款的效力和当地的承认、执行规则。

下表供商量时记录，还没谈拢的项目，把双方意见和要咨询的问题一并记下。

| 项目 | 可以记录的具体信息 |
|---|---|
| 两地时间 | 时区、孩子作息、视频通话的当地时间及备用时段 |
| 学校假期 | 学年和假期起止，考试或活动是否冲突 |
| 往返安排 | 交接地点、陪同人、返回日期、旅行证件和延误后的联系 |
| 取消与改期 | 提前多久通知，生病或航班取消时的通知记录与改期安排，备用联系方式 |
| 支出记录 | 预算、票据、币种、汇率记录及费用有争议时的沟通方式 |
| 尚未决定 | 迁居需要取得谁的同意、法院裁判或限制、条款效力与执行 |

## 抚养费与财产清算，款项用途要写明

每月的教育、医疗和生活开支，与临时的大额费用可以分开列。付款币种、日期和汇款手续费会影响实际到手的金额，讨论金额时应一并定下来。孩子的费用如果和夫妻财产清算混在一笔里，将来可能说不清这笔钱付的是什么。

预算能说明孩子实际需要多少钱。至于由谁负担抚养费、金额多少、以后能否调整，要根据家庭情况、适用法律和已有文书来判断。在台湾以外要求对方履行付款义务，还涉及当地的执行规则。

已经定了搬迁或出行日期的，最好在订票之前咨询。联系昊鼎国际法律事务所时，请写明家人各自的身份和居住地、孩子的年龄和目前由谁照顾、已有的协议或裁判，以及计划的日期；希望用哪种语言沟通，也请一并注明。涉及孩子的敏感资料，请在利益冲突确认后按指示发送，服务范围和费用会在联系后说明。
