# 台湾でけがをさせられた後の治療費と休業損害――刑事附帯民事の使い方

治療費を立て替えたまま帰国しても、台湾で相手が起訴されたことだけで返金を受けられるわけではありません。傷害事件の賠償を求めるには、支出や仕事への影響を示し、相手に請求する手続を選びます。

「刑事附帶民事訴訟」も選択肢です。犯罪によって損害を受けた人が、刑事事件の被告や、民法上賠償責任を負う人に対して、刑事裁判に付随して損害回復を求める制度です。請求できる範囲は民法によります（[刑事訴訟法第487条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0010001&flno=487)）。

## 病院の領収書から、請求する損害を組み立てます

故意・過失によって不法に権利を侵害した人の損害賠償責任は、[民法第184条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=184)が定めています。身体・健康を害されたことによる働く能力の減少や生活上の必要の増加は[第193条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=193)、精神的な損害は[第195条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=195)などを検討します。

支出の合計だけでは足りません。

| 請求を検討する項目 | 準備する資料と説明 |
| --- | --- |
| 診療・治療費 | 領収書、診断書、診療明細。事件のけがとの関係を示します。 |
| 仕事を休んだ損害 | 休業期間、医師の所見、給与明細、勤務先の証明。実際の収入減との関係を確かめます。 |
| 介助や通院などの費用 | 必要性が分かる医療資料、利用日、支払先、領収書。 |
| 後遺症や精神的な損害 | 症状の経過、生活・就労への影響、診療の記録。一定額が自動的に認められるものではありません。 |

台湾と日本の両方で治療した人は、それぞれの通院日と費用を区別します。日本円の資料は原本を残し、中国語訳や換算方法が必要かを確認します。同じ支出を重複して合計しないよう、支払済みの示談金や保険給付の内容も相談時に伝えます。どの金額を損害から差し引くかは、その給付の性質によります。

## 提起できる時期には、途中の空白があります

刑事附帯民事は、刑事事件が起訴された後、第二審の弁論終結までに提起できます。ただし、第一審の弁論終結後から上訴が提起されるまでは提起できません。捜査中に警察へ賠償額を伝えただけでは、この訴えを起こしたことになりません（[刑事訴訟法第488条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0010001&flno=488)）。

裁判所の事件番号を確認します。起訴状や裁判所からの通知で、どの犯罪事実が裁判にかかっているかを確かめた上で、請求する損害がその犯罪によるものか、刑事の被告以外に誰が民法上の責任を負うかも検討します。相手の勤務先、家族、同行者を、関係があるというだけで一緒に被告にできるわけではありません。

書面では、当事者、請求額、事件の経過、損害の内訳と証拠を整理し、相手方の人数に応じた副本を用意します。司法院は、裁判所のサービス窓口に書式例があり、書面作成の手続上の案内を受けられると説明しています（[司法院・被害者の賠償請求](https://www.judicial.gov.tw/tw/cp-1654-2646-134d0-1.html)）。窓口の案内と、どの損害を主張するかという法律上の検討は分けて準備します。

## 無料になる費用と、移送後に必要になる費用

適法な刑事附帯民事の提起には、通常、裁判費を納める必要がありません。費用面の違いがあります。ただし、刑事裁判の進行が止まれば、附帯民事の審理も遅れることがあります（[司法院の案内](https://www.judicial.gov.tw/tw/cp-1654-2646-134d0-1.html)）。

無罪、免訴、不受理という刑事判決では、附帯民事は原則として退けられるものの、原告が申し立てれば管轄裁判所の民事部へ移送する規定があり、この場合は訴訟費用を納める必要があります（[第503条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0010001&flno=503)）。

一方、附帯民事が複雑で長時間の審理を要するため、刑事裁判所が合議で民事部へ移す第504条の手続では、裁判費を免除する規定があります。移送された理由を読まず、「民事部に移れば無料」「移ったら必ず有料」と判断することはできません（[第504条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0010001&flno=504)）。また、附帯民事の要件を満たさない請求まで、免除が当然に続くとは限りません。

## 告訴の6か月と、民事の時効は別に管理します

不法行為の損害賠償請求について、[民法第197条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=197)は、損害と賠償義務者を知った時から2年、または不法行為の時から10年という期間を定めています。時効の進行や中断などには個別の検討が必要です。

普通傷害の刑事告訴をしたことと、民事請求を適切な方法で行ったことを同一視しないでください。起訴を待つ間に時間が経過している場合は、独立した民事訴訟などの方法を検討します。不起訴となった場合も、民事上の責任があるかは別に調べます。

回収の問題も残ります。相手が任意に払わなければ、執行できる裁判書類や財産の状況を踏まえて、強制執行などを検討します。帰国後も記録は残します。台湾で手続を受ける代理人と連絡方法を決め、今後も増える治療費を伝えられるようにしておきます。
