## 법령 상태 확인 (尚未生效 표시의 원인)
- 律師法 LawAll: 修正日期 114-05-28(第9條 개정), 표시 「一百零九年一月十五日修正之第 4 條定自一百十六年一月一日施行」. 沿革 17: 行政院 114-04-01 院臺法字第1141006736號令이 第4條를 116-01-01 시행으로 지정. 칼럼은 第4條를 인용하지 않음.
- 第136條: 沿革 17의 行政院 109-12-03 院臺法字第1090040012號令이 第78·80·106~113①·136條를 110-01-01 시행으로 지정 → 현재 시행 중.
- URL: https://law.moj.gov.tw/LawClass/LawHistory.aspx?pcode=I0020006
