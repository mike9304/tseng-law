# B6 MS 독립 검수 — R2 변경 부분 재확인

판정: R1 필수 M1·M2를 종결한다. 선택 O1–O3도 의미를 보존한 상태로 반영됐다. 이번 확인 범위에서 남은 필수 오류는 0건이다. 원고 수정·통합·배포는 하지 않았다.

R1 이후 실제 변화는 4파일의 정확한 6치환이다. 작성자가 보존한 R1 원문을 R1 manifest의 SHA와 먼저 대조하고, 치환을 직접 재적용한 결과가 현재 파일 전체와 같음을 확인했다. 역치환도 같은 R1 SHA로 돌아간다. 변경 전후 diff와 인접 문단, 수정된 FAQ, 새 추출 단위 4개를 읽었다. 나머지 916·918은 R1 바이트 그대로다. 전체 여섯 편 의미 검수나 전체 문체 검사를 새로 반복했다고 기록하지 않는다.

## 지적별 종결 근거

- M1, 920 본문37행: `Perkara 6(1)(4) turut menyentuh ...`와 `Mahkamah tidak menerima pengelasan itu bagi pemasangan dalam kes ini.`로 수정했다. 특정 조문 주장을 주민에게 귀속한 부분이 사라졌다. 법원이 이 설치를 해당 조문 유형으로 분류하지 않았다는 사건 한정 판단은 남는다. 인접 문단의6(1)(5)·조율 뒤6(3) 구제와 섞이지 않으며, 다음 문단의 주민 주장에 대한 가정적 판단도 불변이다. R1에서 확인한 공식 판결의 당사자 구분과 일치한다.
- M2, 921 본문39행·FAQ2 20행: 두 곳 모두 `mata berbayar yang belum digunakan atau fi permainan yang belum digunakan`이다. 미사용 조건이 유료 포인트와 게임비용에 각각 걸린다. 대상의 OR, 필요비용 공제, 계약 종료부터30일, 쌍방 합의 방식의 대안을 보존했다. 본문 다음 문장의 합의 요건과 FAQ의 언제든 종료/별도7일 해제 구분도 읽었다. 특정 게임의 칩을 설명하는 FAQ1에는 불필요한 일괄 치환을 하지 않았다.
- O1, 915 제목: `Tuntutan wang selepas syor lanjutan masa`로 고쳐 연장 권고 뒤 다시 금전을 청구한 핵심 단계를 드러낸다. 본문·요약의 사건 경과와 맞고 청구 변경을 일률적으로 금지한다는 뜻을 만들지 않는다.
- O2, 919 제목: `pengumuman hukuman`으로 선행한 것이 제재의 발표였음을 명확히 했다. 실제 처분과 발표를 합치지 않는다.
- O3, 919 본문51행: `Kandungan notis menentukan perkara yang perlu dijawab.`가 통지 내용과 답변 대상을 연결한다. 반복적인 짧은 단언을 구체적인 설명으로 바꾸었고, 이어지는 개별 행위·시기·쟁점 통지와 증거 비교 문단에 자연스럽게 이어진다. 새 서식 의무나 개인정보 공개 의무를 추가하지 않는다. R1의 선택 MONOTONY 제안은 이 범위에서 해소됐다.

## 검증과 범위

작성자의 실제 R2 공유 검사 기록을 확인했다. 915/919/920/921은 각각 exit0/FAIL0, CV .501/.467/.502/.480이다. 이는 이번 검수자의 재실행값이 아니다. 원고 SHA와 실제 실행 기록이 맞고, 추출 단위는43/43/42/43으로 유지된다. 167개 단위는 순서와 바이트가 그대로이며 바뀐4개를 직접 읽어 정상 문장 경계를 확인했다. 제목2곳과 FAQ 수정은 본문 점수의 대상이 아니다. 변경 후 자동 구조 오류0과 의미 확인 REQUIRED20 표시는 보존한다. 자동 REQUIRED가 스스로 PASS가 됐다고 쓰지 않는다.

모든 URL 순서는 불변이다. 전체 입력15개를 시작·종료에 SHA로 확인했고 작성자 R1 보고서의 원래 접두부와 독립 R1 보고서도 보존됐다. 정확한6치환 외 수치·메타데이터·출처 변화는 없다. 실제 diff 및 전체6편의 새 SHA는 `checks/ms-independent-r2-checks.json`, 인계 manifest는 `checks/ms-independent-r2-manifest.json`에 있다.

이번 재확인은 제가 작성한 R1 지적에 대한 제한된 종결 검수다. 기계검사의 독립 인증, 사람 원어민 감수, 변호사 승인 또는 공개 배포 완료를 뜻하지 않는다.
