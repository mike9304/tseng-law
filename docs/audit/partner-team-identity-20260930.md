## 사용자 확인

사용자는 증준외(曾雋崴 / Wei Tseng)가 로펌 전체 대표가 아닌 파트너이며, 이 사이트에 소개된 직원들이 증준외 변호사의 팀이라고 확인했다. 이어 제안한 명칭을 모든 언어에 적용하도록 승인했다. 파트너 지위는 사용자 확인을 근거로 한다. 기존 외부 프로필의 `資深律師`를 현재 파트너 지위에 대한 독립 증명으로 사용하지 않았다.

팀 소개는 첫 문장에 주체와 업무 범위를 명시한다. 해당 문장을 삭제하면 팀 범위가 사라지므로 남겼다. 별도 story 배열에서는 같은 설명 반복을 제거하고 기존 상담 언어와 업무 협업 내용을 남겼다. 칼럼 본문은 이번 변경 대상이 아니다.

회계사는 별도 협력 회계사 영역을 유지한다. 謝宛均의 다른 지점 책임자 직함, 실제 외부 링크의 `대표변호사` 슬러그, 법인명·창립자·연혁·학력·사건 결과·연락처는 유지한다. 안내언어 페이지가 생겼다는 이유로 해당 언어의 상담을 제공한다고 쓰지 않는다.
