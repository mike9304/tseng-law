## 코드·검색 발견성

`/{vi,id,th,fil}/{company-setup,debt-collection}`만 실제 정적 라우트로 선언했다. 각 홈·서비스 화면의 실제 href가 두 페이지로 이어지고, 안내 페이지는 해당 언어 서비스·비용·연락처 및 존재하는 관련 칼럼으로 연결된다. 베트남어의 별도 화면 경로도 포함한다. 언어·경로 타입은 `src/lib/sea-business-routes.ts` 단일 정본이다.

새 페이지는 self canonical과 네 언어끼리 상호 일치하는 hreflang, 군집 안의 x-default(vi), index/follow, 해당 언어 Open Graph·BreadcrumbList·LegalService를 사용한다. 영어 intent는 일반 관련 링크이며 번역 대체 페이지라고 선언하지 않는다. middleware의 정확한 8경로 통과와 전체 49언어 전환을 검사했다. 미지원 언어는 홈 fallback을 표시하고 가짜 업무 페이지 URL을 만들지 않는다. `seo.ts`, core10키 및 45언어 안내 사전은 변경하지 않았다. sitemap은 실제 8개 항목만 추가했다.
