# 預售屋的建商、代銷與收款戶名不同，房款該匯給誰？

買賣契約寫著一家建設公司，接待的是另一家代銷，繳款通知上的戶名又不同。遇到這種情形，要請賣方說明：這筆錢是替誰收、付的是哪一期款，以及為什麼應匯入這個帳戶。名稱不一致本身，不足以判定詐騙；有代銷或信託安排，也不能省略收款關係的查證。

代銷與建商原本就可能是不同公司。[不動產經紀業管理條例第4條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=D0060066&flno=4)所稱代銷，是受起造人或建築業委託，負責企劃、代理銷售不動產。至於接洽人能否代收這一期房款、能否變更付款帳戶，仍要另外核對授權，不能只看名片上有沒有印建案名稱。

## 接待中心的名字，要對回契約上的賣方

先翻到買賣契約的當事人與簽章欄，記下賣方完整名稱；土地、房屋如分別簽約，兩份都要看。再對照代銷公司、接洽人與繳款通知的出具者，請對方說明各自代表誰。不要只留下一個建案名稱，日後卻無法指出是向哪個人或公司購買。

[第21條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=D0060066&flno=21)規定，經紀業與委託人簽訂委託契約書後，才能刊登廣告及銷售，廣告與銷售內容也須註明經紀業名稱。可以據此核對廣告上的公司，並請賣方提出足以確認代銷關係與收款權限的資料。

若有人表示自己可以替賣方改付款方式，應請其提出足以確認授權範圍的資料，並向賣方核實。[民法第103條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=103)的代理效力，以代理人在權限內、以本人名義所為的意思表示為前提。現場負責介紹房屋的人，是否也有權作出這次付款指示，不能從職稱直接推定。

另可使用內政部實價查詢服務網的「預售屋建案查詢」，按建案名稱、建商、地段或建造執照核對備查資料。這項功能的範圍是2021年7月1日起申報預售屋資訊及定型化契約備查的建案，並非所有年代的建案都在其中。[內政部操作指引](https://olvr.land.moi.gov.tw/jsp/guide.jsp)

查到建案，只是多了一份可供比對的公開資料，不能據此認定眼前接洽人的收款指示已經獲得授權。

## 契約勾了哪一種履約擔保

內政部公布的[預售屋買賣定型化契約應記載及不得記載事項](https://www.ey.gov.tw/File/17FD66C7511F7121?A=C)第7點之1，要求辦理履約擔保，並列出五種方式。買方應看實際勾選項目及隨附文件，不能把「有銀行承作」一律理解為銀行保證交屋或退還全部房款。

| 契約採用的方式 | 付款前要讀的內容 |
|---|---|
| 不動產開發信託 | 土地與興建資金的信託及履約管理安排；賣方在簽約時應提供信託證明文件或影本 |
| 價金返還之保證 | 承作金融機構、保證契約所定範圍及請求條件；賣方應提供保證契約影本 |
| 價金信託 | 價金的專款專用與信託管理約定；賣方應提供信託契約影本 |
| 同業連帶擔保 | 擔保公司是誰，以及賣方未依約完工或交屋時，向其請求完成建案後交屋的安排；應有連帶擔保書面影本 |
| 公會辦理連帶保證協定 | 加入協定的公司與共同完成建案後交屋的安排；應有加入協定的書面影本 |

價金信託與價金返還之保證是不同選項。依第7點之1的價金信託條款，受託機構按信託契約管理資金，受益人原則上是賣方；賣方未依約完工或交屋時，受益權才歸屬買方。受益權歸屬的安排，也不能直接改寫成「銀行會用自己的錢全額退款」。至於有沒有另作保證、保障哪些款項，仍須讀具體文件。

如果只拿到一張寫著「履約保證」的宣傳頁，尚不足以回答這些問題。請賣方補齊該項機制要求的文件，核對建案、當事人、承作機構及適用範圍；文件上出現銀行名稱時，可自行從銀行官網找到窗口，詢問如何查證該建案的承作與專戶資料。

## 繳款通知應能對回本戶、期別與帳戶

把這一期的繳款通知與契約付款明細表放在一起：棟別、樓層、戶別、金額、期別及付款條件是否相符？再看通知上的銀行、分行、完整戶名與帳號，是否能與契約、履約擔保資料及賣方的付款說明對應。這是付款查核的做法，不是要求每種履約擔保都使用同一種銀行專戶。

有人要求先匯入代銷公司或個人帳戶，再由對方轉入專戶時，應請賣方以書面確認代收者、代收依據、款項流向及如何證明已入帳。涉及信託或保證的，也要確認這樣支付是否符合相關契約，不能只接受接洽人一句「公司都這樣處理」。

行政院消保處在2026年5月14日公布的履約擔保修正草案，另涉及專戶揭示與直接入帳等問題。看到這類修法消息，應再核對正式公告及生效日期，不能把草案當作已生效的付款規定。[修正草案說明](https://www.ey.gov.tw/Page/F7408A6FCA4B0A8A/aa50b3f7-018c-4925-9e23-78b9c70e041c)

繳款通知突然換帳戶，或新通知與已簽文件對不上時，請使用原先核實的賣方聯絡管道確認，保留新舊兩份通知及回覆。付款後也把匯款證明、收據與該期通知放在一起，日後才查得出某筆款項對應的是哪一戶、哪一期。

## 已到繳款日，不能只停繳而不處理

尚未簽約時，可利用契約審閱期要求補齊資料；上述應記載事項第1點所定的審閱期間至少五日。已經簽約、付款期限將到，則應及時向賣方書面說明不一致之處，請其確認收款方式，必要時協議延期。第9點另有逾期付款的處理規定，不能僅因自己提出疑問，就認為付款期限自動停止。

如果已經付款，賣方卻表示沒有收到，應同時整理匯款紀錄、付款指示的來源、代銷授權資料與賣方回覆。依[民法第309條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=309)，向債權人或有受領權的人依債務內容清償並經受領，才有該條所定的清償效果；向其他第三人付款，[第310條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=310)另有規定。因此，不能只憑匯款成功就說房款已付清，也不能只因戶名不同便認定一定要再付一次。

這時需要釐清的是誰有權收款、賣方是否承認或實際受益，以及文件是否遭冒用。可帶契約、通知與付款紀錄，透過[事務所聯絡頁](/zh-hant/contact)安排討論，先確認下一期付款與已付款項應如何處理。
