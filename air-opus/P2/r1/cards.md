# P2 r1 카드 문안 (Air Opus) — 1080×1350, 6장

공통: 인물 실명·지명·식당 이름 없음. 식당 장면은 증언을 바탕으로 한 재구성 그림이며 대사를 만들지 않는다. '증언 요지'와 '법원 판단'을 다른 색 칸으로 나눈다. 최소 글자 32px.

## 1. 표지
- 상단 작은 글씨: 오늘의 판결 · 대만 1심
- 제목: 같이 이혼 등록까지 마쳤는데, 1심은 아직 부부라고 판결했다
- 부제: 증인 한 명이 남편의 이혼 뜻을 직접 확인하지 않았다
- 하단: 臺灣新竹地方法院 113年度婚字第59號 · 2024.6.11
- 그림: 도장 찍힌 이혼 등록 서류와 증인 서명란 두 칸

## 2. 서류만 보면 다 갖춘 이혼
- 제목: 2023년 12월 14일 하루에
- 이혼 합의서에 부부 서명
- 증인 서명 두 개
- 같은 날 부부가 함께 戶政事務所에서 이혼 등록
- 하단: 여기까지는 부부 사이에 다툼이 없는 사실

## 3. 남편과 아내의 말
- 제목: 증인은 남편 뜻을 들었나
- 남편: 증인이 누군지 몰랐다 / 둘 다 내 뜻을 묻지 않았고 서명할 때도 없었다 → 아직 부부임을 확인해 달라는 소송
- 아내: 두 증인 모두 부부 양쪽의 진짜 이혼 뜻을 직접 확인하고 서명했다

## 4. 법정에 나온 증인 (증언 요지)
- 그림: 식당 테이블에 두 사람과 서류 한 장 (재구성)
- 아내를 7~9년 알고 지낸 지인
- 아내 부탁으로 식당에서 아내와 단둘이 만나 서명
- 그때 다른 증인은 이미 서명, 부부 서명·날짜·자녀·재산 칸은 비어 있었음
- 서명 전후로 남편을 만난 적도, 연락처도 없었고 남편의 이혼 뜻을 확인한 적도 없음
- 등록하는 날에도 가지 않음
- 하단: 부부 모두 이 증언에 이의가 없었다 · 장면은 재구성

## 5. 법원이 본 증인의 조건
- 제목: 증인은 무엇을 보고 들었어야 했나
- 법원이 인용한 판례: 같은 자리·같은 시각에 서명할 필요는 없다
- 하지만 부부 두 사람 각자의 이혼 뜻을 직접 보거나 들어야 한다 (親見或親聞)
- 한쪽 배우자에게서 전해 들은 것만으로는 부족
- 결론 칸: 이 증인은 자격 없음 → 법정 방식을 못 갖춘 협의이혼은 무효(민법 73조), 등록이 돼 있어도 → 혼인관계 존재 확인, 소송비용은 아내 부담
- 하단: 다른 증인 한 명은 따로 판단하지 않음 · 1심, 이후 항소·확정은 확인되지 않음

## 6. 정보 카드 — 대만 협의이혼의 방식
- 제목: 증인 칸을 채우는 것과 증인이 되는 것
- 민법 1050조 원문: 兩願離婚，應以書面為之，有二人以上證人之簽名並應向戶政機關為離婚之登記。
- 뜻: 서면 + 증인 2명 이상 서명 + 戶政 등록
- 이 판결이 본 증인: 부부 두 사람 각자의 이혼 뜻을 직접 보거나 들은 사람
- 서명 시각·장소가 꼭 같을 필요는 없다는 것이 판례의 설명
- 방식을 못 갖추면 무효(73조) — 등록을 마친 뒤에도 다툼이 될 수 있다
- 출처 줄: 민법 1050·73조 law.moj.gov.tw (2026-10-20 Astra 확인)
