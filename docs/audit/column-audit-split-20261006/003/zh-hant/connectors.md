# connectors — 원문에 없던 텍스트 전부 (6건 + 사실 정정 1건, R2 반영)

R2로 `## 官方依據` H2와 출처 목록 추가 2항목(刑法41·276)은 삭제했다(1차의 7·8번).

draft.md에서 원문에 없는 글자는 아래뿐이다. 맨 끝 "사실 정정"은 리드 추가 지시(F-007)에 따른 오류 정정이다. 나머지는 원문 문장을 그대로 고르고 옮기고 지운 것이다.

## 이동 문장의 연결 조각 (1–4)

1. Q1 문단3 끝 (Q19에서 이동)
   - 원문 Q19: `即使僅有財物損失，仍應另行檢視道路交通管理處罰條例第62條的處置義務及行政責任。`
   - draft: `應另行檢視[道路交通管理處罰條例第62條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=K0040012&flno=62)的處置義務及行政責任。`
   - 변경: 앞부분 "即使僅有財物損失，仍" 삭제(글자 추가 없음). 링크는 Q19의 [62] 링크 URL 그대로, 문구는 조문명으로 펼침.
2. Q4 문단1 끝 (Q17에서 이동)
   - 원문: `過失致死則為第276條`
   - draft: `過失致死則應檢視[刑法第276條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0000001&flno=276)。`
   - 변경: "刑法" 추가(Q4에는 앞에 刑法 조문이 없어 어느 법인지 불분명해짐), R3에서 "則為" → "則應檢視"(원문 Q17 앞 절의 동사 "應檢視" 재사용). 링크는 Q17의 [276] URL 그대로.
3. Q4 문단1 끝 (Q17에서 이동)
   - 원문: `第41條的易科罰金亦有適用要件與例外，並非一律准許。`
   - draft: `[刑法第41條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0000001&flno=41)的易科罰金有適用要件與例外，並非一律准許。`
   - 변경: "亦" 삭제(앞 문장이 떨어져 나가 "또한"이 가리킬 곳이 없어짐), "刑法" 추가. 링크는 Q17의 [41] URL 그대로.
   - 같은 자리에 `實際刑度依過失、損害及個案情節決定，不能以固定月數預測。`는 글자 변경 없이 이동.
4. Q5 문단3 둘째 문장 주어 (Q18에서 조각 이동)
   - 원문 Q5: `非告訴乃論之罪，即使雙方私下和解，也不會自動終結追訴；…`
   - draft: `過失致死等非告訴乃論之罪，即使雙方私下和解，也不會自動終結追訴；…`
   - 변경: Q18 원문 "過失致死等非告訴乃論之罪" 의 "過失致死等" 5자만 가져옴.
5. Q9 끝 링크 문단 (HUB-TRIM, 링크 문구)
   - `親屬無償照顧的看護費與照護期間，另見[家人照顧能請求車禍看護費嗎？先分清照護需求與期間](/zh-hant/columns/taiwan-accident-family-care-necessity-period)。`
   - 앵커 = 085 제목 그대로. 앞 구절은 Q9 소제목의 "親屬照護費用"과 085의 주제에서 가져온 지칭이며 법적 주장은 담지 않음.
