naturalness (1 = machine, 5 = native professional): N/A for guidance pack (out of scope; part a), 4/5 for columns
variety used: standard தமிழ் in Tamil script, consistent for Tamil Nadu and Sri Lanka readers — not mixed with another language except Traditional Chinese glosses and names that must stay (TFDA, PIF, TWD, PTT). Dates are day–month–year (13 செப்டம்பர் 2025, 1 ஜூலை 2026, 5 ஜூன் 2026). The decimal point is used (0.5 மீட்டர்). Thousands use a Western comma (TWD 1,579,589); the digits match the English, so this is not given a fix row.
systemic patterns (max 6, each one line, with 1 example quote):
- 辦法 is named முறை, which is a method, while 規則 is correctly விதிகள் and 條例 is then also called விதிகள்: "அழகுசாதனப் பொருள் தகவல் கோப்பு நிர்வாக முறை"
