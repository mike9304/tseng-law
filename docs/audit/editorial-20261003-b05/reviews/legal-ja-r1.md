## 확인 증거와 남은 범위

- `python3`의 `Path.read_bytes()`와 `hashlib.sha256()`로 원고·evidence·PNG를 읽고 위 SHA 및 bytes를 출력했다. 실행 종료 코드 0. 본문도 줄 번호를 붙여 전부 읽었다.
- `urllib.request.urlopen` + `HTMLParser`로 S2의 실제 Q1–Q7를 추출한 실행은 HTTP 200, 종료 코드 0이었다. 검색 스니펫을 원문 열람으로 대체하지 않았다.
- 원고와 evidence는 읽기만 했으며 검수 후 재확인 SHA도 위 동결본과 같다.
- 현재 글의 좁은 법률 주장에 필요한 미해결 출처 gap은 없다. 원 공고의 정확한 시행 문구, 특정 결항의 개별 환급 결과, 심야 통지의 날짜 계산은 이번 검수로 확정하지 않았다. 원고에도 그 결론이 없다.
- 향후 본문·법률 조건이 바뀌면 새 SHA로 재검수해야 한다. 공개 날짜 조정·문체 검수·배포는 이번 법률 승인 범위 밖의 후속 단계다.

## R2 — 공개 예정일 10월 4일 조정의 독립 delta 검수

결론: APPROVE, MUST 0 / SHOULD 0. 원고의 날짜 메타데이터 세 줄만 바꾼 아래 새 SHA에 기존 법률·출처 승인을 이어간다. 이 단락은 앞의 R1 원문 전체를 보존하고 덧붙였다.

- Delta 확인 시계: `2026-10-03 15:57:52 UTC` = 대만 2026-10-03 23:57:52 / 한국 2026-10-04 00:57:52. 게시일은 root가 예정한 Asia/Taipei 2026-10-04이며, 그 날짜가 시작되기 전 게시하지 않는다는 조건을 변경하거나 실제 게시 완료로 기록하지 않는다.
- 실제 읽은 기록: `batch-005/B05publication-date-delta.json`, SHA-256 `365c59e3676c7203ec79436ae77dc8e128f12d1cfe1cc5ffceb587f74fde719e`. 해당 JA 항목, 현재 원고 전체와 evidence 추가 절을 직접 읽고, 아래 검증을 별도 Python 코드로 수행했다.
- 새 원고 SHA-256: `3198cd71bceb934cd87721d1272e37899bea058059f5ac9f351851cba75c9934`.
- 새 evidence SHA-256: `5bfe1afdbc652a11caa6c13d9a7a4b3eaa0aabfc5a33bbe3728a081c578d1cb0`.

확인한 원고 변경은 5행 `published: "2026-10-03"` → `published: "2026-10-04"`, 6행 `lastmod`의 같은 변경, 7행 `date_display: "2026年10月3日"` → `date_display: "2026年10月4日"`뿐이다. 독립 역치환으로 이전 승인 원고의 전체 SHA `ef885b4d15a7e9e5708d3ccdcb9171aaf69689f1de39095156d356f3072c7c12`가 정확히 복원됐다. 변경 행 목록은 `[5, 6, 7]`이었다.

본문은 `bytes.split(b'---', 2)[2]`의 전체 5,142 bytes가 같고 SHA는 `f71c98de7df213a10ac48198eeeb8dc3886f66381d04d8f76f32efb8d3955710`으로 유지됐다. 따라서 법률 조건, 출처와 그 날짜, 원고 50행의 실제 확인일 `2026年10月3日（台湾時間）`도 바뀌지 않았다. 제목·요약·SEO·내부 author와 14–16행 이미지 메타데이터 역시 세 줄 역치환의 전체 SHA 복원으로 불변을 확인했다.

Evidence의 앞 17,213 bytes는 기존 전체 SHA `8f5031ca94ec7c7ee1911f3d0cce92e74b2aa571f00cfa7fcdf1b99343493648`와 일치했다. 2,606 bytes의 추가 절은 예정 게시일의 범위·이전/새 SHA·미실시 공개 작업을 구별한다. 과거 출처 열람일이나 원 승인 기록을 덮어쓰지 않았다. 실제 PNG의 SHA도 기존 `9c1e5e0592d29f656e40d1f675fba7f7ff513af8128361af77fdd9c339761368`와 같았다.

검증 명령은 `python3`에서 실파일을 읽고 `hashlib.sha256`, 날짜 세 줄의 정확한 역치환, 줄별 차이, 본문 bytes, evidence prefix와 PNG SHA를 각각 assert 비교한 것이다. 실행 결과 `INDEPENDENT_PASS`, 종료 코드 0. 기존 법률과 이미지는 불변이므로 새 법률 조사나 시각 검수를 반복했다는 주장을 하지 않는다. 이 delta 검수는 본 검수 보고서의 추가 기록만 변경했으며 원고·evidence·이미지·repo에는 쓰지 않았다.

R1 보고서의 원래 7,960 bytes 전체를 prefix로 보존했다. 그 prefix SHA는 `22d2fb25467fadcdec8bce2d846960cfa721adfba9526a4cfafb81fe263ad63a`다. 이번 승인은 위 새 D/E의 날짜 차이에 대한 독립 법률·출처 승인이다. 문체 delta 승인, 준비 패킷 갱신, 날짜에 맞춘 실제 공개 및 운영 readback은 root의 후속 절차다.
