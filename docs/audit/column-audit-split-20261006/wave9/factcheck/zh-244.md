## 참고 메모 (판정 아님, 수정 불요)
1. §10: 칼럼 「離婚、分割遺產這類當事人可以自行處分的事項，原則上看雙方提出的主張和證據（第10條）」 — §10② 는 準用 후 但書 4종(「一、涉及家庭暴力或有危害未成年子女利益之虞。…四、依其他情形顯失公平。」)에서 §10① 법원 직권 사실 참작·증거조사로 돌아감. 칼럼은 「原則上」을 쓰고 있어 오판 유발 수준은 아님 → OK. 원하면 「但涉及家庭暴力或有危害未成年子女利益之虞等情形，法院仍可依職權調查」 1구 추가 가능(선택).
2. §44③ 문언은 「家事非訟事件之第一審終局裁定」 이며, 合併裁判이 判決로 나온 경우 非訟 부분만의 불복 경로는 실무상 설명이 갈릴 수 있음. 칼럼은 마지막 문단에서 「要先分清楚自己不服的是哪一部分，再去核對上訴或抗告的期間」로 유보하고 있어 오류 아님. (2차: airitilibrary 論文·rootlaw 검색 결과는 같은 방향이나 1차 立法理由는 열람 못 함)
