# 台湾劳动法：在台湾领取资遣费真的很难吗？

![主图](../images/008-taiwan-labor-severance-law/featured-01.jpg)

本文说明台湾资遣费（資遣費）在什么情况下才会发生，以及实务上常见的争议。

以下先从制度的基本结构谈起。

![](../images/008-taiwan-labor-severance-law/img-01.jpg)

先看一项常被用来对照的制度差异。

在部分法域（例如韩国），受雇人离职时公司通常须给付离职金。

台湾的制度与此不同：

仅在公司资遣受雇人时，才发生给付资遣费的义务。

若受雇人自行辞职，公司无须给付资遣费。

​

但若受雇人有不法行为，

**违反工作规则，**

**或无正当理由连续3日旷工（曠職），**

公司得解雇且无须给付资遣费。

​

下表就三种情形作简要对照。

|  |  |  |  |
| --- | --- | --- | --- |
| **类型** | 经济解雇（資遣員工，經濟解僱） | 惩戒解雇（解僱員工，懲戒解僱） | **受雇人自行辞职** |
| 意义 | 若雇主因企业状况有调整人力的需要，事由位于雇主企业经营领域，而非受雇人的责任。因此雇主须遵守预告期间并给付资遣费，以平衡补偿受雇人的不利益。 | 若受雇人有不法或不适当行为，雇主得不经事先预告立即终止劳动合同（勞動契約），且无须给付资遣费。这是雇主惩戒权限之一。 | 受雇人得随时终止契约，但须依雇用期间遵守预告期间，使雇主得以办理交接并寻找替代人员。 |
| 条件 | 有  （台湾劳动基准法第11条） | 有  （台湾劳动基准法第12条） | 无 |
| 事先预告 | 需要 | 不需要 | 需要 |
| 难度 | 须符合法定列举事由，并不容易 | 困难 | 受雇人得随时终止，但须遵守预告期间 |
| 公司是否须给付资遣费 | 需要 | 不需要 | 不需要 |
|  | 台湾劳动基准法第11条（勞動基準法第11條）：除发生下列情形之一外，雇主即使事先通知受雇人，也不得终止劳动合同。  1. 歇业或转让  2. 亏损或业务紧缩  3. 不可抗力须停止营业达1个月以上  4. 业务性质须减少人力，且被解雇者无法调至其他适当职位  5. 特定受雇人无法圆满完成该职位所要求的工作 | 台湾劳动基准法第12条（勞動基準法第12條）：受雇人有下列情形之一时，雇主得不经事先通知解雇。  1. 订立劳动合同时为虚伪意思表示（虛偽意思表示），使雇主陷于错误，并使企业有受损害之虞  2. 对雇主、其家属、代理人或其他同事施暴或重大侮辱  3. 受有期徒刑以上确定判决，未宣告缓刑，亦未准易科罚金  4. 严重违反劳动合同或工作规则  5. 故意消耗雇主所有机械、工具、原料、产品或其他物品，或故意泄漏雇主技术及营业秘密，致雇主受损害  6. 无正当理由连续3日旷工，或1个月内旷工6日以上 |  |

> 在台湾，每满1年年资，
> 雇主须给付平均工资0.5个月作为资遣费。
> 至多6个月工资。此公式适用于劳工退休金条例第12条所适用的年资；劳动基准法第17条所适用的年资，则每满1年给付平均工资1个月，没有上限。

​

若受雇人薪资较高且已有一定年资，

资遣费也会相对较高。

因此，个别企业会采取各种方式，

以免给付高额资遣费，

并促使受雇人自行辞职。

受雇人须谨慎，

留意不要落入公司的意图。

​

下面是一件实际承办过的案件（当事人信息已作匿名处理）。

有一家知名的A公司，在台湾各地设有据点。

因某种原因经营层更换，

新经营层一上任，就开始着手安排，

为了降低人事成本，

陆续约谈薪资较高、年资较深的受雇人。

当事人B先生当时已在A公司任职超过10年，

并且是台湾中部地区业绩最好的业务人员。

因为薪资与奖金非常高，

公司把B先生当作目标。

​

有一天，一名主管约谈B，

突然开始责备B工作不认真。

主管说公司经营有困难，

要求B作出牺牲、为其他人作示范，

降低自己的薪资与职位。

否则B应离开公司；

并交给B一张A4纸，

要他在纸上写下“本人［姓名］自愿降低职位与薪资”，

以此作为书面记载。

这份协议，是要给其他全部受雇人看，

让他们跟随。

​

B是台湾中部地区业绩最好的受雇人，

为公司带来许多营收，

并且每天认真工作，

因此强烈拒绝这项不合理要求。

B拒绝写下那些内容，

最后公司干部愤怒地命他离开。

B带着不公与悲伤的心情离开，

离开待了10年的公司，

其后不再前来上班。

​

同样地，公司也

降低了许多主管级受雇人的薪资；

部分受雇人无法忍受这种对待，

最终自行辞职。

​

但B在经营层更换后，

已认识到公司想以不适当方式让受雇人离开，

并及早有所察觉；

并且发现公司在受雇人离职前已经对外刊登招聘，

B在前往面谈当日，

用手机录下了全部过程，

并得以证明自己并非自行辞职。

因此，在后续程序中，

得以依法确认其资遣费请求权，

而其他已经离开的受雇人，则缺少同样的证据基础。

​

这类情形并不少见，

因此，若公司采取不适当手段，

请务必保存证据。

若公司记载受雇人的小错误，

设定难以达成的目标，

提出过度要求，

或将受雇人调到奇怪职位，

**您必须保存证据。**

**您平常的出勤记录、**

**加班记录、绩效记录、**

**工作规则、与同事及上级的电子邮件往来**

**以及与上级的面谈录音——**

**请保存对您有利的证据。**

​

若您在台湾工作，

资遣费比想象中更难取得，

不要轻易与公司达成和解，

并留意公司是否以不适当方式解雇您，

或促使您自行辞职。

资遣费是受雇人的法定权利，

只有在符合法定要件时，才须给付；这不是对任何离职的承诺。

您也须在台湾保护自己的权利。
