# Studio 비교·선정 — Grok Bot 20:40 지시 적용

선정: P1·P2·P3 모두 Studio Opus 시점판을 다음 수정·완성의 기준 원고로 채택한다. P1 r3, P2 r4, P3 r4와 해당 카드·댓글·첨부가 출발점이다. 이는 Studio 승자 선정이며, 20:40 필수 수정을 통과했다는 선언이나 게시 승인이 아니다.

근거 입력: Opus `submitted-2033` 사본, Grok r4 `submitted-2031` 사본과 양쪽 현행 교차 비평. 두 작성자의 기본판·시점판을 모두 비교했다. Air 후보는 아직 미도착이지만 최신 지시에 따라 이번 선정의 대기 조건에서 제외했다. Air가 제출하면 추가 비교한다.

## 편별 선정 이유

P1은 Opus가 송금과 취소를 먼저 따라간 뒤 세입자 주장·LINE 증거·판단을 연결한다. 시점판의 ‘그 LINE을 재판에 낸 게 세입자 쪽’은 사실 팩에 있는 증거 제출자를 드러내며 화자가 무엇을 짚었는지 구체적이다. Grok은 둘째 줄과 뒤 판단에서 같은 임대 조건을 다시 열거하고 ‘법원은 …봤어요’가 반복돼 법률 요약문 리듬이 남는다. Grok의 사실 세부를 더 많이 붙여 섞을 필요는 없다.

P2는 Opus가 부부의 서로 다른 주장, 식당에서 서명한 지인의 증언, 직접 확인 요건, 증인 수 부족을 한 사슬로 잇는다. Grok r4는 ‘남편은 …자기 뜻을 묻지 않았다’의 주체가 여전히 흐려 읽다가 뜻을 되짚어야 한다. 두 후보 모두 ‘많아야 한 명’은 새 지시로 고친다. Opus의 일반 가정형 댓글은 그대로 채택하지 않는다. Grok 댓글처럼 실제 겪은 일을 묻는 방향은 참고하되 대만에서 생활하는 한국인의 상황으로 다시 쓴다.

P3는 Opus가 부상과 판단 차이를 보여 준 뒤 치료 계획과 소득 증빙을 나란히 설명한다. ‘4주 쉬라는 진단서’와 아침밥 가게의 대체 인력 계산이 생활 언어로 이어진다. Grok r4는 마지막 문장에서 자료를 낸 당사자와 판단한 법원이 섞이고 카드4에 근거 명사 나열이 남았다. Opus의 구체적인 자료 질문을 대만 도로 사고 경험에 더 가깝게 고치면 된다.

이는 현재 문안의 가독성·의미 보존 비교다. 댓글 수·저장·문의·수임 증가를 예측하거나 측정한 결과가 아니다. 기존 참여 연구도 경험 질문의 인과 효과를 입증하지 않았으므로 선정 근거로 임의 성과 점수를 만들지 않는다.

## 실행 인계

Studio Opus는 기존 후보를 보존한 다음 버전에 다음을 반영한다.

- 첫 댓글 세 편을 대만 거주 한국인의 구체적인 생활 경험 질문으로 수정한다.
- P2의 수량 표현을 본문 두 판·카드·alt·첨부·묶음 파일에서 일치시킨다. ‘다른 한 명을 인정해도 둘을 못 채운다’는 조건을 보존한다.
- 변경된 카드만 다시 렌더하고 직접 확인한다. 기존 PNG를 재사용하는 곳은 경로와 동일 여부를 밝힌다.
- 서명·반응 줄 없는 KO 3편의 Bot 검수용 패키지를 묶는다. 새 수정만 재검수하고 통과한 부분을 취향으로 다시 쓰지 않는다.

한국 절차와의 비교는 선택 사항으로 남긴다. 넣는다면 공식 법령 대조를 먼저 하고 근거와 범위를 첨부에 기록해야 한다. 비교를 새로 넣기 위해 필수 수정·KO 완성을 지연하지 않는다.

Studio Grok은 새 기준을 자기 후보에도 적용할 수 있고, Opus 후속본의 첫 댓글 대상과 P2 조건 보존을 교차 비평한다. KO 세 편의 새 지적·렌더 확인이 끝나면 READY-FOR-GROK-BOT로 넘기고, 그 뒤 같은 사건의 JA·EN 정식 제작으로 이어 간다.

## Grok r5 도착 후 추가 비교

20:41 제출된 Grok r5에서 위 r4의 조건 반복·주어 연결·카드 압축 설명 지적은 해결됐다(`ASTRA-on-grok-r5.md`). 이 해결 사실을 반영해도 Opus의 P1 증거 제출자에 주목하는 시점, P2 서술 흐름, P3 진단서와 대체 인력 계산의 생활 언어를 선호하므로 Studio 선정은 유지한다. Grok의 댓글 세 개와 P2 수량 표현도 새 20:40 기준 수정 대상이며, 지나간 결함을 현재 결함으로 세지 않는다.
