# ko-256 taiwan-vat-foreign-digital-services-registration — 사실 대조

대조 일시: 2026-10-06~07 (law.moj.gov.tw·law-out.mof.gov.tw·mof.gov.tw·etax.nat.gov.tw 직접 열람). 대조한 주장 수: 40
WRONG 0 / OUTDATED 0 / OVERBROAD 0 / MISSING-COND 3 (M-1 중간, M-2·M-3 낮음) / UNVERIFIED 0

결론: 금액·기한·조문 번호·벌칙 범위·주체는 현행 원문과 일치. 60만(2025-04-07부터, 그 전 이미 48만 초과 사업자는 개정 전 기준) 서술 정확. M-1은 플랫폼 거래에서 "판매자가 직접 대금을 받으면 등록·신고 대상"이라고 쓰면서 60만 기준 조건을 뺀 것.

## 개정 여부 (LESSONS 8번)

- 시행세칙(G0340081): 113-12-17(제4-1·7·11·12·16-3·17·32-2·38·51조), 114-01-01 시행 — 칼럼 "2024년 12월 17일"과 일치.
- 稅籍登記規則(G0340087): 111-08-08(112-01-01 시행), 칼럼 "2022년 8월 8일"과 일치. 統一發票使用辦法(G0340082): 113-12-12(제7·20-1·32조) — 제7조의1은 대상 아님, 칼럼 날짜 일치.
- 跨境電子勞務交易課徵營業稅規範(GL010236): 114-04-07 개정, 시스템 갱신 2026-09-22 기준 최신. 제3점 「年銷售額逾新臺幣六十萬元」. 중구국세국 2026-07-10 안내도 「現行規定為新臺幣60萬元」 — 이후 기준 변경 없음.

## 지적 사항

### M-1 (중간) 플랫폼 경유 판매 — 판매자 등록·신고 의무에서 60만 기준 누락, FAQ3(L19)·본문 L67
- 칼럼 문장 (L19): "플랫폼을 쓰더라도 판매자가 직접 대금을 받으면 판매자가 등록·신고 대상입니다."
- 칼럼 문장 (L67): "판매자가 대금을 직접 받으면 판매자가 등록·신고 대상이고 플랫폼이 판매자에게서 받는 수수료는 대만 영업세 과세 범위가 아닙니다."
- 1차 원문(規範 四、(二)1.(1)): 「外國業者A認屬境外電商營業人，符合前點第一款應辦理稅籍登記規定者，其自買受人乙收取之全部價款，應依營業稅法第三十五條規定報繳營業稅。」 — 「前點第一款」은 三、(一) 「銷售電子勞務予境內自然人之年銷售額逾新臺幣六十萬元者，應…辦理稅籍登記」.
  URL: https://law-out.mof.gov.tw/LawContent.aspx?id=GL010236
- 무엇이 다른가: 원문은 "등록 기준(연 60만 초과)을 충족하는 판매자"가 직접 수취분을 신고한다고 정한다. 칼럼은 조건 없이 "등록·신고 대상"이라고 써서, 대만 개인 대상 매출이 60만 이하인 판매자도 플랫폼 거래만으로 등록해야 하는 것처럼 읽힌다(같은 글 L36 제목·L38과도 내부 불일치).
- 고친 문장 제안:
  - L19: "플랫폼을 쓰더라도 판매자가 직접 대금을 받으면, 대만 개인 대상 연 매출이 60만 대만달러를 넘을 때 판매자가 등록·신고 대상입니다."
  - L67: "…판매자가 대금을 직접 받으면 판매자의 대만 개인 대상 연 매출이 60만 대만달러를 넘는 경우에 판매자가 등록·신고 대상이고…"

### M-2 (낮음) 매입세액 공제 조건 일부 누락 — L50
- 칼럼 문장: "대만 사업자에게서 받은 매입 증빙의 세액은, 그 매입분을 대만 개인 대상 전자서비스 판매에만 썼다면 공제할 수 있습니다(시행세칙 제38조의3, 규범 제5점)."
- 1차 원문(規範 五、(三)): 「境外電商營業人自國內營業人取得載有稅額之進項憑證，如無營業稅法第十九條第一項規定不得扣抵情事，且係專供銷售電子勞務予境內自然人使用並符合營業稅法施行細則第三十八條第一項規定者，得申報扣抵銷項稅額。」 / 시행세칙 §38-3 「…依第三十八條規定應檢附之退抵稅款及其他有關文件，以其專供銷售電子勞務予境內自然人使用者為限。」
  URL: https://law-out.mof.gov.tw/LawContent.aspx?id=GL010236 , https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=G0340081&flno=38-3
- 무엇이 다른가: 전용 요건만 쓰고, 세액이 기재된 증빙일 것과 영업세법 제19조 제1항 불공제 사유가 없을 것(시행세칙 제38조 제1항 요건 포함)을 빠뜨림. 독자가 손해를 볼 정도는 아니라 선택 반영.
- 고친 문장 제안: "대만 사업자에게서 받은 세액 기재 매입 증빙의 세액은, 영업세법 제19조 제1항의 불공제 사유가 없고 그 매입분을 대만 개인 대상 전자서비스 판매에만 썼다면 공제할 수 있습니다."

### M-3 (낮음) 구매자 범위 — "대만 사업자"만 쓰고 기관·단체 구매자 누락 — L17(FAQ2), L26, L56, 표 L60·L62
- 칼럼 문장: "구매자가 대만 사업자이면 납세의무자는 구매자입니다(제2조 제3호)." / 표 "대만 사업자에게 판매".
- 1차 원문: 營業稅法 §2③ 「外國之事業、機關、團體、組織，在中華民國境內無固定營業場所者，其所銷售勞務之買受人」(구매자 자격 제한 없음). MOF 2025-05-14 보도자료 「至境內非自然人（含營業人）購買者，則應依規定自行計算繳納營業稅」, 중구국세국 2026-07-10 「營業人及機關團體向境外電商購買電子勞務，應依…第36條規定申報繳納營業稅」, 기관·단체 구매자는 「購買國外勞務營業稅繳款書(408)」로 납부.
  URL: https://www.mof.gov.tw/singlehtml/384fb3077bb349ea973e7fc6f13b6974?cntId=df234f5edfd14d36a4adb7dd9fa9f938
- 무엇이 다른가: 원문 납세의무자는 구매자 일반(자연인 제외). 칼럼 표는 "개인" 아니면 "사업자"로 양분해 대만 기관·단체(비영리)가 구매자인 경우를 놓친다. 칼럼 문장이 틀린 것은 아님.
- 고친 문장 제안(L26·L56 등): "구매자가 대만 사업자나 기관·단체이면 세금을 내는 쪽이 구매자로 바뀝니다."
