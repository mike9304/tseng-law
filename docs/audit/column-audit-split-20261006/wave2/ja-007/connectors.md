## C. 사실 정정 (WO 지시, FINDINGS)
20. F-001 [part2 §1] 원문 L188 s1 「差額の均等分配が著しく不公平となる場合、裁判所は、財産の隠匿・処分、家事労働や子の養育への貢献、共同生活と財産取得の全般的事情など、法定の事情を考慮して分配を調整し、又は免除することができます。」 →
   「夫婦の一方に婚姻生活への貢献または協力がなかった場合や、その他の事情があって均等に分配すると不公平になる場合には、裁判所は分配額を調整し、または免除することができます。裁判所はこの判断にあたり、家事労働、子の養育、家庭に対する全体的な協力の状況、共同生活および別居の期間、婚姻後の財産を取得した時期、双方の経済力などを総合して考慮します。」
   근거: law.moj.gov.tw 民法 1030-1 제2항 「…無貢獻或協力，或有其他情事，致平均分配有失公平者，法院得調整或免除其分配額。」, 제3항 「…應綜合衡酌夫妻婚姻存續期間之家事勞動、子女照顧養育、對家庭付出之整體協力狀況、共同生活及分居時間之久暫、婚後財產取得時間、雙方之經濟能力等因素。」(2026-10-06 직접 열람). 「著しく不公平」·「財産の隠匿・処分」 제거. 「など」는 법문 「等因素」에 대응(ko PASS 문구에는 없음; ja 267도 「など」를 씀) — 리드 판단 사항, notes 참조.
21. F-012 [part2 §1] 원문 L182 s1 「民法第1017条は、婚前財産と婚後財産の区分および推定に関する枠組みを与えます。」 →
   「民法第1017条は、夫婦の財産を婚前財産と婚後財産に区分しています。婚前の財産か婚後の財産かを証明できない財産は婚後財産と、夫婦のどちらの財産かを証明できない財産は夫婦の共有と推定されます。」 (근거: 民法 1017 「不能證明為婚前或婚後財產者，推定為婚後財產；不能證明為夫或妻所有之財產，推定為夫妻共有」, 2026-10-06 열람.) s2·s3은 원문 그대로 뒤에 붙음(「これらは財産制の分析に有用ですが…」).
22. F-003 [children §2] 원문 L242 s1 자리에 신규 1문장(원문 L242 s1은 F-004로 삭제):
   「確定した養育費の裁判や、裁判所で成立した和解のうち、まだ履行されていない部分は、その後の事情の変更により元の内容どおりでは著しく不公平になる場合に、裁判所に変更を申し立てることができます（家事事件法第102条第1項、第107条第2項）。」
   근거: 家事事件法 §102① 「就第九十九條所定各項費用命為給付之確定裁判或成立之和解，如其內容尚未實現，因情事變更，依原裁判或和解內容顯失公平者，法院得依聲請人或相對人聲請變更…」, §107② 「前項命給付扶養費之方法，準用第九十九條至第一百零三條規定」(2026-10-06 열람). 「合意書」로 넓히지 않았다(득=「できます」). 「著しく不公平」은 §102 원문 「顯失公平」 그대로이며 F-001 문구와 무관.
23. F-004 [children] 원문 L242 s1 「増額、減額その他の変更を求める場合も、「予見不能な事情変更」だけを唯一の要件とするわけではありません。」 → 삭제(대체문은 22번).
24. F-005 [hub §4 목록 7] 「7. 治癒不能の重い疾病。 これは法文の古い疾病表現であり、…」 → 「7. 治癒不能の悪疾（法文は「有不治之惡疾」）。 これは法文の古い疾病表現であり、…」 — 앞 어구만 교체, 뒤 두 문장은 원문 그대로(「法文の古い疾病表現」이 「悪疾」와 맞음). 근거: 民法 1052①7 「有不治之惡疾」(열람).
25. 날짜 갱신 [hub §4] 원문 L126 s1 「このただし書は、2026年7月25日時点の現行条文に残っています。」 → 「…2026年10月6日時点の現行条文に残っています。」 (1052② 단서 「但其事由應由夫妻之一方負責者，僅他方得請求離婚」 2026-10-06 열람 확인, WO 지시.)
26. 날짜 갱신 [part2 공식 자료] 원문 L292 s1 「…2026年7月25日時点で確認したものです。」 → 「…2026年10月6日時点で確認したものです。」 — part2 출처는 민법 링크 2개이고 인용 조문(§1017·§1030-1은 내가 직접 열람, §1056·§1057은 ko-007-fable-r2의 2026-10-06 재확인)이 모두 10-06에 확인되어 ko 275와 같은 처리. hub·children의 출처 기준일(7/25)은 그대로.
