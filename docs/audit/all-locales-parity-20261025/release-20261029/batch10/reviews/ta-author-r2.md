916의 짧은 반박을 삭제한 뒤 실제 검사에서 CV .448 FAIL이 발생했다. 이를 남기고, 현재 법 조문만으로 2018 사건의 모든 근거를 단정할 수 없다는 설명과 당시 법적 근거·행동 기록을 따로 읽어야 한다는 이유를 한 문장으로 연결했다. 별도의 짧은 현재법 안내 다음에 긴 이유 설명을 두어 비슷한 길이의 문장 반복을 줄였다. 새 수치가 좋다는 이유만으로 의미 연결을 승인한 것은 아니다.

현재 실제 측정은 915/916/918/919/920/921 순서로 44/40/43/32/38/54문장, CV .478/.465/.451/.476/.461/.471이다. 처음 여섯 편 실행은 916 때문에 exit1이며 나머지 다섯 편의 현재 SHA별 OK를 사용한다. 916 수정 후 표적 실행만 exit0이다. 전체를 다시 실행해 성공한 것으로 기록하지 않는다. 구조검사6편과 이후916 표적검사 모두 오류0이다. REQUIRED36과 FAQ17은 그대로이며 의미 검토는 기계 통과와 별도로 한다.
