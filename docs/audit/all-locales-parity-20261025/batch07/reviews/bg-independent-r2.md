# BG 독립 R2 — 승인 변경의 표적 종결

R1의 필수 M1·M2와 선택 O1은 아래 현재 SHA에서 해결됐다. 검토한 변경 범위에 남은 필수 지적은 없다. 선택 O2 날짜 문장은 유지됐으며, BG915의 기존 날짜 약어 오분절 한계도 그대로다. 전체 언어·법률 재승인이나 사람 원어민 감수를 뜻하지 않는다.

| 원고 | 현재 SHA-256 | 저자의 실제 R2 공유 실행 |
|---|---|---|
| 916 | `cb3f84123bfd34d8c9587088875d7b7820e630afa5621c4e3a0fe6245f151cfa` | exit 0 / FAIL 0, CV .484, 42분절 |
| 921 | `a7e85faf8bd43c50827620fbc8e3e92e1b7eb18b825254bd4ca98fb712392013` | exit 0 / FAIL 0, CV .458, 40분절 |

저자 R2 SHA `354c63af1ef452026490d49ef2414f8cd3c2f18d6e32f9fcb8617003ed949f3a`, manifest SHA `6a7f59f1abf0d33739755627698fc27eba97f05842b4e7d248526ec7d3df1d14`와 실제 파일을 대조했다. 나머지 네 원고는 R1 SHA 그대로다. 기존 저자 기록·manifest·독립 R1 보고서를 고치지 않았다.

| 지적 | 실제 변경 및 주변 조건 재확인 | 판정 |
|---|---|---|
| M1 | 921 첫 문장은 `Дава ли остатъкът от монети в профила право на връщане на пари?`가 됐다. 이어지는 청구액 243,548 TWD·기각·사건 인용·불복불가는 남아 있다. 배치 도입은 사실/결과 3, 독자 질문 2, 물리적 장면 1이다. | 종결 |
| M2a | `Съдът не присъжда поисканата сума.`로 청구의 결과를 직접 쓴다. 다음 문장의 잔존 칩과 미사용 유료 포인트 OR 미사용 게임요금 구별, 모든 칩이 이미 쓰였다는 뜻이 아니라는 한정은 유지됐다. | 종결 |
| M2b | `В това дело съдът преценява искането за възстановяване според функцията на останалите монети.`가 실제 사건의 판단을 말한다. 직전의 이용자 자기 해지와 사업자 종전 조치 자동 정당화 부정이 그대로다. | 종결 |
| M2c | 7일 이후 제18점의 언제든 통지 해지권을 직접 쓰는 한 문장으로 바뀌었다. 앞 문단의 제4점 게임 시작 기산·서면·무이유·무비용 및 7일이라는 기간을 모두 확인했다. | 종결 |
| M2d | 추상적인 ‘서로 다른 기한’ 한 문장과 뒤 공백 한 칸만 삭제했다. 바로 앞의 제9점 최소 30일 보관과 요청 수령 후 7일 제공 의무, 뒤의 조기 요청 안내가 연결된다. | 종결 |
| O1 | 미국을 지원 주체, 대만을 민간투자 목적지로 명시했다. `възможна`와 준거법 조건, 미국–대만 맥락, 모든 투자자 지원 부정, 협정 전체 발효 미단정이 모두 남는다. R1에서 직접 확인한 USTR 투자 항목의 범위를 벗어나지 않는다. | 종결 |

남은 921의 직접 대비는 기능/화면 숫자, 대결 칩/환급 대상, 7일/영업일 세 곳이다. 법적 구별에 필요한 부정문을 모두 삭제하는 방식으로 지적을 닫지 않았다. 수정 뒤 `Съдът`으로 시작하는 두 인접 문장은 한 쌍이며 규칙의 허용 범위 안이다. 다른 시작·길이·인용·법적 조건의 새 문제는 이 변경 문단들에서 발견하지 않았다.

저자의 여섯 치환을 R1 백업에 실제 재적용해 현재 두 파일을 재현했고, 현재 파일에서 정확한 문자 위치로 역적용해 R1 전체 바이트·SHA를 복원했다. frontmatter/FAQ 전체와 모든 링크 값·순서는 같다. M2d의 공백 삭제도 예상된 범위로 따로 확인했다. O2의 915·918·921 원문 날짜 문장 세 개가 그대로 있음을 확인했다.

저자 원시 실행과 배열을 현재 SHA에 연결했으며 동일 CLI를 다시 돌리지 않았다. 변경 두 파일의 84개 이전 분절은 82개가 됐다. 그중 77개는 동일한 텍스트·순서로 유지되고 여섯 변경 구간은 새 문장 5개, 두 문장 통합과 한 문장 삭제를 포함한다. 변경 구간과 앞뒤 관련 문단을 직접 읽었다. 전 배치로는 현재 249개 분절 중 244개가 R1과 같다. 새 오분절은 발견하지 않았다.

최초 저자 래퍼가 916의 OK 출력 후 기존 배열 키를 잘못 읽어 중단한 사실도 확인했다. 스키마를 확인한 뒤 변경 두 파일을 다시 실행·저장한 기록과 구별했다. 이를 숨기거나 첫 실행에서 두 파일을 모두 검사했다고 적지 않는다. 변경 두 편 구조 검사 오류 0, 의미 검토 항목 10을 재사용하며, 미변경 네 편의 기존 항목까지 배치 전체 `REQUIRED` 30개는 유지된다.

BG915는 원고·기존 배열·수동 민감도 기록을 바꾸지 않았다. 그 정상 문장의 `г.` 뒤 대문자 주어를 도구가 둘로 나누는 한계는 미해결이다. 이번 종결이나 두 파일의 실제 PASS가 이 도구 문제까지 해결했다는 뜻은 아니다. 검수자는 BG 프로필 구현 이력이 있어 도구 코드의 독립 검증을 주장하지 않는다.

[표적 검증 증거](../checks/bg-independent-r2-evidence.json)에는 입력 21개 종료 해시, 정·역복원, 실제 배열 차이와 남은 한계가 있다. [최종 manifest](../checks/bg-independent-r2-final-manifest.json)로 연결한다. 이 검수에서는 원고·저자 기록·R·shared를 수정하지 않았으며 공개 렌더링·배포·사람 승인을 검사하지 않았다.
