# 台灣公司設立：營業場所選擇與台北市預先查詢

![營業場所選擇示意圖](../images/015-taiwan-company-setup-pitch-location/featured-01.jpg)

公司或店面的所在地，不能只依租金、交通、客層決定。簽約前必須確認預定的營業項目，能否在該地址、該樓層、該建物用途下經營。本文以在台北市辦理公司及商業登記、經營餐廳的情境為其中一個例子，整理現行的「營業場所預先查詢」制度。

![](../images/015-taiwan-company-setup-pitch-location/img-01.jpg)

餐廳因涉及土地使用、建築、消防、衛生、食品等多項確認，是容易理解的例子，但台北市的預先查詢並非僅適用於餐飲業的制度。此外，其他縣市的制度名稱、申請方式、應備文件及審查流程可能不同，行業別許可也另有規定，請確認管轄所在地的地方政府與各行業主管機關的最新說明。

## 1. 在台北市，只有特定行業才需要辦理營業場所預先查詢嗎？

不是。依台北市現行說明，自2023年1月1日起，申請公司及商業（含分公司及分支機構）之設立、所在地變更或增列營業項目登記時，應就營業場所與營業項目是否符合土地使用分區及建築管理規定辦理預先查詢，並將符合規定的查詢結果檢附於登記申請。請勿僅依舊制「主動查詢」營業項目清單判斷是否需要查詢。

台北市已改採在受理公司及商業登記前，全面確認營業場所與營業項目是否符合規定的機制。現行制度下，申請人原則上使用[台北市營業場所預先查詢系統](https://www.businesslocationinfo.gov.taipei/BLBQS/Home/Notice)，就預定地點與營業項目取得符合規定的結果，再檢附於相關登記申請。

現行程序大致依下列順序準備。

1. 確認將使用的正確地址、樓層、範圍及預定營業項目。
2. 取得最新的建物登記資料及其他應備文件。
3. 申請營業場所預先查詢，就地址與營業項目的組合接受審查。
4. 將符合規定的查詢結果，檢附於公司及商業之設立、所在地變更或增列營業項目登記申請。
5. 另行完成行業別許可、消防與衛生準備、裝修及其他開始營業要件。

依台北市現行說明，登記申請未檢附查詢結果時，不會因此直接作成最終決定；主管機關會以輔導函通知申請人補充結果，於補充後續行登記程序。若查詢結果顯示部分營業項目不符合規定，應依個別結果，評估變更營業場所，或將不符合規定的營業項目自登記申請中移除等因應方式。

一次查詢申請可受理的營業項目最多五項，台北市現行FAQ說明應選擇主要營業項目作為審查對象。請與第五點所定項目的隨案主動查詢區分確認。

[台北市營業場所協助查詢服務作業須知](https://laws.gov.taipei/Law/LawSearch/LawArticleContent/FL080687)中，對包含餐廳及其他餐飲服務在內的特定營業項目，仍保留「隨案主動查詢」的處理方式。這是指該作業須知第五點所列營業項目已包含在登記申請中，但已提出的符合結果未包含該項目時，由台北市商業處隨登記案件主動啟動查詢的補充機制。第五點清單並非恢復「僅清單所列行業才需要預先查詢」的舊有觀念。

關於制度變更的背景與適用登記案件，亦可參考台北市的[營業場所全面預先審查FAQ](https://www.gov.taipei/News_Content.aspx?n=EEC70A4186D4C828&s=E70ACC80BEEC5910&sms=87415A8B9CE81B16)。

## 2. 辦理營業場所預先查詢需要哪些建物資料？

依台北市現行制度，原則上應提出申請日前三個月內核發的建物登記謄本（含第二類）或建物所有權狀，以便確認地址、樓層、面積等資訊。建物用途屬「以住宅為主兼作辦公室」等情形時，可能另需切結書、土地使用分區證明等補充資料，請依物件與用途確認最新應備文件。

首先，不只看租賃契約或廣告上的地址，還要核對建物登記資料上的正式地址、棟、樓層、面積及用途。同一建物若樓層或使用範圍不同，可能影響判斷，因此「整棟建物看起來可以使用」的判斷並不足夠。預定營業項目也應對照登記所用名稱準備。

建物登記謄本可透過台北市各地政事務所或便民工作站等窗口、政府的電子謄本系統，以及其他現行官方管道申請。取得方式可能因申請人資格、所需謄本種類及線上身分驗證方式而異。無須一律透過特定熟人或律師辦理，請先向官方窗口或透過官方線上服務確認使用條件。

建物用途為「以住宅為主兼作辦公室」的案件，會涉及實際使用比例的切結書——住宅使用部分超過總面積五分之三、辦公室使用部分未達五分之二——以及土地使用分區證明等補充資料。重要的不只是書面表述，實際使用狀況須與申報內容一致。所需資料會因物件區分、用途、面積或申請內容而改變，請配合查詢系統的最新注意事項。

資料過舊、地址或樓層不一致、無法確認圖面或面積、補充資料不足等情形，都需要補正，並影響預定時程。在確定租賃契約前先取得資料、確認候選物件與營業項目的組合，日後若需變更地點，也較能降低負擔。

## 3. 租賃地址、借址登記或虛擬辦公室可以作為公司地址嗎？

不能僅憑名稱一概判斷可否使用。應以租賃契約書、所有權人同意及所有權資料等證明使用該地址的權限，並確保實際上能收受官方通知，再確認台北市營業場所預先查詢及實際使用狀況的相關規範。登記地址與實際營業場所不同時，實際場所仍須另行符合土地使用、建築、消防、衛生及其他要件。

經濟部關於有限公司設立登記的文件說明中，列有租賃契約書影本，或所有權人使用同意書及所有權證明資料等，作為證明所在地使用權限的資料。具體組合請確認[經濟部有限公司設立登記文件一覽](https://gcis.nat.gov.tw/F/t70044_p)與受理機關的現行說明。

這些資料證明的核心事項，是使用該地址作為公司所在地的權限。所有權人同意或訂有租賃契約，不代表已確認該場所對任何營業項目在土地使用分區、建築、消防或衛生上均屬合法。反之，僅以「借址登記」或「虛擬辦公室」的服務名稱為由，即認定一律不得使用，同樣不適當。

簽約前，至少應具體確認下列事項。

- 契約當事人或同意人是否有權讓他人使用該物件。
- 登記所用地址、樓層、室及使用範圍，是否與建物資料一致。
- 能否確實收受寄給公司的行政文書及其他官方通知，並做必要處理。
- 能否就預定營業項目取得營業場所預先查詢的符合結果。
- 若在登記地址以外的地點實際營業，是否已就該實際地點完成必要確認。

例如，以登記地址作為事務聯絡據點，而在另一處廚房或店面調理、販售食品時，店面方面的土地使用、建築、消防、衛生、食品業者登錄及行業別許可，均為獨立的問題。僅備齊登記地址的相關資料，並不代表已滿足另一實際營業場所的要件。

## 4. 預先查詢結果符合規定，就可以立即在該處營業嗎？

不是。預先查詢是確認營業場所與營業項目是否符合土地使用分區及建築管理規定的程序，不代表出租人權限、租賃條件、消防、衛生、環境、招牌、食品業者登錄、行業別許可及其他要件均已獲核准。請確認從公司及商業登記到開始營業之間仍須另行辦理的程序。

查詢結果符合規定固然重要，但確認範圍有其限度。查詢結果是就所確認的地址與所申請營業項目的組合，確認其與土地使用分區及建築管理規定的符合性，並非全面核准租賃契約的效力、出租人權限、設備工程、消防安全設備、排煙排水、廢棄物、噪音、招牌設置或個別行業法上資格的證明文件。

以餐廳為例，除公司及商業登記外，還須確認依店面實際使用狀況所需的消防、建築準備、食品衛生管理、食品業者登錄、從業人員與設備相關要件、營業型態別許可等。關於食品業者登錄的對象與程序，請參考衛生福利部食品藥物管理署的[食品業者登錄相關公告](https://www.fda.gov.tw/tc/newsContent.aspx?id=11672)等官方資料，並以開始營業時的最新說明為準。

此外，查詢後若地址、使用樓層、使用範圍、營業項目或建物狀態有所變更，未必能沿用已取得的結果。應使申請內容與實際使用一致，發生變更時，向台北市及相關主管機關確認是否需要重新查詢或辦理其他程序。

預先查詢、公司及商業登記、稅籍相關程序、行業別許可、裝修與消防、衛生準備，各有不同的目的和審查範圍。請一併參考[台灣投資及公司設立服務](/zh-hant/services#investment)與[台灣公司設立進階篇1](/zh-hant/columns/taiwan-company-establishment-advanced-1)，將物件簽約至開始營業的流程分階段整理。

## 5. 預先查詢的處理時間與結果有效期間是多久？

台北市行政作業基準設有一般案件5日（曆日）、需函詢外部機關案件11日（曆日）的處理目標，但可能因補正、申請件數及其他情事而變動，並非完成日期的保證。依現行查詢系統說明，查詢結果自審查完成日起六個月內有效，逾期需重新申請。

[台北市現行行政作業基準](https://laws.gov.taipei/Law/SOPSearch/DownloadFile?sop_no=P04020118.pdf)所記載的5日與11日，均非工作日，而是以曆日計算的行政處理目標。實際天數可能因申請文件的補正、其他機關的回覆、案件數量、物件或營業項目的複雜程度而變動。請勿僅依賴這些天數來確定租賃契約起始日、裝修工程、公司設立或開店日。

查詢結果六個月的有效期間，以審查完成日為起算點確認。為使公司及商業登記申請時能檢附有效的符合結果，應安排物件選定、簽約、查詢、登記及營業準備的順序。若已逾有效期間或查詢內容有變更，請勿以舊結果續行，應確認是否需要重新申請。

營業場所對公司設立後的事業營運與成本影響重大。在決定候選物件的階段，逐一確認正確的地址、樓層、面積、建物資料、營業項目、契約上的使用權限、實際使用方式及行業別要件，十分重要。如需整理個別案件，歡迎使用[聯絡我們](/zh-hant/contact)。

本文僅提供一般性制度資訊，非針對個別案件的法律意見。制度、申請格式、應備文件及審查實務可能變更，請確認申請時點的官方資訊與受理機關的說明。
