2. 「簽約時可直接列出這些預定用途…檔案和權限。」 삭제 시 제목의 문제제기에서 법률 설명으로만 넘어가 실무 행동이 사라져 유지.
3. 「對受著作權保護、且非屬受雇人職務著作…出資目的範圍內利用。」 삭제 시 계약을 쓰지 않았을 때의 기본값과 적용조건이 누락되어 유지. 제11조 제외조건과 저작재산권/저작인 기본값을 명시하도록 다듬음.
4. 「這項規則無法替開發商取得第三方模型的權利…都有著作權。」 삭제 시 §12만으로 모든 모델·데이터 소유 문제를 해결할 수 있다고 읽힐 위험이 있어 유지. 기존 255와 구분하는 핵심 범위이기도 함.

### 05

1. 「原本用來偵測危險區域闖入…重新確認資料用途。」 삭제 시 단순한 개인정보 정의 강의로 시작하므로 유지.
2. 「即使影像已刪除姓名…仍可能是個人資料。」 삭제 시 익명화 오해와 의무가 시작되는 식별 기준을 놓치므로 유지.
3. 「工廠可先沿著資料流向盤點…送往外部平台。」 삭제 시 목적 전환을 확인하기 위한 실제 조사범위가 없어져 유지.
4. 개정 중 있던 「只拍晶圓且無法識別自然人的資料…法律判斷不同。」는 앞 문장의 식별 기준과 반복되고 결론도 추상적이므로 실제 삭제.
