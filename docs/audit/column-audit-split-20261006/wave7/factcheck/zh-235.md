## 기록만 (비집계, 경미·저위험)
- L27 가상 예시(車手가 80만 수령 → 상부 상납 → "留在車手身上"인 3천 원만 자기 犯罪所得): 大法庭 재정은 個人所得을 「包含因詐欺犯罪而取得之被害人財物，及為了犯罪而取得之報酬在內」로 정의. 상납한 수령액이 '실제 취득'에서 빠진다는 판단은 이 재정이 직접 하지 않은 적용 문제이나, 칼럼 문장이 「留在車手身上、算得上「他的」犯罪所得的」로 한정하고 가상 예시임을 밝히고 있어 오류로 집계하지 않음.
- L43 「被告的行為在2026年1月23日之前或之後，決定了他依第47條減刑前要不要先付清和解的錢」: 1월 23일 이후 행위는 신법, 이전 행위는 원칙적으로 구법(신법이 더 유리하면 신법) — 바로 뒤 문장과 FAQ가 「可能」 한정을 두고 있어 문맥상 정확. 필요하면 「之前的行為原則上適用舊條文」 정도로 한 구절만 보강 가능(선택).
- 詐欺條例 §50② (2026-01 개정 대상): 「犯詐欺犯罪後，犯罪行為人於賠償被害人所受全部損害或支付與被害人達成調解或和解之全部金額前，法院尤應注意…(逾越一般人通常生活程度之…消費·投資·贈與)」 — 칼럼은 量刑 일반 규정(刑法 §57)만 언급. 누락일 뿐 오류 아님(독자 손해 가능성 낮음). 제47조 외 피해 회복 유인 조항으로 보강 후보(선택).
