# 078 버스 급정거 칼럼 통합

주소: `/zh-hant/columns/taiwan-bus-sudden-braking-passenger-carrier-liability`.

검수된 번체 원고를 게시 스키마에 맞춰 등록했다. 원고의 H1/frontmatter를 사이트 제목·작성자 필드로 옮겼으며 실질 본문은 바꾸지 않았다. 원고 전체 SHA-256은 `2832f42bdda39663ddbdbbbf02598107dc908f7b1d8c278ba38a9772b194f5df`, 본문은 `81e886ba703720642855fc778e36bb150103806445c253eccd0cfa543b72651d`다. 사진·4개 영상·포스터/단계 PNG10개·VTT 총16개 파일도 인계 원본 바이트를 유지한다.

`traffic-accidents`, `traffic-liability` 태그로 기존 교통사고 게시판에 자동 포함된다. 번체11편/한국어4편/영어4편/일본어3편이며 기존 글 URL이나 번역은 복제·변경하지 않는다. 버스 운송계약과 운전자 과실의 구별이 글의 중심이므로 책임 분류를 사용했다.

## 검수 근거

- 작성자의 최종 인계문과 manifest595개, 제작자 manifest56개, ZIP57항목 CRC/SHA를 직접 확인했다. 최초 GPT-6 Astra 작성 기록과 기존 Claude Max 구독의 실제 `claude-opus-5-5` 결과를 확인했다. 최종 교차검수는 원고·사진1장·영상 실제 정지 프레임9장 및 설명문 조합 PASS, 필수0·비차단9개 제안이다. 비차단 제안은 작성자의 처리 이유대로 유지했다.
- 게시 전 공식 판결 PDF, 민법654/227-1/217/193/195/197과 공식 심급응답 총8건을 다시 받았다. 판결/심급은 바이트 동일,6개 법령은 조문 내용 동일. 법령 사이트 정비 기준은2026-09-24. 확정·상소 여부는 확인되지 않았다.
- 제목·요약·사진 alt/caption·AI 저자 표시·공식 출처·원고 한계를 유지했다. 영상은 승용차 개념 예시로 판결의 오토바이나 도로 재현이 아니고, 전방 기울임과 회복만 나타낸다. 실제 넘어짐·부상 또는 책임을 입증하는 영상이라고 쓰지 않는다.
- 최종 caption/long-description을 접근 가능한 텍스트로 표시하고 네 단계 정지 이미지를 제공한다. 원본 VTT는 공개 보조 자산으로 보존하지만 현재 공용 수동 플레이어의 선택형 자막 트랙으로 연결하지 않았다. 필수 설명은 페이지에 모두 있다.
- PNG 포스터를 그대로 사용하므로 수동 플레이어의 잘못 고정된 WebP MIME 힌트를 제거했다. 기존 WebP도 파일에 맞게 브라우저가 판별한다. 원본3D 포스터는816,225/1,201,828bytes로 기존 간단 도해보다 크다. 재인코딩·다른 그림으로 바꾸지 않았다.
