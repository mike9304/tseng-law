# 고속도로 급정지·화장품 자료 확인 영상 검수

번체중문 098번 고속도로 진로 방해 칼럼 1페이지와 011번 화장품 시장 진입 칼럼 49언어 페이지에 두 장면을 연결한다. 서로 다른 새 영상은 두 편이며, 화장품 영상의 한국어·영어·일본어·번체중문 AI 표시를 포함해 배포 파일은 다섯 개다. 나머지 45언어는 영어 표시 영상과 각 언어의 제목·설명·AI 고지를 사용한다. 기존 법률 본문·출처·날짜·이미지는 수정하지 않았다.

## 생성과 동작

Codex가 만든 시작·종료 이미지를 Grok 4.7 `reference_to_video`에 전달했다. 두 영상 모두 무음 H.264 1280×720이며, 원본 24fps와 재생 길이를 보존했다. 배속 조정은 하지 않았다.

- `motorway-brake-v2`: 4.041667초, 97프레임. 차선 진입 뒤 멀어진 채 주행하는 느낌이 남은 v1은 게시하지 않았다. 종료 이미지를 가까운 정지 장면으로 수정한 v2에서는 첫 1초 동안 앞차와의 거리가 빠르게 줄어든다. 약 0.625초에 브레이크등이 켜지고 약 1.33초부터 가까운 정지 상태가 유지된다. 충돌·손상·추가 차량은 없다. 초반 왼쪽 차선 텍스처가 잠시 불안정한 점은 기록했다. 도로 형태나 실제 간격을 입증하는 자료로 쓰지 않는다.
- `cosmetics-check-v1`: 6.041667초, 145프레임. 손이 뚜껑이 닫힌 용기를 들어 펼친 서류철 위로 옮기고 라벨 쪽을 돌려 본다. 뚜껑을 열거나 서명·날인하지 않는다. 종이는 읽을 수 없는 가상 자료이며 실제 제품등록이나 PIF 완비를 나타내지 않는다.

원본 전체 242프레임을 17개 시트로 직접 확인했다. AI 표시를 넣은 파일 다섯 개의 첫 화면과 동작 화면도 직접 읽었고 전체 디코딩을 통과했다. AI 표시가 앞차·브레이크등이나 손·용기를 가리지 않는다.

## 문구와 본문 적합성

고속도로 원문은 야간의 반복적인 진로 방해 사건이다. 영상은 별도의 낮 시간 가상 장면에서 한 차례 끼어들기·제동만 보여준다. 반복 행위, 다른 교통, 고의·형사책임을 재현하거나 입증하지 않는다고 고지한다. 화장품 영상도 제품등록, PIF 완비, 안전성, 판매 허가를 증명하지 않는다고 각 언어로 표시한다.

| 검토 표현 | 문제와 이유 | 최종 문구 및 의미 보존 |
|---|---|---|
| 國道攔車犯罪重現 | 실제 사건 재현과 범죄 성립을 단정한다. | `前車切入後煞車，後車近距離停住`로 보이는 차선 진입·제동·정지만 설명한다. |
| PIF 검토와 제품등록 완료 | 용기와 서류를 보는 동작만으로 서류 완비·등록 완료를 알 수 없다. | `서류 위에서 화장품 용기를 살펴보는 장면`으로 제품·서류의 맥락을 유지한다. |

첫 설명을 삭제하면 구체적인 동작·길이·무음 정보가 사라지고, AI 고지를 삭제하면 실제 사건·자료와 가상 장면의 구분 및 영상의 한계가 없어진다. 범용 도입·상담 홍보·장식용 굵은 강조를 넣지 않았다.

기본 네 언어의 화장품 본문과 고속도로 번체중문 본문 다섯 개는 전문을 읽었다. 나머지 45개 화장품 번역문은 제목·첫 두 문단·초기 소제목을 읽어 장면과 설명의 적합성을 검토했다. 언어별 최근 글 세 개의 비교 근거를 남겼으며, 과거 직접 읽은 135개 발췌는 해시가 같은 경우만 재사용했다. 기본 네 언어의 최근 글 12개는 제목·첫 두 문단·소제목·끝 두 문단을 직접 확인했다. 작업 중 새 글이 등장한 여섯 항목도 교체해 읽었다. 원어민 감수나 법률 전문가 검수를 주장하지 않는다.

## 검증과 게시 판정

관련 단위 테스트 406개(26파일), 변경 TS/TSX의 ESLint, 브라우저 QA 문법 검사와 새 production 빌드가 통과했다. 빌드의 기존 `ContactEditorial.module.css` 경고는 이번 변경과 무관하다. 영상의 출처·언어가 다른 칼럼으로 잘못 연결되지 않는지와 고속도로 칼럼의 영상 목록 포함 여부를 확인했다.

로컬의 390px와 1440px에서 100개 재생 경로가 통과했다. 공개 사이트에서도 같은 경로를 검사한다. 원래 1배속 전체 재생, 정지·탐색, 설명·RTL 표시, 영상 목록, Range 206과 파일 해시를 대조한다. 일반 설정의 교통 영상 자동 재생과 수동 정지 유지, 화장품 영상의 수동 재생은 별도 네 경로로 검사한다. 로컬 모바일 화면 50개·대표 PC 화면 19개와 한국어 전체 화면 두 개를 직접 확인했다. 초기 전체 화면의 기존 언어 제안 알림은 닫을 수 있으며, 알림을 닫은 영상 figure에서 캡션 전체를 읽었다. 공개 화면도 동일 범위로 확인한다. 물리적 iOS 기기 검수를 주장하지 않는다.

공개 재생과 배포 파일 검증 전에는 완료 수에 추가하지 않는다. 상세 근거는 `qa/motorway-cosmetics-*.json`, 공개 확정 기록은 `qa/production-motorway-cosmetics-release.json`이다. YouTube 업로드는 하지 않는다.
