variety used: standard Slovene (slovenščina), formal *vi*, consistent; no Croatian/Serbian spelling except the single word *masažist* in 006. Typography is right where it was checked in earlier rounds: running quotes are Slovene guillemets »…«, the decimal separator is a comma (`0,5 meseca`, `1,57`), the thousands separator is a dot (`500.000`, `3.200.000`) — which is the correct Slovene convention, so r4's row 31 should not be re-actioned — percentages take a space (`5 %`, `21 %`), and dates are Slovene (`13. septembra 2025`, `27. 12. 2023`, `25. 7. 2026`). systemic patterns (max 6, each one line, with 1 example quote):
- *Ter* is used as the default "and" in plain two-item lists (003 106× vs 16 *in*, 004 137×, 007 209×, 005 11× vs 1, 008 18× vs 2): "kot so britje ter nega obraza"

- *Treba* drops out after a fronted infinitive, in three files: "Preveriti je tudi, ali se prevod"
- Statute citations mix Slovene "99. člen" with the English-order "člen 371"/"Člen 9" inside one file (002 6:2, 004 17:3, 007 9:33): "Po členu 371 zakona o družbah"
- Non-words and doubled words survive four rounds of review: "smejo biti trjena ter dokazovana", "narislati", "nositve stroškov", "ali ali"
