# connectors — en 136 새로 쓴 문장 (전부)

새 법률 주장 없음. 아래 4건이 전부이고 모두 원문 사실의 재배열·압축이다. 판결 링크 치환은 해당 없음(이 글에 판결 인용 없음) → 치환 0건.

1. §What Taiwan has announced, L39 대체 문단 (원문 L39의 누계 서술을 대체)
   `The list changes in both directions. The ITA’s [April 1, 2026 update](…pid=813420) and the MOEA’s [June 9, 2026 update](…news_id=122960) each removed names as well as adding them, so a screening record should name the version of the list it was run against.`
   재료: 원문 "Updates in 2026 have both added and removed names." / "Because names come off as well as go on, a screening record is only as good as the list version it names." / 4월 "removed 8", 6월 "13 removed"(숫자 없이 사실만). 리드 지시문("the list changes in both directions, so record which version of the list you screened against")의 평서문화. 링크 문구 "announced on April 1, 2026" → "April 1, 2026 update"(링크 URL 동일). 데이터셋 문장은 원문 그대로.

2. §The U.S. rules, 합친 문단 안 (테스트 정의 2문장을 대체)
   `…the rule has a product test, which looks at the item, and an end-user test, which looks at whether a footnote 1 entity is involved.`
   재료: 원문 L89 "has a product test and an end-user test" + 두 테스트 정의(제품 범위 / footnote 1 entity가 구매자·최종수하인 등 거래 당사자). 정의를 지운 뒤 L93·L95의 "product test / end-user test / footnoted entity is involved"가 읽히도록 붙인 한 절. 조문 문구를 해석한 것이 아니라 두 테스트의 대상(물품 / 관여 entity)만 말한다.

3. §The U.S. rules, 합친 문단 안 (연결·재배열, 단어 새로 들어감 거의 없음)
   - `The same rule added 68 non-U.S. affiliates in 26 destinations, Taiwan among them.` ← 원문 "and it added 68 non-U.S. affiliates in 26 destinations, Taiwan among them"(주어 "The listing"→"The same rule").
   - `The [December 2024 Entity List rule](…) (89 FR 96830) added the footnote 5 designation to SMIC’s entry, and the referenced EAR provisions came from the [December 2, 2024 interim final rule](…) (89 FR 96790), which created new FDP rules for certain semiconductor manufacturing equipment and added controls on high-bandwidth memory.` ← 원문 두 문장 + "That rule created…" 문장을 한 문장으로 합침(새 사실 없음).

4. §The U.S. rules, 벌칙 한 문장 (원문 L97 대체)
   `Violations of the Export Control Reform Act carry criminal and civil penalties; for willful violations, the criminal maximum is a fine of up to US$1 million and, for individuals, imprisonment of up to 20 years ([50 U.S.C. 4819](…)).`
   재료: 원문 "The penalties under the Export Control Reform Act are set out at 50 U.S.C. 4819. For willful violations, the criminal maximum is a fine of up to US$1 million and, for individuals, imprisonment of up to 20 years. The civil maximum per violation is …". "criminal and civil penalties"는 원문의 형사 상한·민사 상한 두 문장이 존재함을 한 어구로 요약.
