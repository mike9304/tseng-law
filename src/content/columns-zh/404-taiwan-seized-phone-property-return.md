# 手機被扣押後，案件還沒結束能聲請發還嗎？

手機被扣押，工作與聯絡都受影響，是否得等到結案？[刑事訴訟法第142條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0010001&flno=142)規定，扣押物若無留存必要，不待案件終結，應以法院裁定或檢察官命令發還。重點是留存必要性。

## 先從扣押收據辨認物品

扣押時應製作收據，詳記物品名目，交給所有人、持有人或保管人，這是[第139條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0010001&flno=139)的要求。型號對嗎？多支手機一起被扣押時，型號、識別號碼等資料可用來確認請求的標的。

能證明手機是自己的，還不代表應立即取回。[第133條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0010001&flno=133)允許扣押可作為證據或得沒收的物品，另有保全追徵的財產扣押規定。工作上需要手機，不會自行消除這些目的。

提出發還請求時，可寫明物品、自己是所有人或其他何種身分，以及認為沒有繼續留存必要的理由。如果有出境安排，也一併說明。機票本身不會讓機關必須放行扣押物。

## 暫行發還，要負保管責任

第142條第2項另有暫行發還的方式：因所有人、持有人或保管人的請求，得命其負保管責任，將物品暫時交還。是否准許仍須判斷。取得物品時，也要讀清楚保管條件，避免誤以為已可任意處置。

急著使用手機，與只需要其中幾份檔案，可以分開說明。同條第3項規定，有正當理由的所有人、持有人或保管人，在審判中得預納費用，請求扣押物的影本。這不是偵查中任何人都能取得整支手機資料的承諾。

## 不服檢察官的處分，向法院聲請

受檢察官扣押或扣押物發還處分的人，可依[第416條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0010001&flno=416)，向檢察官所屬法院聲請撤銷或變更。本段討論檢察官處分。警察措施或法院裁定，須先看作成機關及文書性質，不能把救濟方式混用。

期間只有10日。第416條區分自處分日起算，以及以送達方式為之時自送達後起算；[第417條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0010001&flno=417)則要求以書狀敘述理由，向該管法院提出。一直打電話請求歸還，不表示這項期間會停止。

收到不准發還的書面時，將全文、收件紀錄與扣押收據放在一起。物品是什麼、處分是誰作成、何時送達，會影響接下來能採取的程序。
