# WO-M8-COLUMNS-TEXT — /ar/columns 안내 문장을 "아랍어 기사 있음" 상태로 (Opus 5, 소형)
## 공통 규칙
작업트리 ~/Projects/tseng-law-mena-20260916 만. 허용 파일: src/data/international-guidance-content.ts(ar.pages.columns·home 칼럼 관련 문장만), src/lib/__tests__/guidance-ar-content.test.ts. 커밋·build·전체 스위트 금지. 언어 계약·광고 규정 동일. 새 법률 주장 0.
## 배경
R1(927e28cb)에서 columns-ar 부재를 이유로 ar columns 페이지 description/intro/paragraph를 "이 페이지에는 아직 아랍어 기사가 없다"로 정정했음. 이제 src/content/columns-ar/ 에 5편이 있고 /ar/columns 에 렌더됨(나머지 12편은 원문 언어 링크). vi 원문(583·585·591행 부근) 구조 = "아랍어(현지어)로 제공되는 글은 이 페이지에 직접 실리고, 그 외 글은 원문 언어 링크" 형태.
## 목표
1. ar.pages.columns.description·intro·sections[0].paragraphs[1]을 vi 원문 구조로 되돌리되 사실에 맞게: "일부 글은 아랍어로 이 페이지에 실리며, 나머지는 원문 언어(영어·중국어·일본어·한국어 등) 링크로 열린다. 아랍어판은 준비되는 대로 추가된다." 의미(MSA, 시점·개수 약속 없음).
2. 홈의 칼럼 안내 배지 문장(2158행 부근 "아래 기사는 아랍어판이 없다…")이 현재 상태와 맞는지 확인 — 5편이 ar로 존재하므로 "일부는 아랍어판이 있고, 없는 글은 원문 언어로 열린다" 의미로 조정.
3. 테스트 guidance-ar-content.test.ts의 "never says Arabic articles are listed" 케이스를 반대로: 아랍어 기사 존재를 단정 부정하는 문구(ليست في هذه الصفحة مقالات بالعربية / لا تضمّ … بعد) 0, 그리고 "원문 언어 링크" 의미 문구 존재.
