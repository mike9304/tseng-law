# B7 FA — root 직접 집필, 독립 선택 제안 반영

독립 R1 필수0·선택5 중 S01–S05 전부 채택했다. Root가918/919/921 세 원고의 정확히 다섯 문자열을 직접 수정했다. 초기 저자 보고서, manifest, 최종 배열과 독립 R1은 그대로 보존했고, 수정 직전 원고6·저자 기록은 `checks/fa-before-independent-suggestions/`에도 바이트 단위로 남겼다.

변경3편에만 실제 공유 검사와 구조 검사를 실행했다. shared exit0/FAIL0, 구조 selected3/errors0. 현재918은39분절/CV .488,919는40/.451,921은41/.453이다. 그 외915·916·920은 현재 SHA와 도구가 동일한 기존 실제 통과 행을 재사용한다. 이전 전체 실행 exit1 이력은 지우지 않았으며 이번 전체6편을 새로 실행했다고 하지 않는다.

Root가 실제 출력에서 변경된 세 본문 문단·제목·소제목을 읽었다. 918 날짜/설치 상태,919 사건번호와 징계/상소 한계,921 보관·제공 기한의 문장 경계가 정상이다. 최종 전체는247분절·FAQ17로 유지된다. §5의 기존 전체 점검에서 변화하는 것은919소제목 질문 반복 완화와 해당 문장 길이뿐이다. 도입 유형·문단 시작·인용 배치·결말·법적 조건은 그대로이며 새 단조로움 반려 사유를 발견하지 못했다.

`fa-independent-suggestions-edits.json`의 정·역치환으로 수정 전3개 SHA를 정확히 복원했다. 나머지3 전체 SHA 불변,FAQ17 원문과 링크 값·순서 불변,921 title 외 frontmatter 전체 불변을 확인했다. 실제 수정과 증거는 `fa-author-final-manifest.json` 및 `fa-final-boundaries-after-independent.json`에 연결한다. 이 기록은 저자 후속 확인이며 독립 R2·화면 RTL·통합·배포 완료를 대신하지 않는다.
