## Verdict
naturalness (1 = machine, 5 = native professional): 4/5 for guidance pack, 3/5 for columns
variety used: Khalkha Mongolian in Cyrillic, consistent. Polite address is Та/та. Running dates use YYYY.MM.DD (`2025.09.13`, `2023.12.27`, `2026.05.29`), which is the ordinary Mongolian numeric date; do not convert them to day-month-year. Thousands still use a comma (`500,000`, `3,000,000`) and `0.5` uses a point; Mongolian uses a space and a decimal comma.
systemic patterns (max 6, each one line, with 1 example quote):
