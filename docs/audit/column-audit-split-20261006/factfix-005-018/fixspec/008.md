# fixspec 008 taiwan-labor-severance-law (리드 원문 확인 2026-10-06 21:0x, law.moj.gov.tw)

적용 언어: ko·en·zh-hant = 1~8 전부(변호사 명의 옛 번역본). ja = ja-plan 재작성본이라 1·3·4·5·6·7은 이미 반영됨 → 2(F-017-2)만, 그리고 FAQ2의 "労工退休金の個人口座" 문장을 2의 범위로 한정.

1. F-017-1 근로자가 제14조 사유로 계약을 끝내면 資遣費를 받는다(자발적 퇴사 = 0 단정 금지).
   원문: 勞基法 §14① 「有下列情形之一者，勞工得不經預告終止契約：…五、雇主不依勞動契約給付工作報酬…六、雇主違反勞動契約或勞工法令，致有損害勞工權益之虞者。」 §14④ 「第十七條規定於本條終止契約準用之。」
   URL https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0030001&flno=14
   적용: FAQ1 답과 본문 "직원이 자발적으로 퇴사하는 경우 회사는 퇴직금을 지급할 필요가 없다" 문장에 단서 1개 — "다만 회사가 임금을 지급하지 않거나 노동법령을 위반하는 등 근로기준법 제14조의 사유가 있어 직원이 이를 이유로 계약을 끝내면, 회사는 퇴직금(資遣費)을 지급해야 합니다." 같은 언어의 009(taiwan-voluntary-resignation-severance)로 링크 1개(본문 단서 문장에만, `/{locale}/columns/taiwan-voluntary-resignation-severance`). 표의 "직원 자발적인 사임" 열 "필요 없음"은 그대로 두되 그 칸 끝에 "(제14조 사유로 종료하는 경우 제외)" 괄호 1개.

2. F-017-2 노동자퇴직금조례(勞工退休金條例)의 0.5개월·6개월 상한 산식은 이 조례 적용 대상 근로자에게만 해당한다. 적용 대상은 대만 국적 근로자, 대만 국민(호적 있음)과 혼인해 거류 허가를 받은 외국인, 영주 허가를 받은 외국인 등이다(제7조 제1항). 그 밖의 외국인 근로자(일반 취업 허가)의 근속기간에는 근로기준법 제17조(1년당 평균임금 1개월분, 상한 없음)가 적용된다.
   원문: 勞退條例 §7① 「本條例之適用對象為適用勞動基準法之下列人員…：一、本國籍勞工。二、與在中華民國境內設有戶籍之國民結婚，且獲准居留而在臺灣地區工作之外國人、大陸地區人民、香港或澳門居民。三、…離婚或其配偶死亡，而依法規規定得在臺灣地區繼續居留工作者。四、前二款以外之外國人，經依入出國及移民法相關規定許可永久居留，且在臺灣地區工作者。」 §12① 「勞工適用本條例之退休金制度者，適用本條例後之工作年資，…其資遣費由雇主按其工作年資，每滿一年發給二分之一個月之平均工資，未滿一年者，以比例計給；最高以發給六個月平均工資為限，不適用勞動基準法第十七條之規定。」
   URL https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0030020&flno=7
   적용: FAQ3 답과 본문 인용 블록의 "이 산식은 노동자퇴직금조례 제12조가 적용되는 근속기간에 대한 것이며" 뒤에 1문장 — "이 조례는 대만 국적 근로자, 대만 국민과 혼인해 거류 허가를 받은 외국인, 영주 허가를 받은 외국인 등에게 적용되므로(제7조 제1항), 그 밖의 외국인 근로자의 근속기간은 근로기준법 제17조로 계산합니다." ja: §56 문단 끝과 FAQ3에 같은 1문장. ja FAQ2 "毎月積み立てられている労工退休金の個人口座は、解雇の種類に関係なく労働者のものです" → "勞工退休金條例が適用される労働者の場合、毎月積み立てられている個人口座の退休金は、解雇の種類に関係なく労働者のものです" 정도로 대상 한정.

3. F-017-3 징계해고 30일 기한: 勞基法 §12② 「雇主依前項第一款、第二款及第四款至第六款規定終止契約者，應自知悉其情形之日起，三十日內為之。」
   URL https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0030001&flno=12
   적용: 본문 "회사는 직원에게 퇴직금을 지급하지 않아도 해고할 수 있습니다" 문장 뒤 1문장 — "다만 제3호(유기징역 확정)를 뺀 사유로 해고할 때는 회사가 그 사정을 안 날부터 30일 안에 해야 합니다(근로기준법 제12조 제2항)."

4. F-017-4 징계해고 사유의 규칙 위반은 "情節重大"(중대한 경우)만: §12①4 「違反勞動契約或工作規則，情節重大者。」
   적용: 본문 "회사 규칙을 위반하거나" → "근로계약이나 회사 규칙을 중대하게 위반하거나", FAQ2 답 "회사 규칙 위반" → "근로계약·회사 규칙의 중대한 위반", "3일 연속 무단결근" 뒤에 "(또는 한 달에 6일)" (§12①6 「無正當理由繼續曠工三日，或一個月內曠工達六日者」). 표의 제12조 번역(4·6호)은 이미 맞으므로 그대로.

5. F-017-5 제11조 제4·5호 번역: 「四、業務性質變更，有減少勞工之必要，又無適當工作可供安置時。五、勞工對於所擔任之工作確不能勝任時。」
   URL https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0030001&flno=11
   적용: 표 안 제11조 번역 4호 → "업무의 성질이 변경되어 근로자를 줄일 필요가 있고, 배치할 적당한 업무도 없는 경우", 5호 → "근로자가 맡은 업무를 확실히 감당할 수 없는 경우". 8. F-017-8 용어: 글이 "퇴직금"이라 부르는 것은 資遣費다. 대만에도 퇴직(退休) 급여 제도는 따로 있다(勞退條例 §6① 「雇主應為適用本條例之勞工，按月提繳退休金，儲存於勞保局設立之勞工退休金個人專戶。」, 勞基法 §53·§55 구제도).
   URL https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0030020&flno=6
   적용: "직원이 자발적으로 퇴사하는 경우…" 단락 바로 뒤(F-017-1 단서 다음)에 1문장만 — "여기서 말하는 퇴직금은 계약 종료 때 받는 資遣費이며, 퇴직(退休) 후를 위한 退休金 제도는 이와 별도로 정해져 있습니다." 세부(6% 등)는 넣지 않는다. en: "severance pay" 용어를 이미 쓰면 해당 없음 처리하고, "pension"과 혼동되는 문장이 있을 때만 같은 취지 1문장. zh: 이미 「資遣費」로만 쓰면 해당 없음.
