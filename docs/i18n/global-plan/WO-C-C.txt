## 2. 제품 잠금 (세 언어 공통)
- 이 세 언어는 **안내 로케일**이다. 상담 언어는 영어·중국어(中文)·일본어·한국어 넷뿐이다.
  해당 언어로 상담·통역·즉시응답·성공률·비용/결과 보장·24/7·무료 상담을 **암시조차 하지 말 것**.
  (pl·hi·sv 모두 상담 언어가 아니다. 해당 언어로 상담 가능하다는 인상을 주지 말 것.)
- 대만 변호사 광고규정: 승소율·보장·최고/유일 표현 금지.
- 새 법률 주장 금지. 원본에 없는 수치·기관명·절차를 만들지 말 것.
- `[변호사 검수 필요]` 마커가 산출물에 남으면 안 된다(0건).
- 대만 법률 용어는 선례대로 **원문 한자를 괄호로 병기**한다. 예: 工作許可, 外僑居留證, 資遣費, 勞動契約.
  hi는 데바나가리 문자다. 한자 용어는 번체 그대로 괄호 병기하고 데바나가리로 음역하지 말 것.

## 3. 형식 패리티 (체커가 검사한다)
- frontmatter 키 집합과 순서는 원본과 같게. `title` `url` `lastmod` `date_display` `read_time`
  `categories` `featured_image` `faq`.
  - `url` `lastmod` `featured_image` 는 **원본 값 그대로**. 바꾸지 말 것.
  - `date_display` `read_time` 은 해당 언어 표기로 옮긴다.
  - `categories` 는 해당 언어로 옮기되 개수는 원본과 같게.
  - `faq` 항목 수는 원본과 **정확히 같게**. q/a 모두 번역한다.
- 본문 블록 수(문단·제목·이미지·목록)와 순서가 원본과 일치해야 한다. 합치거나 쪼개지 말 것.
- 이미지 경로는 원본 그대로. 대체 텍스트만 번역한다.
- 링크: 내부 링크는 원본 그대로 두는 것이 기본이다. `/ko/columns` `/ko/contact` `/ko/services`
  `/ko/faq` `/ko/pricing` 만 해당 언어 접두사로 바꾼다. `/ko/services/investment` 같은 상세 경로는 그대로.
- **숫자는 아라비아 숫자로**. 원본의 숫자 개수와 목표의 숫자 개수가 같아야 한다.
  숫자를 낱말로 풀어 쓰지 말 것(예: "세 가지" → "3"). 천단위 구분은 언어 관례를 따르되
  원본의 값 자체를 바꾸지 말 것. 통화 기호와 단위(TWD, USD, 新臺幣)는 원본대로.
- 한글이 남아 있으면 안 된다. 영어 단어가 과도하게 남아 있어도 안 된다(고유명사·기관 영문명은 예외).
