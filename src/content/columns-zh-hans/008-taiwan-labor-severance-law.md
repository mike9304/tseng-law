# 台湾劳动法：在台湾领取资遣费真的很难吗？

![主图](../images/008-taiwan-labor-severance-law/featured-01.jpg)

您好，我是台湾律师曾雋崴。

今天想与您谈谈台湾的资遣费。

![](../images/008-taiwan-labor-severance-law/img-01.jpg)

许多人已经知道。

在韩国，受雇人离开企业时，公司须给付离职金

但在台湾则与韩国不同：

仅在公司资遣受雇人时，才发生给付资遣费的义务。

若受雇人自行辞职，公司无须给付资遣费。

​

但若受雇人有不法行为，

**违反工作规则，**

**或无正当理由连续3日不到班（旷工），**

公司得解雇且无须给付资遣费。

​

我用一张简单表格为您整理。

|  |  |  |  |
| --- | --- | --- | --- |
| **类型** | **经济解雇**  **资遣** **员工(经济解雇)** | **惩戒解雇**  **解雇** **员工(惩戒解雇)** | **受雇人自行辞职**  **员工自请离职** |
| 意义 | 若雇主因企业状况有调整人力的需要，事由位于雇主企业经营领域，而非受雇人的责任。因此雇主须遵守预告期间并给付资遣费，以平衡补偿受雇人的不利益。 | 若受雇人有不法或不适当行为，雇主得不经事先预告立即终止劳动契约，且无须给付资遣费。这是雇主惩戒权限之一。 | 受雇人得随时终止契约，但须依雇用期间遵守预告期间，使雇主得以办理交接并寻找替代人员。 |
| 条件 | 有  （台湾劳动基准法第11条） | 有  （台湾劳动基准法第12条） | 无 |
| 事先预告 | 需要 | 不需要 | 需要 |
| 难度 | 简单 | 困难 | 简单 |
| 公司是否须给付资遣费 | 需要 | 不需要 | 不需要 |
|  | 台湾劳动基准法第11条（勞動基準法第11條）：除发生下列情形之一外，雇主即使事先通知受雇人，也不得终止劳动契约。  1. 歇业或转让  2. 亏损或业务紧缩  3. 不可抗力须停止营业达1个月以上  4. 业务性质须减少人力，且被解雇者无法调至其他适当职位  5. 特定受雇人无法圆满完成该职位所要求的工作 | 台湾劳动基准法第12条：受雇人有下列情形之一时，雇主得不经事先通知解雇。  1. 订立劳动契约时为不实陈述，使雇主陷于错误，并使企业有受损害之虞  2. 对雇主、其家属、代理人或其他同事施暴或重大侮辱  3. 受有期徒刑以上确定判决，未宣告缓刑，亦未准易科罚金  4. 严重违反劳动契约或工作规则  5. 故意消耗雇主所有机械、工具、原料、产品或其他物品，或故意泄漏雇主技术及营业秘密，致雇主受损害  6. 无正当理由连续3日旷职（旷工），或1个月内旷职6日以上 |  |

> 在台湾，每满1年年资，
> 雇主须给付平均工资0.5个月作为资遣费。
> （至多6个月工资）此公式适用于劳工退休金条例第12条所适用的年资；劳动基准法第17条所适用的年资，则每1年给付平均工资1个月，没有上限。

​

若受雇人薪资较高且已有一定年资，

资遣费也会相对较高。

于是，部分不审慎的台湾公司会用各种手段，

以免给付高额资遣费，

并促使受雇人自行辞职。

受雇人须谨慎，

留意不要落入公司的意图。

​

我向您讲述一件我承办过的案件。

有一家知名的A公司，在台湾各地设有据点。

因某种原因经营层更换，

新经营层上任后即开始，

为了降低人事成本，

陆续约谈薪资高、年资深的受雇人

当时我的当事人B先生，已在A公司任职超过10年，

并且是台湾中部地区业绩最好的业务人员。

因为薪资与奖金非常高，

公司把B先生当作目标。

​

有一天，一名主管约谈B

突然开始责备B工作不认真。

公司会有困难，

B应牺牲并做榜样

降低自己的薪资与职位。

否则B应离开公司；

并交给B一张A4纸

要他写下：「本人OOO自愿降低职位与薪资」

作为内容。

这份协议，是要给其他全部受雇人看，

让他们跟随。

​

B是台湾中部地区业绩最好的受雇人，

为公司带来许多营收

并且每天认真工作，

因此强烈拒绝这项不合理要求。

B拒绝写下那些内容，

最后公司干部愤怒地命他离开。

B带着不公与悲伤的心情离开，

离开待了10年的公司，

其后不再前来上班。

​

同样地，公司

降低许多主管受雇人的薪资

部分受雇人无法忍受这种对待

而自行辞职

​

但B在经营层更换后，

已认识到公司想以不适当方式让受雇人离开，

并及早察觉

且因在受雇人离开前已发现求职机会，

B在前往面谈当日，

以行动电话录下全部过程

并得以证明自己并非自行辞职。

因此后来在律师协助下，

得以领取较高资遣费，

而其他离开的受雇人则没有同样机会。

​

因为有许多这样的案件，

您必须保存证据，

若公司使用不适当手段。

若公司记载受雇人的小错误，

设定难以达成的目标，

提出过度要求

或将受雇人调到奇怪职位，

**您必须保存证据。**

**您平常的出勤纪录、**

**加班纪录、绩效纪录、**

**工作规则、与同事及上级的电子邮件往来**

**以及与上级的面谈录音——**

**请保存对您有利的证据。**

​

若您在台湾工作，

资遣费比想象中更难取得

不要轻易与公司和解

并留意公司不要以不适当方式解雇您

或促使您自行辞职

资遣费是受雇人的法定权利，

公司当然应给付。

您也须在台湾保护自己的权利。
