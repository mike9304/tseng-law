# Four-market columns, 10 October 2026

This batch adds 12 independently reviewed Taiwan-law articles: three each in Traditional Chinese, US English, Japanese and Korean. Topics were selected from the site's measured content inventory and current legal research; traffic or conversion gains are not asserted.

The manuscripts were copied byte for byte from the frozen approved sources. Each has a distinct generated hero, a localized factual alt description and an AI-image disclosure. Original PNGs remain preserved privately; the production WebPs are centered 1600 × 900 renditions. The independent visual review inspected the originals, exact WebPs and 24 desktop/mobile CSS crop previews.

The reviewers are AI roles. The authors, independent language reviewers, legal chair and visual reviewers have separate responsibilities. This is not a claim of human native-speaker review or licensed-lawyer certification. Internal author provenance is retained without adding a fictional public byline.

`review-evidence.json` records exact manuscript and image hashes, the private source/review evidence hashes, and how private paths were normalized. It intentionally omits home folders, temporary media URLs, generation run identifiers, network addresses and account details. Original work reports were not changed.

Required integration adds the native article registry, publication dates, both sitemap count expectations and nine pending embedding records for Traditional Chinese, English and Korean. Japanese uses the existing public text-search path. No embedding API call was made. Existing articles, the Singapore batch, earlier media and the AI-data video were preserved.

This is the pre-release integration snapshot. Product-page review, full verification, the clean release, deployment and fresh public URL readback remain separate gates; this document does not certify their completion.
