법원 URL을 이번에 다시 열었다고 주장하지 않는다. B6 기록의 10월26일 접속 실패, 25일 보관 법원 회신 및 정부 PDF의 선택된 행 범위를 그대로 구분했다. 현재 새 법조문 확인이 보관 판결을 새 판결 전문이나 후속 확정 조사로 바꾸지 않는다. ES 본문의 10월25일 확인일도 원 정본의 확인일로 유지했다.

## 실제 검사 결과와 보조검사 오류 보존

공유 CLI 6회는 각각 실제 exit 0, FAIL 0, WARN 0이었다. 첫 독립 보조 스크립트 전체는 연락처 검사가 절대 URL만 가정한 탓에 exit 1이었다. 915/916의 정본 및 원고는 `/en/contact` 상대 링크와 “en inglés” 표기를 쓰므로 원고 실패가 아니었다. 첫 결과를 [구조 r1](../checks/es-independent-structure-r1.json)에 보존하고 이 조건만 바로잡아 [구조 r2](../checks/es-independent-structure-r2.json)를 실행했다. r2 실제 exit 0, FAQ 17개, 메타데이터·이미지 경로·굵게 금지·숨은 제어문자·공식 링크/출처 대조 모두 통과. 공유 CLI는 반복하지 않았다.

검수 종료 시 원고·정본·입력·도구 해시를 다시 대조했다. R 작업트리는 깨끗하다. 사진 픽셀을 이번 언어 검수에서 새로 보았다고 표시하지 않으며, 캡션·alt는 정본과 작성자의 이미지 검토 및 기존 이미지 경로를 대조한 범위다.
