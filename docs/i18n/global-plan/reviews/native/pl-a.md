## Verdict
naturalness (1 = machine, 5 = native professional): 3/5 for guidance pack, 2/5 for columns
variety used: standard Polish, consistent; German-calqued syntax and typography throughout; English leftovers in UI labels; Korean-audience passages left in columns 001, 004, 005, 007–009
systemic patterns (max 6, each one line, with 1 example quote):
- Masculine title for Wei Tseng despite feminine verbs: "Sprawdziła adwokat Wei Tseng" / "jest adwokatem kierującym"
- German calques in UI and prose: infinitive buttons ("Wysłać wniosek"), guillemets « », "osoba 3.", "Zbadajcie państwo"
- Korea-audience copy not recast for a Poland reader: "przelewie kapitału (資本額) z Korei", Taiwan–Korea tax treaty as if it were the default
- Lowercase "państwo" (formal you) looks like "the state": "gdy kończą państwo spółkę"
- Stock legal boilerplate stacked until no native would write it: "należy zbadać", "toteż", "wychodząc od", "nie należy wnosić"
- Number format mixed: English "TWD 1.57M" next to German thousands "TWD 500.000"

Guidance pack is meaning-faithful and the consultation-language / no-promise lines are correctly negative. A Poland client can follow it, but the site still reads like German UI translated into Polish. Columns 001–004 and 007 are dense, grammatically strained legal German; 005–009 keep a Korean blog voice. No E (win-rate / Polish-consultation) hits in this part. Files 006 and 009 are the most readable once Korea leftovers are cut.
