# Fable 5.1 — 2차 응답 (tseng-law.com 공개 관찰 토론)

도구·파일·외부 접근 없이, 1차 보고 3건과 신규 1차 증거만으로 답합니다.

## 1. 내 1차 과대주장 정정

- **reduced-motion 게이트를 "접근성 결함 후보"로 쓴 것 철회.** 버튼 실제 클릭 시 H1·헤더·이메일 CTA가 KO/ZH-HANT에서 정상 노출되고, 메뉴 열기/Escape 닫기도 동작. reduced-motion이 정적 인트로 우회를 요구한다는 근거는 없음. → **UX 개선 권장**으로 재분류.
- **도메인 불일치(tseng-law.com vs hoveringlaw.com.tw)를 신뢰 공백으로 올린 것 격하.** 브랜드 도메인 상이는 결함이 아니고 사기 근거도 아님. 선택적 안내 문구 백로그로 이동.
- **"일반 문의 폼" 문구 삭제 권고 철회.** 컨택 `forms: []`는 사이트 전체 폼 부재의 증거가 아니며(홈에 검색 폼 존재), 민감정보 안내는 어떤 경우에도 삭제 대상이 아님.
- **회신 SLA 문구 제안은 운영 사실 확인 항목.** 소유자가 지킬 수 있는 값이 있을 때만; 임의 숫자 금지.
- **중문 명칭·자격 확인 경로**는 자격을 만들어 넣으라는 뜻이 아님. 확인 후 표기 여부만 소유자 판단.
- 리뷰 "5.0·17개"는 여전히 **가설**(하드코딩 미확인).

## 2. Grok에 대한 응답

- **동의:** 홈 첫 페인트에 포지셔닝·CTA 부재(관찰). 카카오/라인 코드 복원 금지. innerText를 원장으로 쓰지 말라 — 실제로 클릭 후 H1이 있으므로 "H1 없음"은 틀린 추론이었음. 타이베이 전화·언어 표기는 카피 원장 문제.
- **불일치:** 2번 수락 기준 "reduced-motion에서 스크롤 없이 본문 노출"은 필수 요건이 아님. 모션 ON/OFF 두 경로는 **선택지**로만 유지. 또한 "첫 포커스가 스킵링크"는 좋은 관행이나 위반 판정 근거는 없음.
- **보강:** Grok 5번 언어 불일치는 신규 증거로 **결함 확정**됨(아래).

## 3. Codex에 대한 응답

- **동의:** 인트로 삭제 없이 1·2·3번 먼저. 접근성 위반과 개선 권장 분리. `/zh` 404는 검사자 실수. 예약 CTA가 mailto라는 확인은 내 4번 가설을 **사실**로 승격시킴.
- **부분 이견:** 컨택 첫 이메일 y=1780px는 "준비 안내가 상단"이라는 우선순위 문제에 동의하나, 준비 안내 자체는 이미 있는 강점이므로 **삭제·축약이 아니라 이메일 블록을 위로 끌어올리는 재배치**여야 함.
- **미검증 수용:** 칼럼 소개의 "실제 수집된 칼럼 본문…" 제작 문구와 리뷰 이벤트 CTA가 일반 상담과 동일 제목이라는 관찰은 내가 못 봤으나 href 확인이라 하므로 카피 항목으로 접수.

## 4. 분류 재정리

**사실 결함 (재현됨)**
- KO/EN/ZH-HANT mailto 템플릿의 희망언어 목록에 **일본어 누락**, JA만 4개. 로케일 간 동일 필드 불일치.
- 상담 언어 표기가 contact(한·중·영) / pricing(4개) / lawyers(한·중·일) / 푸터(한·일)에서 모두 다름.
- `/ko/search?q=법인` axe 색 대비 13건: `.search-results-total`, `.list-meta` 13.12px `#86968b`/`#fff` = 3.11:1 (요구 4.5:1). WCAG AA 위반.
- "상담 예약하기" CTA가 mailto — 문구가 예약 UI를 암시하나 실제는 메일 작성. 카피-동작 불일치.

**설계 트레이드오프**
- 풀스크린 인트로(클릭 후 정상). 컨택 이메일 위치(y≈1780). 이메일 단일 채널. 사무소 목록 중복 노출.

**운영 사실 확인 필요 (코드 전 소유자 답변)**
- 실제 상담 가능 언어(변호사 직접/사무 응대 구분). 타이베이 전화 운영 여부. 한국 010 번호 역할. 회신 소요 기준. 리뷰 이벤트 진행 여부·조건. 리뷰 수치 출처.

## 5. 공동 순위 계획 (구현 전)

1. **언어 원장 통일** — 소유자 확인 후 4개 페이지·푸터·4개 로케일 mailto 템플릿을 한 소스로. 수락: 텍스트 추출 비교 불일치 0, 4개 mailto 디코딩 시 동일 목록.
2. **검색 결과 대비 수정** — `#86968b` → 4.5:1 이상 색상 1개로 교체(같은 토큰 쓰는 다른 `.list-meta`도 함께). 수락: axe 재실행 0건, 데스크톱 반복 포함.
3. **CTA 카피 정합** — "상담 예약하기" → "이메일로 상담 일정 문의" 류. 리뷰 이벤트 CTA는 제목 분리. 예약 시스템 신규 개발 없음. 수락: mailto 유지, 클릭 전후 동사 일치.
4. **컨택 재배치** — 공식 이메일·mailto·복사·민감정보 한 줄을 첫 화면(390 기준 스크롤 1회 이내)으로, 준비 안내는 그 아래 유지. 수락: 첫 이메일 링크 y가 KO/EN/JA/ZH-HANT 모두 현재 대비 크게 상승, 내용 삭제 없음.
5. **홈 게이트 보강(선택)** — 인트로 유지, 게이트 안에 한 줄 포지셔닝(KO/JA에 "대만·변호사" 포함)과 문의 링크 1개. reduced-motion 분기는 선택. 수락: 스크롤 0px에서 브랜드 외 텍스트+링크 1개.
6. **카피 원장 정리** — 타이베이 블록 전화 또는 "이메일 접수" 명시(확인 후), 칼럼 제작 설명 문구 제거, 기관명 표기 통일, 한국 사무장 연락 위임 문구.
7. **백로그** — 도메인 안내 1줄, 리뷰 수치 기준일, 회신 기준(값 확보 시), 사무소 중복 블록.

## 6. 하지 않을 것

인트로 삭제, 카카오/라인·전화·폼 신규 추가, 민감정보 안내 삭제, 전화/SLA/언어/자격 임의 기재, 이미 있는 mailto·복사·가격·프로필·지도·드로어 재개발.
