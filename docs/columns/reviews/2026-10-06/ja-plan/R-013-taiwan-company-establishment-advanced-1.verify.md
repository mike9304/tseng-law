# R-013 검증 메모 — 投資審査と登記住所 (slug 유지: taiwan-company-establishment-advanced-1)

원본: columns-ja/013 (Q&A 5문, 한 줄씩 끊는 블로그체, 「😊」, /ja/guides·/ja/taiwan-lawyer 링크, 한국어 블로그 URL 링크 1곳). 재작성 방향은 PLAN-FINAL §2(投資審査と登記住所: 投審司 심사·登記住所 없이 신청·居留証 없이 구좌 개설·학력경력 심사).

## 바꾼 것
- 블로그체 → 절 구성. 「😊」, 「台湾のある銀行員から直接聞いた話」(출처 없는 전언) 삭제. 「それほど厳格ではありません」(주관 평가) → 「学歴の一致を要件にしているわけではありません」.
- 「会社設立には約3か月、就業許可証と居留証の取得にも約1か月」 → 「数か月」(수치 근거 없음).
- 한국어 블로그 URL 링크 → /ja/columns/taiwan-company-establishment-basics.
- 「私も同感です」 → 「私たちの経験とも一致します」(사무소 경험으로, 개인 신분 꾸밈 없음). 총괄 판단으로 삭제 가능.
- 「台湾の保証金は比較的少ない（通常2か月分）」 → 住宅은 법정 2개월 상한, 店舗는 제한 없음으로 정정(원본은 店舗 보증금을 2개월이라고 서술했으나 법적 근거는 住宅에만 있음).
