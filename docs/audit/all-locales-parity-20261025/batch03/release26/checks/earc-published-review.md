# B1/B2 공개 14언어 704: 전자 ARC 출력 동사 좁은 검토

검수자 Codex `/root/column_source_quality`, 2026-10-26 KST. R의 이미 공개된 B1/B2 14언어 704를 읽기 전용으로 확인했다. 소유 출력은 이 보고서 하나다. 원고·lastmod·도구·배포를 직접 바꾸지 않았다. 아래 3건은 root가 별도로 수정했으며 그 변경도 말미에서 읽기 전용으로 재확인했다.

범위는 기존 전자 ARC 문장에 실제로 있는 가능 표현과 출력 의무의 차이다. 전자 ARC 설명이 없는 글에 새 문단을 추가하라고 요구하지 않았고, 칩 카드의 수령 가능 시점이나 다른 법률 주제로 확장하지 않았다. 이 보고서는 칼럼 전체의 새로운 법률 승인·원어민 사람 감수를 뜻하지 않는다.

## 공식 근거와 판정 기준

[NIA 학생 온라인 지침 4(3)(a)](https://www.immigration.gov.tw/5475/5478/141465/141808/417829/cp_news)를 이번 검토에서 직접 다시 열었다. 게시/수정일은 2026-08-28이다. 학생 절차에서 유효기간 6개월 이하의 전자 ARC는 온라인 납부를 완료한 뒤 신청인이 다운로드하고 출력해야 한다. 영문 동사는 `shall download and print`다. 승인 후5근무일 납부와 칩 카드의 납부 후3근무일 수령은 별개다.

따라서 명시적으로 ‘할 수 있다’로 쓴 전자 ARC 다운로드/출력 문장은 의무를 복원할 대상이다. 규정 절차를 현재형·수동형으로 서술한 문장까지 모두 오역으로 반려하지 않았다. 언어별 동일한 조동사를 강제하지도 않았다.

초기 분류는 명시적 가능3, 절차 서술9, 조건부 절차 서술1, eARC 언급 없음1이었다.

## 공개 응답 확인

공개경로는 `https://tseng-law.com/<locale>/columns/taiwan-arc-first-application`이다. web 도구에서 MS/FIL/NL 세 URL을 열 때는 `not accessible via this tool`이었고, 첫 기본 sandbox urllib 조회는 DNS 실패였다. 이를 실제404나 사이트 장애라고 판단하지 않았다.

이후 허용된 읽기 전용 공개 GET으로14언어를 조회했다. 모두 HTTP200이었고 요청 URL에서 해당 콘텐츠가 반환됐으며 ARC 본문이 있었다. HTML의 script/style을 제외하고 텍스트를 파싱한 뒤 MS/FIL/NL의 위 초기 문장이 정확히 존재하는지 확인해 모두 true였다. 브라우저를 조작하거나 서비스에 쓰지 않았고, 다른11언어의 모든 HTML을 저장소 파일과 바이트 단위로 일치시켰다고 주장하지 않는다. 그 언어의 의미 분류는 읽은 R 문장에 근거한다.

## root 수정본 읽기 전용 재확인
