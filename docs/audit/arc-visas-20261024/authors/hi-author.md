8. 일관된 실용 힌디어. 몸체 H1·굵은 글씨·공개 byline/AI 표시·허구의 1인칭·명령형 체크리스트 제목 없음. 내부 `author: legal-ai-assistant`는 유지했다.
9. 문체 수정 후 조문 번호·기산점·금액·자격·범위·공식 링크와 FAQ를 다시 대조했다. 일반 연장 예외 보완 및 해외 분실 링크까지 현재 해시에 포함된다.

이는 저자 자기 점검이며 독립 언어 검토 결과가 아니다. 힌디어용 검증된 문체 지표가 제공되지 않아 공유 정량 문체 기준 충족을 주장하지 않는다.

## 구조와 보조 관찰 — 실행 범위

아래 read-only Node 명령은 frontmatter 필수 항목·날짜·분류·FAQ 3개, body H1/굵기/공개 byline, 줄끝 공백, 본문 공식 URL의 말미 목록 포함, 실제 내부 링크 대상 파일 존재를 검사했다. 결과 `STRUCTURE 3 files; errors 0`, exit 0.

같은 명령의 `Intl.Segmenter('hi')` 부분은 실제 문장·시작어를 읽기 위한 보조 관찰이다. CV와 8단어 이하 비율은 공유 규칙의 검증된 힌디어 기준이나 통과 판정이 아니다. 706의 보조 CV 0.444도 숨기지 않는다. 본문 평문 공백 단어수는 890 / 1094 / 1237이며 표·FAQ·출처는 제외한다.

## 남은 검토와 실행하지 않은 것

- fresh 독립 힌디어 검토 및 독립 최종 법률·출처 검토가 필요하다. 모든 의견은 이 보고서의 최신 해시를 기준으로 확인해야 한다.
- 공유 variety의 hi 미지원은 그대로 남았다. 별도의 힌디어 심사 결과나 검사기 변경으로 해결했다고 주장하지 않는다.
- 힌디어 상담 가능 여부, 특정 인도 공관 인증 요건, 모든 서비스센터의 우편/대리 수령, 항공사별 해외 분실 탑승 서류는 확인되지 않았다. 원고는 해당 사실을 확정하지 않는다.
- 로그인한 포털 신청·결제·카드 수령·외부 발행·production smoke·사이트 빌드를 실행하지 않았다. 이 author 작업은 원고 파일과 근거·검사 인계까지다.
