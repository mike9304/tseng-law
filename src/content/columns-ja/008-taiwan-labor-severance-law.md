# 台湾労働法：台湾では退職金（資遣費）を受け取りにくい？？

![代表画像](../images/008-taiwan-labor-severance-law/featured-01.jpg)

こんにちは、曾雋崴弁護士（Wei Tseng）です。

今日は皆さんと、台湾の退職金（資遣費）についてお話ししたいと思います。

![](../images/008-taiwan-labor-severance-law/img-01.jpg)

すでに多くの方がご存じでしょう。

韓国では、従業員が退職すると会社が退職金を支払わなければなりません。

しかし台湾は韓国と異なり、

会社側が従業員を解雇した場合にのみ退職金を支払う義務が生じます。

従業員が自発的に退職する場合、会社は退職金を支払う必要がありません。

​

しかし、従業員が違法行為を犯したり、

**会社規則に違反したり、**

**理由なく3日以上出勤しなかった場合、**

会社は従業員に退職金を支払わずに解雇できます。

​

簡単な表にまとめてお示しします。

|  |  |  |  |
| --- | --- | --- | --- |
| **種類** | **経済解雇**  **資遣** **員工(經濟解僱)** | **懲戒解雇**  **解僱** **員工(懲戒解僱)** | **従業員の自発的な辞職**  **員工自請離職** |
| 意義 | 雇用主が経営状況に応じて人事調整の必要がある場合、その事由は雇用主の経営領域で生じたものであり、労働者の責任ではありません。したがって雇用主は事前予告期間を遵守し、退職金を支払うなどの義務を負うことで、労働者に生じる不利益との均衡を図らなければなりません。 | 労働者が違法または不当な行為を犯した場合、雇用主は事前予告なく直ちに労働契約を終了でき、退職金を支払う必要がありません。これは雇用主の懲戒権限の一つです。 | 労働者はいつでも契約を終了する自由がありますが、勤務期間に応じて予告期間を遵守しなければなりません。それにより雇用主が引継ぎや後任の確保を行えるようにします。 |
| 条件 | あり  （台湾労働基準法第11条） | あり  （台湾労働基準法第12条） | なし |
| 事前予告 | 必要 | 不要 | 必要 |
| 難易度 | 簡単 | 困難 | 簡単 |
| 会社が退職金（資遣費）を支払うべきか否か | 必要 | 不要 | 不要 |
|  | 台湾労働基準法第11条（勞動基準法第11條）：次の状況のいずれかが生じない限り、雇用主は労働者に事前通知をしても労働契約を終了できません。  1. 使用者の業務が停止または移転された場合  2. 事業主の事業が営業損失を被り、または事業場を縮小する場合  3. 不可抗力により1か月以上の営業停止を必要とする場合  4. 事業の性質上、人員削減が必要であり、解雇された従業員を他の適切な職務に再配置できない場合  5. 特定の労働者が当該職務に必要な業務を満足に遂行できない場合 | 台湾労働基準法第12条（勞動基準法第12條）：雇用主は、労働者が次のいずれかに該当する場合、事前通知なく解雇できます。  1. 労働契約締結時に虚偽の情報を提供して雇用主を誤認させ、事業に損害を与えるおそれがある者  2. 雇用主、雇用主の家族、雇用主の代理人またはその他の同僚に暴力を加え、または重大な侮辱を加える者  3. 懲役刑以上の刑を言い渡されて確定し、執行猶予または罰金刑に従わない者  4. 労働契約または就業規則の違反が重大な場合  5. 雇用主が所有する機械、工具、原材料、製品その他の品目を故意に消耗させ、または意図的に雇用主の技術および営業上の秘密を漏洩して雇用主に損害を与える場合  6. 正当な理由なく3日連続で無断欠勤し、または1か月に6日以上無断欠勤する行為 |  |

> 台湾では、従業員の勤続年数が1年満了するごとに
> 雇用主は平均賃金の0.5か月分を退職金として支払わなければなりません。
> （上限は6か月分の賃金まで）

​

従業員の給与が高く、一定の勤続年数を満たしている場合、

退職金も相対的に多くなります。

このとき、一部の悪質な台湾企業は高い退職金を支払わないために、

さまざまな手段を用いて

従業員が自発的に退職するように仕向けます。

従業員は注意し、

会社の思惑どおりにならないよう警戒しなければなりません。

​

私が扱った事件の一つをお話しします。

台湾全土に支店を持つ有名なA社があります。

何らかの理由で経営者が交代し、

新しい経営者は就任するとすぐに

会社の人件費を減らすために

高年収・長期勤続の従業員を一人ずつ呼び出して面談を始めました。

当時、私の依頼者であるB氏はA社で10年以上勤務した従業員で、

台湾中部地域で最も高い実績を上げた営業社員でした。

給与とボーナスが非常に高かったため、

会社はB氏を標的にしました。

​

ある日、会社の上級幹部がB氏を呼び出して面談し、

突然、B氏がいかに不真面目な働き方をしているかを非難し始めました。

会社が困難を抱えているから、

B氏が犠牲になって模範を示すべきだとして、

B氏に給与と役職の引下げを受け入れるよう要求しました。

そうでなければ会社を去らなければならないと言いながら、

B氏にA4用紙を渡し、

「私はOOO、役職と給与の引下げを自発的に受け入れます」という

内容を書くよう指示しました。

そしてこの協定書を他のすべての従業員に見せて

従わせると言いました。

​

B氏は中部で最高の実績を上げた従業員として、

会社のために多くの利益を上げ、

毎日誠実に働いていたため、

このような不合理な要求に強い不満を持ちました。

B氏はこうした内容を書くことを拒否し、

結局、会社の幹部は怒ってB氏に出て行くよう言いました。

B氏は悔しく悲しい思いを抱えながら

10年間勤めた会社を去り、

その後出勤しませんでした。

​

会社は同じ方法で

多くの役職の高い従業員の給与を下げ、

一部の従業員はこうした扱いに耐えきれず

自発的に退職しました。

​

しかしB氏は、会社の経営者が交代した後、

不当な方法で従業員を退職させようとしていることを

早くから察知しており、

従業員が退職する前から求人広告を出していることを発見していたため、

その日B氏が面談に臨む際、

携帯電話で一部始終を録音し、

B氏が自発的に退職したのではないことを証明できました。

そのため、その後弁護士の助けを得て

高額の退職金を受け取ることができましたが、

他の退職した従業員はそれほど運がよくありませんでした。

​

このような事例は多いため、

会社が不当な方法を用いるときは

証拠を残さなければなりません。

会社が従業員の小さなミスを取り上げたり、

達成困難な目標を設定したり、

無理な要求をしたり、

従業員を不自然な役職に配置するなどの状況では、

**証拠を残さなければなりません。**

**通常どおり出勤していたことを示す記録、**

**残業記録、業績記録、**

**会社規則、同僚および上司とのメール記録、**

**上司との会話も録音して**

**自らに有利な証拠を残さなければなりません。**

​

台湾で働く場合、

退職金は思ったより受け取りにくいものです。

会社と安易に妥協せず、

会社から不当に解雇されたり

自発的な退職へ追い込まれたりしないよう注意しなければなりません。

退職金は従業員の法的権利であり、

会社は当然支払うべきものです。

皆さんも台湾で自らの権利を守ってください。
