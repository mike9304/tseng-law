- 전: 営業項目によります。飲食業の営業項目で商業ビルの一室を借りると、銀行の口座開設が難しくなります。銀行は賃貸借契約書を見て、所在地を実地で確認するからです。最終的な会社登記でも、台北市では飲食店を営める区域内に登記住所がなければ登記できません。
