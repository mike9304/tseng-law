# fixspec 005 taiwan-company-establishment-advanced-2 (리드 원문 확인 2026-10-06 21:1x, law.go.kr 외국환거래법 시행 2026-01-02본)

적용: 한국 외국환 신고를 서술하는 언어판만. ja(ja-plan 재작성, 일본 독자용)와 zh에 한국 법 서술이 없으면 "해당 없음".

1. F-018-1 법령명: 「외환 관리법/외환관리법」 → 「외국환거래법」(현행 법령명). en "Foreign Exchange Transactions Act", zh 「外國換交易法」(한국 법), ja 「外国為替取引法（韓国）」.
2. F-018-2 신고 시점: 외국환거래법 제18조 제2항 「제1항의 신고와 제3항의 신고수리(申告受理)는 제15조제1항에 따른 절차 이전에 완료하여야 한다.」 → "신고 시점은 … 자본금 송금 시 신고 접수가 되어야" 류 문장을 "신고는 대만 법인으로 자본금을 송금하기 전에 외국환은행에 하여 수리를 받아야 하며"로.
   URL https://www.law.go.kr/법령/외국환거래법/제18조
3. F-018-3 신고 의무자 기준은 국적이 아니라 거주자: 제3조 제1항 제14호 「"거주자"란 대한민국에 주소 또는 거소를 둔 개인과 대한민국에 주된 사무소를 둔 법인을 말한다.」, 제18호 「"해외직접투자"란 거주자가 하는 …」 → "한국의 국적을 가지고 계시는 분이" → "한국 거주자(한국에 주소나 거소를 둔 개인)가".
   URL https://www.law.go.kr/법령/외국환거래법/제3조
(기록만, 적용 안 함: 005-4 대만 달러 출자 서류 "심사상 필요할 때" — 1차 說明書 미열람.)
