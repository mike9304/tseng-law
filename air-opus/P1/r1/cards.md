# P1 r1 카드 문안 (Air Opus) — 1080×1350, 6장

공통: 인물 실명·회사명·주소·집 위치 표기 없음. LINE 말풍선은 판결에 인용된 문구를 재구성한 그림이며 실제 화면이 아니라는 표시를 같은 카드 하단에 둔다. 최소 글자 32px.

## 1. 표지
- 상단 작은 글씨: 오늘의 판결 · 대만 1심
- 제목: 서명 전에 보낸 집 계약금 21,800대만달러
- 부제: 그날 취소하고 돌려 달라고 했지만, 1심은 반환 청구를 기각했다
- 하단: 臺灣士林地方法院 115年度士小字第864號 · 2026.6.30
- 그림: 서명란이 빈 임대 계약서 위에 돈봉투

## 2. 그날 있었던 순서
- 제목: 집을 본 날
- ① 세입자가 관리회사와 함께 집을 봄
- ② 오후 2시 51분, 회사 계좌로 21,800 송금 (월세 한 달 치)
- ③ LINE 말풍선: "…承租訂金" (임차 계약금)
- ④ "짐 넣기엔 좁다" — 같은 날 안 빌리겠다며 돈을 돌려 달라고 함
- ⑤ 회사는 돌려주지 않음
- 하단 고지: 말풍선은 판결에 인용된 문구를 재구성한 것

## 3. 양쪽이 한 말
- 제목: 계약이었나, 아니었나
- 왼쪽(세입자): 서면 계약 없음 / 기간·보증금·입주일 안 정함 / 빌릴 마음만 보인 돈이니 돌려줘야
- 오른쪽(회사): 월세와 조건을 설명함 / 최소 1년은 광고에 적혀 있었음 / 돈을 받고 뒤에 올 세 팀 방문을 취소함 / 정식 서면은 7~14일 안에 쓰기로 함
- 하단: 양쪽 주장이다. 법원이 전부 사실로 인정했다는 뜻은 아님

## 4. 법원이 꼽은 것
- 제목: 서명은 없었지만 이미 정해진 것
- 목록(판결 순서대로): 어느 집 / 월세 21,800 / 생활 규칙 / 설비 목록 / 최소 1년
- 덧붙임: 세입자가 보낸 ‘承租訂金’ 메시지
- 결론 칸: → 계약이 성립했다는 걸 보여 주는 계약금(證約定金)으로 봄
- 하단: 민법 248조는 계약금을 받으면 계약이 성립한 것으로 ‘추정’한다. 돈만 보내면 무조건 계약이라는 판단은 아님

## 5. 누구 책임이었나
- 제목: 계약을 못 지킨 이유
- 좁다고 느낀 시점: 돈을 보낸 뒤 (세입자 본인 진술) → 세입자에게 책임 있는 사유
- 회사 책임이라는 증거: 없음
- 결과 칸: 21,800 + 이자 청구 기각 · 1심 소송비용 1,500도 세입자 부담
- 하단: 이후 항소·확정 여부는 확인되지 않음

## 6. 정보 카드 — 계약금은 언제 돌려받나
- 제목: 대만 민법 249조, 계약금의 기본 규칙
- 전제 띠: 당사자가 따로 정한 게 없을 때
- 계약대로 이행 → 돌려받거나 대금 일부로 충당
- 낸 쪽 책임으로 못 지킴 → 돌려 달라고 할 수 없음
- 받은 쪽 책임으로 못 지킴 → 받은 계약금의 두 배를 돌려줌
- 양쪽 모두 책임 없음 → 돌려줌
- 하단: 248조 — 계약금을 받으면 계약 성립을 추정. 이 사건은 조건을 이미 말로 정했고 본인 메시지도 있어, 서명 전이어도 계약으로 봤다
- 출처 줄: 민법 248·249조 law.moj.gov.tw (2026-10-20 확인)
