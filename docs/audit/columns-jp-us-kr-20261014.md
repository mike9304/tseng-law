## 게시 전 실행 증거

- 게시형식·검색 데이터·FAQ·출처 이미지 경로·사이트맵 등 관련 테스트 150개 통과. 별도 Blob 독자 범위 회귀 3개 통과. 테스트의 실제 예상 게시물 수와 날짜만 갱신했다.
- 프로덕션 Next 빌드 통과, 정적 페이지 2,499개 생성. 기존 테스트 파일의 사용하지 않는 import 한 줄이 lint를 막아 제거했다. 테스트 단언은 변경하지 않았다.
- Chromium 검사 16개 항목 통과: 3언어 × 1440/390px, 실제 본문·제목·canonical·이미지 로딩·공식 링크·가로 넘침, 검색·목록·사이트맵, 본문 관련 글 클릭. 새 탭으로 열리는 기존 링크 동작을 실제 popup에서 확인했다. 기존 QA가 같은 탭에서 기다리던 오류를 고쳤으며 제품 링크는 바꾸지 않았다.
- 화면을 직접 확인했다: 한국어 모바일 상단의 제목·사진·목차, 일본어 모바일 본문과 링크, 영어 PC 상단 제목·사진. 브라우저의 언어 추천 알림은 기존 구성이다. 공개 AI 작성자 이름을 추가하지 않았다.
- 로컬 증거: `~/tseng-jp-us-kr-20261014/qa/local/`. 이는 일반 Next 실행 검사이며 Codex Sites 공개 배포 확인을 대신하지 않는다. 게시 완료는 공개 build-info와 세 URL을 확인한 뒤 기록한다.

영상은 계약명의와 등기시점을 더 명확하게 설명하지 못하므로 이 주제에서는 제작하지 않았다. 기존 회사 건물 사진을 사용했다.
