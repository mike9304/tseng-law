# WO-SEO-IL — 미색인 핵심 페이지 내부링크 보강 (2026-07-22)

> 근거: SEO 딥리서치 확정 #4 (구글 미색인 병목 = 품질 + 내부링크). 지시서 2026-07-22 섹션.
> 담당: 에이전트 구현 / 오케스트레이터 검수. **법률 수치·신규 법률 주장 금지**(링크·앵커·내비만).

## 목표
미색인·저노출 핵심 한국어 URL로 **문맥형 내부링크**를 늘려 크롤 경로와 주제 클러스터 신호를 강화한다.
홈 푸터/메뉴에 같은 URL을 반복 나열하는 허브 스팸 방식은 금지.

## 링크 소스 (어디서 걸 것인가)
1. **기존 칼럼 본문** 관련 문단 말미 1~2개 (자연 문맥, 앵커=의도 키워드).
2. **가이드 ↔ 랜딩 ↔ 서비스** 상호 링크 (상호 1회 이상, 동일 앵커 반복 금지).
3. **칼럼 목록/관련글** 컴포넌트가 있으면 주제 클러스터 기준 추천 (임의 최신글 4개 나열 지양).
4. 아웃리치(STEP 13) 문안의 링크 필드도 홈 → 위 P0 URL로 교체.

## 구현 제약
- 스코프: 콘텐츠 md, 가이드/랜딩 페이지 TSX, 관련 컴포넌트, 아웃리치 md. 빌더 발행 문서 패치는 별도 승인.
- `npm run qa` + 영향 페이지 200 확인.
- 앵커 텍스트에 `변호사` 단독 사용 시 `대만 변호사`로 통일 여부 점검.
- C1~C4(markers 포함) 푸시·배포 전 링크 타깃에 넣지 말 것.
