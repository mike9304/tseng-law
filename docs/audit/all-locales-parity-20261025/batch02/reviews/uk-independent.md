## 필수 / 선택 지적

필수: 없음. 다음은 조건을 잘못 단정한 문장을 발견했다는 판정이 아니라 명료성·문체·출처 접근성을 높이는 선택 제안이다.

### S01 — 704의 5년 기간 문단에서 취업허가 주체 명료화

- 문장: `Потрібні відповідні трудове схвалення та дозвіл на проживання; відлік цього строку починається наступного дня після схвалення проживання NIA.`
- 이유: 앞 문장의 대상은 고용된 특정전문인재와 법정 가족이다. 현재 문맥에서는 전문인재의 고용 요건으로 읽을 수 있으나, 주어 없는 다음 문장이 가족도 취업허가를 받아야 한다는 뜻으로 읽힐 여지를 줄이면 좋다. `трудове схвалення`도 추상적인 직역이다.
- 수정안: `Професійна робота самого фахівця має бути охоплена належним дозволом або застосовним звільненням. Він та охоплені законом члени родини мають отримати схвалення проживання NIA. Строк кожної такої ARC рахують із наступного дня після відповідного схвалення проживання.`
- 의미 보존: 앞 문장의 고용된 특정전문인재·정해진 가족·최장 5년 및 인재법 제8조 링크를 유지한다. 가족에게 새 취업허가 요건을 만들지 않고, NIA 거류허가 다음 날 기산을 그대로 둔다. 수정 후 실제 문장 다양성 재검사는 별도 필요하다.

### S02 — 704·705의 입국 표현에서 생략된 말을 보충

- 문장 예: 704 `... допускає пряму заяву до NIA після безвізового в’їзду чи гостьової візи.` / 705 `... допускає пряму заяву після безвізового в’їзду або гостьової візи.`
- 이유: 의미는 문맥상 분명하지만 `після ... візи`는 비자라는 문서 뒤라는 직역 형태다. 무비자 입국과 방문비자로 한 입국을 같은 문법 수준에서 연결하면 자연스럽다. 704 첫 FAQ와 705 가족 문단에도 같은 생략형이 있다.
- 수정안: 해당 구절을 `після безвізового в’їзду або в’їзду за гостьовою візою`로 쓴다. 기존의 `чи`를 유지해도 된다.
- 의미 보존: 두 입국 경로의 OR, 별도 신청 자격과 허가 조건을 유지한다. 비자 발급일이 직접 신청의 기산점이라는 의미를 새로 만들지 않는다.

### S03 — 706의 NIA 여권 안내에 현재 열리는 공식 경로 사용

- 대상: `офіційна відповідь NIA` 본문 링크와 끝 목록의 `паспорт на день прибуття для власника ARC/APRC` 링크, 현재 `/5382/5385/12162/12197/414977/`.
- 이유: 현재 web 열람은 이 경로에 내부 오류를 반환했다. 반면 같은 NIA의 [현재 경로](https://www.immigration.gov.tw/5385/12162/12197/414977/)는 질문·답변과 2026-06-29 게시·수정일을 직접 확인할 수 있었다. 오류를 확정 404나 법령 폐기로 판단하지 않는다. 별도 Python HTTP 확인은 이 실행 환경의 DNS 실패였으므로 URL의 상태 증거로 사용하지 않았다.
- 수정안: 본문과 끝 목록을 모두 `https://www.immigration.gov.tw/5385/12162/12197/414977/`로 연결한다. 원문 URL 이력을 남길 경우 저자 기록에 같은 기관·같은 414977 문서라는 대응을 적는다.
- 의미 보존: 유효 ARC/APRC 소지자, 도착일 유효 여권, 6개월 잔존기간 불요, 입국심사 유지라는 답변은 그대로다. 이 URL은 EN 정본 필수 URL 집합에 없으므로 교체가 EN 출처 누락을 만들지 않는다. 도구의 URL 비교 규칙을 완화할 필요도 없다.

### S04 — 704 수수료 문단의 국소적 반박·번역투

- 문장: `Більша оплата не купує довшого дозволу.`
- 이유: 바로 앞에서 법정 기간과 NIA 승인을 설명했다. 지불액을 사는 주체로 만든 표현이 부자연스럽고, 독자가 더 돈을 내서 기간을 사려 한다는 반박을 덧붙인다.
- 수정안: `Збір обчислюють за строком проживання, який NIA схвалило на законній підставі.`
- 의미 보존: 수수료가 거류 자격이나 승인기간을 결정하지 않는다는 취지, 앞의 3년·5년·Gold Card 1–3년과 출처를 유지한다.
- `MONOTONY: 대비·반박 — «Більша оплата не купує довшого дозволу.» — 지불액이 아닌 승인기간이 수수료 계산의 기준이라는 긍정문으로 다듬기.` 국소적 선택 제안이며 이 한 문장으로 전체 문체를 반려하지 않는다.

## 문체·최근 3편·§5

비교한 UK867은 허가 전 근로 질문, 868은 우크라이나의 혼인면접 특별목록 제외일, 869는 표시된 가상 식용유 미수금 장면으로 시작한다. 새 704는 30일 기산이라는 숫자, 705는 입국 방식이 전문인재와 학생에게 주는 다른 결과, 706은 사유가 끝난 뒤 카드상 만료일까지 머물 수 있는지 묻는 질문이다. 같은 가상장면·훈계형 제목을 세 편에 복제하지 않았다. 새 글은 우크라이나어 독자를 우크라이나 국적자로 가정하지 않는다.

첫 두 문단을 문장별로 대조했다. 704는 의무·기산·NIA·ARC 기능과 일반 방문자 제한·통합문서 예외, 705는 전문인재/학생의 경로 차이와 여권·관할 공관, 706은 사유 소멸의 효과와 사건일을 입증할 자료를 담는다. 삭제해도 정보가 같아지는 범용 예고형 첫 문장은 없다. 제목·요약과 FAQ도 본문보다 넓은 권리를 약속하지 않는다.
