## OVERBROAD

### O1 · L46 · 긴급보호령 4시간의 기산 서술 (경미, 해석)
- 칼럼 문장: 「제16조 제4항의 4시간은 법원이 신청을 접수하고 신청인의 출석이나 전화 진술로 급박한 위험을 인정한 때부터의 기한이지, 처음 신고한 때부터 세는 시간은 아닙니다.」
- 1차 원문(家庭暴力防治法 §16④): 「法院於受理緊急保護令之聲請後，依聲請人到庭或電話陳述家庭暴力之事實，足認被害人有受家庭暴力之急迫危險者，應於四小時內以書面核發緊急保護令，並得以電信傳真或其他科技設備傳送緊急保護令予警察機關。」
- URL: https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=D0050071&flno=16
- 무엇이: 조문은 기산점을 "위험을 인정한 때"로 못 박지 않는다. 문언상 "접수 후 … 4시간 안에 발령"이며, 2차 출처 요약(검색 결과 요지, 페이지 본문 미열람)도 「法院應於受理聲請後4小時之內核發」로 서술. "경찰 신고 시점부터 세지 않는다"는 부분은 맞지만 "위험 인정 시점부터"라고 단정한 부분은 조문에 없음.
- 고친 문장 제안: 「제16조 제4항의 4시간은 처음 경찰에 신고한 때부터가 아니라, 법원이 긴급보호령 신청을 접수한 뒤 신청인의 출석이나 전화 진술로 급박한 위험이 인정되는 경우에 법원이 지켜야 하는 발령 기한입니다.」
