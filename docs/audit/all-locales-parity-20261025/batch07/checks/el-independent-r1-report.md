## 필수 M01 — 920 본문 32행, 계량기 소유권의 추가 단정

문제 문장: `Ο μετρητής ανήκε στον κάτοικο. Η κυριότητά του δεν άλλαζε το καθεστώς των υπόλοιπων σημείων από τα οποία περνούσαν τα καλώδια.`

이유: 첫 문장의 `ανήκε`에 이어 두 번째가 법적 소유권을 뜻하는 `κυριότητά`를 명시한다. 실제 판결의 비쟁점 사실은 공용 전기함에 차단기를 추가하여 `上訴人電表`로 연결한 경로다. 주민의 계량기로 연결된다는 사실을 계량기 자체의 법적 소유권이 인정되었다는 사실로 넓힐 근거는 이번 정본·조건표·보관 판결에서 확인되지 않았다. 계량기를 누가 법적으로 소유하는지 새로 추정할 필요도 없다.

수정안: `Τα καλώδια κατέληγαν στον μετρητή του κατοίκου. Αυτό δεν άλλαζε το καθεστώς των υπόλοιπων σημείων από τα οποία περνούσαν.`

의미 보존: 주민의 계량기로 이어지는 배선, 그 배선이 지나는 벽·천장·공용 전기함의 지위, 공용부 승인 문제가 모두 남는다. 소유권 단정만 제거한다. 앞 문장의 실제 공사 내용과 뒤의 법 제11조·단지 규약 제15조 설명을 삭제하거나 약화할 필요가 없다. `του κατοίκου` 같은 일상적 소유격 자체를 일괄 오류로 보지 않는다. 이 지적은 `κυριότητά`로 법적 권리까지 확정한 문맥에 한정한다.

근거: [보관 실제 판결 응답](../../batch06/research/retained/zh-hant-ev-primary-recovered.md)의 표기 L40/L43. 실제 문구는 `…接至台電電箱增設斷路器至上訴人電表。`이고, L43은 벽·천장·공용 전기함의 공용부 성격을 판단한다. [원 공식 판결](https://judgment.judicial.gov.tw/FJUD/printData.aspx?id=KSHV%2C111%2C%E4%B8%8A%2C132%2C20220622%2C1)의 이전 실제 응답을 다시 읽었으며 이번 검수에서 새 웹 요청을 했다고 표시하지 않는다.

## §5·MONOTONY와 실제 검사 연결

기계 수치는 각 현행 원고 SHA와 네 공유 도구/프로필 SHA를 기존 실제 CLI 영수증에 연결하여 확인했다. 915/916/921은 `el-variety-dates.json`, 918/920은 initial, 919는 revised의 해당 행이다. 여섯 행의 실제 exit는0이고 FAIL0다. 저자가 처음916/919에서 기록한 실패와 이후9문단의 실제 수정은 덮어쓰지 않았다. 공용 구조검사의 errors0·runtime filter상6편도 실제 영수증과 현재 SHA가 맞지만 의미 검토를 대신하지 않는다. 공용 도구의 의미 검토 요구32건은 사람 승인으로 바꾸지 않는다.

검수자가 전문을 읽은 본문에 실제 추출269분절의 시작·끝 위치를 전부 대조했다. 그리스어 질문 부호 `;`, `44.417.150`·`243.548` 천 단위 구분, `1η`·`22ας`·`30ή` 등의 날짜·서수, 중국어 사건번호, 조문·항·호 경계에서 잘못 잘린 부분을 확인하지 못했다. 다만269에는915와921의 표 앞 콜론 도입2개가 포함된다. 모두 문법적으로 완결된 문장이라고 과장하지 않는다.

| 6. 대비 | 판례 결과의 범위를 한정하는 필요한 부정을 삭제하지 않았다. 독자가 하지 않은 주장을 되풀이해 반박하는 장치나 세 번을 넘는 대비 공식은 확인하지 못했다. |
| 7. 결말 | 출처 확인일·적용범위의 구조적 꼬리 앞 실질 결말은 각각 청구 변경 기록, 정보 수신·결정, 통지/검수/인도 문서, 조사 기회, 배선·승인·비용, 결제·변환·사용 기록으로 돌아온다. 필요한 고지 반복만으로 단조로움을 반려하지 않았다(SENTENCE-VARIETY-RULE 2-7 예외). |
| 8. 어조·형식 | 설명문 그리스어를 유지한다. 굵은 강조·지어낸 변호사1인칭·기계적인 명령형 체크리스트 제목·공개 작성자/감수 표시가 없다. O01/O02는 문맥상 뜻이 유지되는 선택 개선이다. |
| 9. 의미 우선 | 법률 조건·기산점·금액·출처·허구 캡션을 대조했다. M01이 해결되기 전 의미판정은 REQUEST_CHANGES이며 기계 PASS로 덮지 않는다. |

MONOTONY: 현행 전문에서 §5의 두 항목 이상 위반이나 독립적인 단조로움 반려 사유를 확정하지 않았다. 초기 기계 실패를 현재 PASS처럼 소급하지 않는다. M01은 단조로움 문제가 아니라 근거 범위 문제다.
