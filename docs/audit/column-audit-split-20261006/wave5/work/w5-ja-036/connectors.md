# connectors — 036 ja: 원문에 없는 문구·변경 (draft.md 기준, 전부 기록)

새 법률 주장은 F-039 두 건(리드가 1차 원문으로 확인한 문장)뿐이다. 나머지는 연결·재배열이다. 판결 링크 → 짧은 괄호 치환 0건(원문에 본문 판결 링크 없음).

C1 (L26, 첫 문장 삭제에 따른 지시어 보강) — draft:
`現地法人の董事長などを兼務すると、日本の感覚では出向先の役職のひとつと受け止めるのが自然ですが、台湾の法律ではその役職に「負責人」という法的な立場がつきます。`
- 원문 s2: `日本の感覚では、出向先の役職のひとつと受け止めるのが自然ですが、台湾の法律ではそこに「負責人」という法的な立場がつきます。`
- 새로 쓴 부분: 「現地法人の董事長などを兼務すると、」(삭제한 s1의 「現地法人の董事長を兼務」·제목 「董事長・経理人になったら」에서), 「そこに」→「その役職に」. 법적 내용 변화 없음(L32가 董事·董事長·経理人을 負責人으로 설명).

C2 (L34, 분공사 經理人 불확실성 축약) — draft:
`分公司の経理人として登記された駐在員が、第8条第2項の経理人と同じ意味で負責人になるかどうかは、外国会社の分公司に準用される条文の一覧（公司法第377条第1項）に第8条が含まれていないため、条文だけでは一律に言えませんが、実務では職務の範囲で負責人として扱われることが多く、支店の経理人に就く場合も、負責人と同じ心構えで臨むのが安全です。`
- 원문 s3+s4 두 문장을 한 문장으로. 변경: 「言えず、在台負責人としての指定の有無や実際の職務によって変わります。実務では、」→「言えませんが、実務では」, 「多いので」→「多く」. 삭제: 「在台負責人としての指定の有無や実際の職務によって変わります」. 새 법적 서술 없음. 조문(§8②·§377①)·결론 문장 유지.

C3 (L56, F-039 #1 — 리드 확인 문장) — draft:
`規範の附表では、審査される事情が欠税額の区分で変わります。確定した欠税額が200万元以上600万元未満（行政救済中は300万元以上900万元未満）の区分では、財産の隠匿・移転の兆候がある場合に限って制限の対象になります。600万元以上2,000万元未満（行政救済中は900万元以上3,000万元未満）の区分では、営業状態の異常、負責人の出國頻繁・長期の国外滞在・所在不明、財産の隠匿・移転の兆候のうち、いずれか一つがあれば対象になります。2,000万元以上（行政救済中は3,000万元以上）は、こうした事情を問わず対象になります。`
- fixspec 문구와 다른 점 3가지:
  1. 첫 문장 앞에 「規範の附表では、」 — factcheck 「참고」(출처 표기 대상은 規範 附表)에 따른 귀속 보강.
  2. 중간 구간: fixspec 「…区分で、営業状態の異常や…も条件に加わり、2,000万元以上は…」 → 「…区分では、…のうち、いずれか一つがあれば対象になります。」 附表 원문 「且有下列情形之一者」(營業狀況異常·出國頻繁·長期滯留國外·行蹤不明·隱匿移轉跡象 5개 중 하나)를 그대로 옮기려고. 「条件に加わり」는 누적(AND)으로도 읽힌다.
  3. fixspec의 한 문장(중간 구간+2,000万元 이상)을 두 문장으로 나눔.
- 숫자·구간 값은 fixspec/036.md·factcheck M-1(附表 인용)과 대조 완료.

C4 (L56 마지막 문장) — `中間の区分では、日本との往復が多い駐在員は「出國頻繁」に当たりやすく、この要件はあまり安心材料になりません。` 원문 문장 앞에 「中間の区分では、」만 추가(fixspec).

C5 (L66, F-039 #2 — 리드 확인 문장) — draft:
`…行政執行では滞納額が合計10万元以上であれば使われる可能性があります（10万元未満でも、すでに2回出境している場合は制限の対象から外れません。行政執行法第17条第2項第1号）。そのため、税の出境制限より金額の基準はずっと低くなります。`
- fixspec 문구와 다른 점: 「除外されません」→「制限の対象から外れません」(「除外」가 어느 쪽으로 읽히는지 모호하다 — 조문은 「不得限制住居」의 예외이므로 10万元 미만이어도 제한될 수 있다는 뜻). 조문 강도 유지(不得限制 → 但書 「不在此限」).

C6 (프런트매터 FAQ3 답) — 원문 「財政部の規範が定める出国頻度などの事情も考慮したうえで」 → draft 「財政部の規範が欠繳額の区分ごとに定める事情（財産の隠匿・移転の兆候や出国頻度など）も考慮したうえで」. 본문 L56과 같은 취지의 최소 보정(fixspec: 「FAQ(L19)에 같은 서술이 있으면 같은 취지로 최소 보정」).
