# Grok 4.6 2차 — 반박·정정·공동 계획

도구·파일·기억 없이, 공개 실측과 두 보고만으로 수정한다.

## 1차 과잉 주장 정정

1. **홈 1순위를 철회한다.** 오프닝 버튼 실클릭 후 KO·ZH-HANT에서 H1·헤더·메일 CTA가 정상이다. 진입 후 첫 메일 CTA는 y=345. 인트로는 **설계 선택**이지 고장·SEO 제목 부재가 아니다. 「스크롤 0에서 브랜드만 보인다」는 관찰은 남기되 결함으로 올리지 않는다.
2. **reduced-motion = 인트로 의무 스킵 주장을 철회한다.** 정적 게이트를 모션 감소가 법적으로 건너뛰게 한다는 추론은 프라이머리가 부정한다. **위반**과 **개선 권고**를 분리한다. 이번 axe 2A/AA/2.1AA에서 KO 홈·연락처·가격은 자동 위반 0.
3. CONTACT `forms:[]`로 사이트 전체 폼 부재·개인정보 고지 삭제를 말하지 않는다. 홈 검색 폼은 이미 있다.
4. 도메인 병존을 사기 단서로 쓰지 않는다.

## Fable 5.1

**동의.** 상담 언어 원장 불일치는 **콘텐츠 결함**이다. 내가 5위로 둔 것은 낮다. mailto까지 보면 더 단단하다: KO/EN/ZH-HANT는 한·중·영만, JA만 4개. 메신저 복원 금지, 인트로 삭제 전 클릭 검증 — 클릭이 통과했으므로 삭제안은 기각. 「예약」vs 실제 수단은 1차에선 가설이었으나 `/ko/pricing` href=mailto로 **사실 확정**. 예약 UI 신설 근거가 아니다.

**이의.** 도메인 설명·SLA를 수락 조건에 넣는 것은 과하다. 없는 회신 약속을 발명하게 된다. 「사이트 전체 문의 폼 0건」도 위험하다. CONTACT 무폼 ≠ 전역 무폼. 「일반 문의 폼」문구만 범위에 맞게 고치고 고지 본문은 유지. 리뷰 5.0·17은 오표기로 단정하지 않는다.

## Codex

**동의 — 순서 제안을 수용한다.** 인트로를 지우지 않고 (1) 연락처 메일 위치 (2) CTA 카피=mailto (3) 언어/mailto 정합이 먼저다. 타이베이 전화·영어 범위는 번호/약속을 만들지 말고 소유자 확인. 홈 칼럼 「실제 수집된 칼럼…」제작 누설과 리뷰 CTA 제목 비보존은 내가 1차에 빠뜨렸다. 공개 카피 결함으로 편입한다. 이벤트 위법으로 비약하지 않는 점에 동의.

**보정.** y=1780은 **정보 우선순위 문제**이지 렌더 버그·문의 불가가 아니다. 홈 진입 후 메일은 이미 가깝다. 고칠 곳은 CONTACT(EN/JA 동형)의 순서다. 검색 대비 13건(13.12px `#86968b`/`#fff`, 3.11:1 < 4.5)은 이번 실측이며 1차 공동안에 없었다. 홈·연락·가격 axe 0과 **페이지를 섞지 말 것**. 데스크톱 재검은 대기.

## 재분류

- **사실 결함:** 페이지·mailto 언어 집합 불일치; 가격 CTA「상담 예약하기」vs mailto; 검색 결과 명도대비; 칼럼 제작 설명 노출; 리뷰 CTA 제목이 일반 상담과 동일.
- **설계 트레이드오프:** 시네마틱 인트로(클릭·메뉴·Escape 정상); 메일 전용 접수(프리필·복사·민감정보 경고는 **강점, 재개발 금지**); 연락처 상단이 준비 안내; LINE/Kakao 없음; 브랜드 도메인 상이.
- **운영 확인 후 카피:** 타이베이 Tel 유무; 일본어가 접수 언어인지 변호사 상담인지; 영어 범위; 손정민 연락 위임; 리뷰 수치 기준일; 리뷰 이벤트 유효 여부. 데스크톱 대비 미측정.
- **비목표:** 인트로 삭제, 예약 시스템, 메신저 허위 추가, SLA/전화/자격 발명, 고지 전역 삭제, 기존 가격표·프로필·지도·드로어·mailto 재개발.

## 공동 순위 계획 (구현 전)

1. **언어 원장 1개.** 「이메일 접수 언어」와 「변호사 상담 언어」를 구분해 한 소스. JA를 mailto에서 뺀 것이 정책이면 페이지 접수 목록에서도 빼고, 상담 가능이면 네 로케일 mailto를 맞춘다. 영어 미지원으로 단정하지 않음.
2. **CTA = 실제 동작.** 가격(및 동등 로케일) 「상담 예약하기」→「이메일로 상담 일정 문의」등. href=mailto 유지. 예약 UI 없음.
3. **CONTACT 순서.** 공식 메일·mailto·복사를 첫 화면(홈 진입 후 y=345 수준)으로, 긴 준비 안내는 뒤로. EN/JA 동일. 채널 추가 없음.
4. **검색 대비.** `.search-results-total`·`.list-meta` 등 13건을 4.5:1 이상. 홈/연락/가격과 별개 회귀. 데스크톱 재측정.
5. **공개 카피.** 칼럼에서 제작 공정 문장 제거. 리뷰 이벤트는 운영 중 확인 뒤에만 별도 제목, 아니면 분리·비노출. 「일반 문의 폼」은 실제 폼 범위에 맞게 수정, 고지는 유지.
6. **인트로(선택·하위).** 게이트 유지. 버튼 옆 한 줄 포지셔닝만. reduced-motion으로 법적 스킵 강제 없음. 메뉴/Escape는 통과 상태 유지.
7. **소유자 확인 게이트.** 타이베이 전화 또는 「타이베이는 이메일만」; JA 접수 여부; 손정민→대표 메일 위임. 확인 전 번호·SLA·자격 신설 금지.

수락은 로케일별 텍스트/href 비교와 390 실클릭만. 전환율 숫자는 만들지 않는다.
