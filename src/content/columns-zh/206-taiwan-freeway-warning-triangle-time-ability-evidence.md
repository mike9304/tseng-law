# 警告標誌還拿在手上，後車已撞來：法院怎麼看來不及完成的義務？

06:06:48，駕駛手裡還拿著車輛故障標誌，距離自己的車尾約二十公尺。他舉牌向後方來車示警；下一秒閃往內側路肩，再下一秒，後車撞上他的車。後車駕駛送醫後死亡。

這段經過，記在彰化地院判決所附的監視器勘驗筆錄裡。駕駛確實還沒有把標誌放到規定的位置，車子的雙黃燈也沒有亮。法院仍判無罪，二審維持。理由落在一個更具體的問題：事故留下的時間與車況，是否讓他有可能完成法律要求的動作？〔[一審，第5至8頁、附件第10至12頁][trial]；[二審，第6至11頁][appeal]〕

本文依公開判決及附件說明，沒有取得原始監視器影片。下列時間均為判決記載的畫面顯示時間，不表示已另外校正為標準時鐘。

## 先撞上前車的過失，與後來死亡的刑責

事故發生於2021年12月30日，國道一號南下207.1公里處。A車先擦撞內側護欄，停在內側車道；隨後，B車駕駛因未注意車前狀況，從後方撞上A車。B車也停在內側車道，之後遭C車自後追撞，C車駕駛因傷死亡。本文沿用判決的A、B、C車代稱，討論的是B車駕駛的刑事責任。〔[一審，第1至3頁][trial]〕

B車駕駛並不爭執自己對撞上A車有過失。但檢方這次指控的過失致死，還涉及碰撞之後的處置：B車未顯示危險警告燈，也沒有完成設置故障標誌，是否因此應對C車駕駛的死亡負刑責？

法院承認B車駕駛有警示後方來車的義務。車留在內側車道，已成為道路障礙；加上他自己的前階段過失，不能把後續危險當成與自己無關。然而，第一次碰撞有過失，並不能省略對後續死亡所作的刑事要件與證據判斷。〔[一審，第4頁][trial]；[二審，第4至5頁][appeal]〕

## 有義務，還要查當時做不做得到

刑法第276條規定過失致死罪。法院在本案另援用刑法第15條，檢查以「沒有採取必要行動」成立犯罪的條件。第15條第1項要求法律上有防止結果的義務，而且是「能防止而不防止」；第2項則規定，因自己行為造成犯罪結果危險的人，負有防止結果發生的義務。〔[刑法第15條][cr15]、[第276條][cr276]〕

因此，需要分開看的有三件事：B車駕駛是否負有防止危險的作為義務、事故處置規則要求他注意什麼，以及那些動作在當時的時間、空間與機件狀態下，是否實際做得到。判決稱最後這一點為「作為能力」。有義務，並不代表現實條件就一定容許完成；已發生死亡，也不能倒過來補足這項要件。〔[一審，第4至5頁][trial]；[二審，第5頁][appeal]〕

本案適用的警告規定也有不同情境。《高速公路及快速公路交通管制規則》第15條規定，汽車因機件故障或緊急情況無法繼續行駛，已滑離車道、停在路肩待援時，除顯示危險警告燈外，應在車後五十至一百公尺設置故障標誌；無法滑離車道時，則是車後一百公尺以上，並應立即通知公路管理或警察機關協助。〔[事故時版本][freeway-old]、[現行第15條][freeway]〕

《道路交通事故處理辦法》第3條要求在適當距離豎立故障標誌或其他明顯警告設施，第4條將高速公路的距離列為事故地點後方一百公尺。本案發生在國道一號，不能混用同條另列的快速道路八十公尺規定。這些相關條文在事故時與本次查閱的現行版本，內容相同。〔[事故時第3、4條][accident-old]、[現行第3、4條][accident]〕

## 九十二秒從停定算起，兩次碰撞則隔了九十六秒

法院沒有只看「標誌還沒放好」這個結果。勘驗附件把駕駛下車、示警、返回車旁、取牌與向後走的過程分開記下來。

| 畫面顯示時間 | 判決記載的動作 |
| --- | --- |
| 06:05:14 | B車撞上A車車尾，將A車向前推行。 |
| 06:05:18 | B車停定在內側車道。 |
| 06:05:34至06:05:48 | B車駕駛下車，走到車後揮手示意後方車輛變換車道。 |
| 06:05:49至06:05:56 | 駕駛走回B車，途中另揮手一次，之後到達靠近駕駛座的車旁。 |
| 06:06:07至06:06:30 | 走至車尾、開啟後車門，在後車廂拿取故障標誌。 |
| 06:06:31 | 手持標誌，開始沿路面邊線向後步行。 |
| 06:06:48 | 在距B車車尾約二十公尺處，持牌向C車示警。 |
| 06:06:49 | 閃往內側路肩。 |
| 06:06:50 | C車撞上B車車尾，將A、B兩車向前推行。 |

資料：〔[一審附件，第10至12頁][trial]；[二審，第7至8頁及附件第13至15頁][appeal]〕。表格是在整理法院的勘驗記載，並非示範應站在車道上舉牌。

二審計算的九十二秒，是 06:05:18停定到06:06:50後撞。若從 06:05:14的首次碰撞 算到06:06:50，兩次碰撞相隔的是九十六秒。判決理由雖曾概括使用「兩次碰撞」的說法，二審第8頁已把九十二秒的起訖列明；閱讀時應把起點保留下來。

接著，法院從06:06:31到06:06:48的十七秒，估算駕駛向後走了多少距離。依兩段車道線、兩個間距，以及每段四公尺、每個間距六公尺計算，約是二十公尺。以本案這段步行速度推估，走一百公尺約需八十五秒。

即使先只加上下車的十六秒，以及從06:06:07開始取牌到06:06:31向後步行的二十四秒，合計也要一百二十五秒，已超過停定後的九十二秒。這個估算尚未把前面揮手示警、返回車旁等時間全數加進去。法院也考量駕駛所述安全帶卡住的情況，認為難以認定下車與取牌所花的時間有刻意拖延。〔[一審，第7至8頁][trial]；[二審，第8至9頁][appeal]〕

一百二十五秒是法院用本案資料作的履行時間估算，不是法律給每個人的寬限期；九十二秒也不是碰撞發生在這段時間內就一律免責的界線。換了車況、可用時間、取牌位置或處置經過，就需要重新判斷。這裡的結論，來自具體證據所呈現的時間不足。

## 雙黃燈沒亮，不等於已證明駕駛能讓它亮

燈號是另一個必須獨立回答的問題。法院從勘驗結果認定，兩階段碰撞之間，B車確實沒有顯示危險警告燈。這不是採信「其實有亮，只是鏡頭沒拍到」的辯解。〔[一審，第5頁][trial]；[二審，第6頁][appeal]〕

但未亮的原因仍有疑問。判決引用國瑞汽車公司的函覆，說明B車的供電來自電瓶，若電瓶沒有電力、損毀或斷線，危險警告燈便無法啟動。法院再對照初撞當下大燈熄滅、引擎蓋突起變形，以及後續未見尾燈照亮駕駛等情形，認為不能排除第一次碰撞已影響供電。〔[一審，第5至6頁][trial]；[二審，第6至7頁][appeal]〕

這與「檢查後確認電瓶壞了」有差別。B車後來又遭C車追撞，車況已有變化；依判決記載，車輛報廢前未做檢查，現有證據已無法確認第二次碰撞前的實際車損。廠商函提供的是供電機制的說明，並非本案電瓶經實物檢驗後的故障診斷。

檢察官上訴時提出一個反問：B車的行車紀錄器還在錄影，不就表示車上仍有電，能開雙黃燈？二審認為，單憑持續錄影，不足以排除上述車損與燈號變化所留下的疑問。判決也提到一般市售紀錄器可能靠內建電池，在車輛關閉電源後繼續錄影一段時間。〔[二審，第10頁][appeal]〕

這段理由不能擴張成「所有紀錄器都有備援電池」，更不能寫成法院已查明本案機型、電池狀態與供電方式。公開判決沒有這樣的個別檢驗記載；它在這裡支持的，是不能只用錄影持續，就推定整車供電及警示燈功能正常。

## 初次鑑定與覆議分歧，法院追問的是時間條件

就C車追撞B車的這一階段，初次行車事故鑑定認為B車駕駛「無肇事因素」；覆議意見則認為他肇事後沒有完成設置故障標誌、影響行車安全，屬肇事次因。這裡說的是兩份行車事故鑑定意見，不能混稱為警方初判表。〔[一審，第8至9頁][trial]；[二審，第9至10頁][appeal]〕

法院不採覆議的這項結論，理由很具體：覆議看到客觀上尚未放好的標誌，卻沒有精準計算完成設置需要多久，以及後車撞來之前究竟剩多少時間。對法院來說，判斷不能停在「沒有完成」，還得回答「當時有沒有完成的可能」。

這也是本案與賠償比例討論不同的地方。此處要判斷的是過失致死罪能否成立，而不是把「次因」換算成應賠多少成。法院採用初次鑑定，並不表示初次意見永遠優於覆議；重點在於各份意見是否把決定結論的條件算進去。

## 兩審維持無罪，仍不能直接寫成無罪確定

彰化地院於2025年1月8日判B車駕駛無罪；臺灣高等法院臺中分院於2025年5月29日駁回檢察官上訴，維持無罪判決。二審末尾仍記載，檢察官得上訴，但理由受《刑事妥速審判法》第9條第1項三款事由限制。這是在告知對二審判決的後續上訴限制，不是說檢察官先前提起二審上訴也只能援用該條。〔[一審，第9頁][trial]；[二審，第11至12頁][appeal]〕

本次查閱司法院歷審清單只列出這兩筆裁判；沒有另取得確定證明，本文因此只寫「兩審維持無罪」。這項刑事判斷，也不等於已一併處理各車之間所有民事賠償問題。

## 留下證據之前，先離開持續暴露的危險

法院事後可以逐秒核對，事故當下的人卻不能為了湊足某個公尺數，在危險車道裡繼續冒險。高速公路局2026年8月25日的安全提醒，強調採取動作前先確認自身安全，放置標誌須在確保安全的前提下，沿路肩或護欄外行動，並儘速移往安全處所、報警求助，避免逗留車內或車道。該提醒提及的五十至一百公尺，不能取代前述第15條對無法滑離車道情況的一百公尺以上規定。〔[高速公路局安全提醒][safety]〕

因此，不宜把本案駕駛的舉牌動作當成應模仿的處置方式，也不能把判決計算的一百二十五秒拿來等待。若現場條件使某一步無法安全完成，應優先脫離危險、向救援單位說明車輛位置與現況，依現場條件及救援指示處理。

等人員安全、救援處置妥當後，這類爭議值得保存的，是能分出不同階段的資料：初撞到後撞之間的原始連續影像、不同裝置的時間差、初撞後立刻可辨識的燈號與車損，以及拖吊、保管、檢查、修理或報廢的紀錄。若爭議涉及供電，還需要分清車輛系統與紀錄器本身的型號、接線及供電方式；後來整台車的受損照片，未必能單獨回答第一次碰撞後的狀態。

本案真正影響判斷的，是「有沒有時間、機件是否容許」被具體留下來。標誌尚在手中，是畫面裡的一個事實；要由這個事實走到過失致死的刑責，仍須證明當時有能力履行卻未履行，以及犯罪成立所需的其餘條件。
