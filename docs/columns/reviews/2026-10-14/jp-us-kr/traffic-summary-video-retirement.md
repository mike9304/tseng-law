# 교통사고 본문 요약 영상 공개 노출 중단 검수

2026-10-14, Codex 직접 검수. 사용자 요청의 “우리가 설명하는 것을 영상으로 만든 것”을 공개 칼럼에서 제외한다. 사용자가 지목한 특정 파일이나 말하는 아바타의 존재를 단정하지 않는다.

## 범위와 판단 근거

`traffic-column-films.json`의 165개 언어·글 조합(49개 언어, 43개 주제)은 80~240초, 8~24개 장면으로 칼럼 설명을 이어 붙인 레지스트리다. 한국어 `traffic-procedure-film-v1-ko.mp4`의 8개 장면 프레임을 실제 확인했다. 사고 뒤 서류·진료·수리·소득 자료 등의 설명으로 이어진다. 나머지 모든 파일의 전체 프레임을 검수했다는 뜻은 아니다. 레지스트리의 챕터와 설명을 근거로 해당 유형 전체의 공개 선택을 중단한다.

원본 영상 파일·R2 자산·기존 캡션을 삭제하지 않는다. 제품 변경은 `column-generated-videos.ts`의 두 공개 조회 함수에서 이 레지스트리 우선 선택을 제거한 것이다. 별도로 검수된 장면 레지스트리는 유지한다. 다른 비교통 분야 영상이나 개별 장면까지 전부 제거했다는 주장이 아니다.

경찰 자료 글(4언어)과 번체의 시세하락·조정 후 지연손해·사고감정 비율 글에는 별도 검수 영상이 없어 빈 플레이어 없이 본문만 표시한다. 교통 목록의 영상 필터에서도 빠진다. 추격 글은 기존의 독립 장면 두 개를 유지한다. AI 생성·가상 장면·실제 사건 영상이 아니라는 고지를 보존한다.

## 코드·검사 검수

- 먼저 새 회귀검사 4개를 작성했다. 변경 전 4개 모두 예상한 이유로 실패했다(`/tmp/tseng-jp-us-kr-video-red.log`). 변경 후 4개 통과(`/tmp/tseng-jp-us-kr-video-green.log`). 165개 조합에서 두 조회 함수와 실제 React 렌더가 은퇴한 src 또는 챕터 UI를 내보내지 않는지 확인한다.
- 기존 파일의 법률 본문 해시, 금액·판결 확정 여부·언어 범위 검사는 유지했다. 공개하지 않는 합성 영상의 길이·챕터 순서 검사를 실제 공개할 단일/복수 장면의 src·캡션 연결·고지·언어·재생 속성 검사로 바꿨다. 사고 일반 및 추월의 기존 다국어 검사에서 전 언어를 제외하던 film 필터도 제거했다.
- 전체 단위 검사 1,423파일·14,635항목 실행: 1,419파일 통과, 4개 실패는 제거된 요약 영상이 여전히 있다고 기대한 목록/필터 검사였다. 해당 4파일의 기대값을 영상 없는 글의 배제까지 명시하도록 수정했고 32개 재검사 통과. 전체 로그 `/tmp/tseng-jp-us-kr-video-full-suite.log`, 재검사 `/tmp/tseng-jp-us-kr-video-remaining-tests.log`. 최종 전체 재검사·정적 빌드·실제 재생은 후속 기록으로 남긴다.
- 변경 TypeScript lint와 `git diff --check` 통과. 처음 lint 명령은 존재하지 않는 `.tsx` 경로를 전달해 실패했으며, git 변경 파일 목록을 사용한 재실행은 통과했다.
