# 台湾のリチウム電池管理見直し、輸入者の登録と回収費用

新しい指針の公表は、2027年第1四半期が目標です。[11月2日の中央社報道](https://www.cna.com.tw/news/ahel/202611020236.aspx)によると、台湾の環境部長は、リチウム電池の火災を受け、製造、販売、使用から廃棄までを対象とする循環管理の方針を示しました。

日本ブランドのモバイルバッテリーを台湾企業が輸入する取引には、既存の回収制度に基づく登録や費用納付も関わります。報道された新指針の公表予定が、これらの義務の開始日になるわけではありません。

## 完成品の中の電池も対象

台湾の[廃棄物清理法第15条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=O0050001&flno=15)は、回収対象となる物品と、回収・処理等の責任を負う事業者の範囲を、主管機関が指定する仕組みを定めています。輸入する商品の種類と、自社が指定された「責任業者」に当たるかが判断の出発点です。

[資源循環署の案内](https://recycle1.moenv.gov.tw/sys/Business/doc/CommonlyItems.aspx)では、商品に組み込まれた対象電池も制度に含まれます。例として挙がるのは、モバイルバッテリー、スマートフォン、電子時計などです。電池単体に限られません。

ここでいう「乾電池」には、充電式も含まれます。従来から、セル単体が1kg未満の密閉型の小型電池が含まれ、鉛蓄電池や、電解液などを加えて初めて発電するものはこの区分から除かれます。

また、[環境部の公表資料](https://enews.moenv.gov.tw/moenv-news/zh-tw/News/2711)によると、2025年7月1日には、セル単体が1kg以上の充電式リチウム電池も回収対象に加わりました。それより小さい対象電池は、以前から制度に含まれています。重量を確認する際は、組み立て前のセルと製品全体を区別する意味があります。

## 費用の基準になる輸入量

まだ販売していない在庫はどうでしょうか？　[第16条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=O0050001&flno=16)は、指定された責任業者に登録を義務づけ、輸入業者には税関に申告した輸入量を基準とする回収・処理等の費用納付を求めています。販売済みの数量だけで判断する制度ではありません。

控除の余地もあります。台湾で廃棄されない物品や、使用後に廃棄物が出ない物品については、証明書類を添えて輸入量等の控除や返金を申請できます。

確認する資料は輸入者で変わります。台湾の販売会社が輸入するのか、別の商社が輸入するのかを販売契約で確かめると、必要な登録記録や通関資料の所在も分かります。電池の種類やセル重量が分かる日本側の製品仕様と照らし合わせれば、申告対象の区分や数量を具体的に検討できます。

電池製品の管理をイメージして生成した架空の写真です。実際の事故製品や回収現場を撮影したものではありません。
