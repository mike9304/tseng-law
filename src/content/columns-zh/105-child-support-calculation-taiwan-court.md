# 離婚後子女扶養費怎麼算：生活支出、父母分擔與逾期給付

子女扶養費要分開算兩件事：孩子每月合理需要多少，以及父母各自負擔多少。[民法第1119條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=1119)要求衡量受扶養人的需要與義務人的經濟能力、身分；[第1115條第3項](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=1115)則規定，同親等的扶養義務人應依各自經濟能力分擔。因此，查到一個縣市的平均消費支出，還不能直接得出另一方每月應匯多少錢。

與外籍配偶離婚時，[涉外民事法律適用法第57條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000007&flno=57)以扶養權利人的本國法決定扶養的準據法，不能只看付款父母的國籍或工作地。以下說明限於適用台灣法的未成年子女扶養費；孩子有多重國籍、住在海外或已有外國裁判時，需要另外確認準據法與既有裁判的效力。

## 離婚後，沒有同住的一方仍有扶養義務

[民法第1084條第2項](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=1084)規定，父母對未成年子女有保護及教養的權利義務。[第1089條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=1089)以父母共同負擔為原則，並規定不能共同負擔時由有能力者負擔；[第1116條之2](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=1116-2)更明定，扶養義務不因婚姻經撤銷或離婚而受影響。沒有與孩子同住、或離婚後由另一方行使親權的父母，仍要負擔扶養費。

也因此，討論離婚扶養費時，需要先說清楚款項是為了孩子的生活，還是夫妻之間的財產分配。協議若把不同款項合寫成一筆「補償金」，日後容易對支付目的和涵蓋期間產生爭議。夫妻財產另見[跨國夫妻的財產，適用哪一國法律](/zh-hant/columns/taiwan-marital-property-regime-international-couples)。

## 平均每人月消費支出，是哪一年的數字？

法院估算生活費時，可參考行政院主計總處家庭收支調查的「平均每人月消費支出」。例如後述臺北地院案件，就把當時的地區統計與孩子的實際支出、父母資力一起考量。

截至2026年10月3日查閱的[主計總處原始統計表](https://ws.dgbas.gov.tw/001/Upload/463/relfile/10315/1259/4.xls)，114年（2025年）資料包括下列數值，單位為新臺幣元／人／月：

| 統計範圍 | 114年平均每人月消費支出 |
| --- | ---: |
| 總平均 | 28,513 |
| 新北市 | 30,364 |
| 臺北市 | 36,654 |

資料入口是[家庭收支調查常用資料](https://www.stat.gov.tw/cp.aspx?n=3914)中的「平均每人月消費」。114年是調查資料的年度，不是「115年法院扶養費標準」。原表也提醒，縣市樣本數有限，應考量抽樣誤差，不宜據此作嚴謹的縣市排名。

這張表並未替不同年齡的孩子訂出統一價目。孩子住在哪裡、讀什麼學校、是否需要托育或持續治療，都可能影響實際需要。引用統計時，可以註明年度、地區與選用理由，再說明孩子的支出為何接近或偏離該數值。孩子戶籍設在臺北市、實際卻住在別的縣市時，要把實際居住地和支出資料一併說明。

統計與單據的用途不同：統計提供生活水準的參照，單據說明這個孩子實際需要什麼。若以平均消費作基礎，又把餐費、交通費等全部加上去，可能把同一筆需要算兩次；主張另加的支出，應說明原先估算是否已經涵蓋。

## 孩子的費用明細怎麼整理

日常餐食、交通、托育或課後照顧，可以按實際支付期間整理；每學期繳一次的學雜費，則可列出原始金額、涵蓋月份與換算方式。這是為了讓雙方或法院看懂支出，不表示每一筆提出的費用都會被全額採認。[民法第1119條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=1119)仍要求一併衡量孩子需要與父母負擔能力。

醫療或特殊照顧費用，可以附診斷、療程、估價或收據，說明支出原因與頻率。只寫「醫療費很多」，無法看出是固定治療、單次手術，還是尚未確定的預估。反過來說，尚未支付的必要治療，也不能只因還沒有收據，就在整理資料時漏掉；可把預估與已支出分開列明，讓法院就個案判斷。

全家的房租、水電等共同支出，則需要說明如何計入孩子的生活費。把整戶費用全部算在一名孩子身上，會使總額失去依據。若另一方已直接繳付學費或托育費，也可註記付款人、日期與用途，讓雙方確認這筆錢是否納入原有扶養安排，避免各算各的。

## 父母的收入比例，還要連同照顧負擔一起看

依經濟能力分擔，不等於只拿某個月的薪資相除。收入證明、歷年所得、財產與工作能力，能呈現不同面向；負擔較多日常照顧的一方，也不只是提供現金。接送、陪診、處理學校事務等照顧安排，可以具體說明由誰負責，讓分擔比例的討論有依據。

在[臺灣臺北地方法院111年度婚字第155號、112年度家親聲字第50號及第80號合併裁判](https://judgment.judicial.gov.tw/FJUD/printData.aspx?id=TPDU%2C112%2C%E5%AE%B6%E8%A6%AA%E8%81%B2%2C80%2C20240402%2C1)中，法院於2024年4月2日參考108至111年度臺北市消費統計、孩子的實際開銷、雙方所得與財產，也考量付款一方再婚後仍須扶養其他子女，以及主要照顧者付出的勞務。綜合這些情況，法院認定孩子每月需要33,000元，由另一方負擔三分之二，即每月22,000元，按月支付至孩子滿18歲之日止。

這件案子的父母並不是經這份判決離婚，而是法院確認兩人的婚姻關係不存在，理由是前婚姻依法視為消滅。法院在理由伍、五㈠說明，應類推適用[民法第1116條之2](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=1116-2)處理子女扶養義務。這是地方法院的個案判斷，本文未確認後續上訴或確定情形；33,000元與三分之二都不是其他家庭可直接套用的標準。

這個算式裡，33,000元是孩子所需總額，22,000元才是法院命另一方支付的金額。討論自己案件的金額時，也可以分別提出生活費估算與分擔理由，避免把「孩子花多少」和「向對方請求多少」混成一個數字。

如果父母一方在海外工作，整理薪資時可保留原幣金額，標明是哪段期間、稅前或稅後收入，是否包含獎金，再附新臺幣換算及匯率依據。海外生活負擔也應有資料支持。僅把一筆外幣月薪換成台幣，無法完整呈現其經濟能力；台灣所得資料未列出的海外收入，也應另行說明。

## 一次付清、按月支付，以及逾期後的金額

[家事事件法第100條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0010048&flno=100)容許法院審酌情況，命一次給付、分期給付或給付定期金，必要時命提出擔保，且不受聲請人聲明拘束；子女扶養費給付方法依[第107條第2項](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0010048&flno=107)準用相關規定。希望對方一次付清，要向法院說明具體理由，由法院決定是否採用。

每月持續發生的扶養費，與把一筆既定總額拆成數期支付，要分清楚。第100條第3項處理分期給付，第4項處理定期金；法院得就逾期時哪些款項提前到期，酌定範圍或條件。實際請求時，要回到裁判主文，不能自行假定餘下所有月份都到期。

前述[臺北地院裁判主文第三項及理由伍、五](https://judgment.judicial.gov.tw/FJUD/printData.aspx?id=TPDU%2C112%2C%E5%AE%B6%E8%A6%AA%E8%81%B2%2C80%2C20240402%2C1)，寫明遲誤一期時，後面六期也視為到期。也就是後面六期的付款期限提前，總金額沒有增加；六期是法院在這個案件酌定的範圍。

「加給金額」則另見[第100條第4項](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0010048&flno=100)：法院得酌定，但不得超過每期定期金金額的二分之一。二分之一是上限，是否加給、加多少，由法院在裁判中酌定；它和提前到期是兩種不同的安排。

## 跨國匯款的約定與日後變更

雙方談妥按月給付時，可以把每期金額、幣別、付款日及收款帳戶寫清楚。從海外匯款的家庭，還可約定匯費由誰負擔、外幣如何換算，以及以哪個時間點判斷付款是否完成，避免匯出金額與實收金額長期有落差。

對於未計入每月金額的重大醫療或教育費用，可另談範圍、分擔比例、通知方式與憑證；如有緊急醫療需要，也可把無法事前商量的情況納入安排。泛寫「額外支出另計」，到了付款時仍可能無法判斷哪些費用在約定範圍內。

金額確定後，孩子的需要或父母的經濟情況仍可能改變。[民法第1121條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=1121)容許當事人因情事變更，請求變更扶養的程度及方法。若給付已由確定裁判或成立的和解定下來，尚未履行的內容因情事變更而顯失公平，可依[家事事件法第102條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0010048&flno=102)聲請法院變更；子女扶養費依第107條第2項準用此規定。主張調整時，可比較原來與現在的支出、收入及照顧安排，說明改變了什麼；僅提出變更要求，不能直接當作既有付款義務已經減少。

若問題已是對方不付款，或手上只有外國法院的裁判，接下來涉及執行名義及財產所在地，詳見[子女扶養費的跨國執行](/zh-hant/columns/taiwan-child-support-enforcement-cross-border)。
