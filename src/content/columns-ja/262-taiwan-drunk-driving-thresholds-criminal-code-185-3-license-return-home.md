# 台湾の飲酒運転：呼気0.15と0.25の線、刑法185条の3、免許と帰国

呼気1リットル中0.15ミリグラム。この数字が、台湾で運転してはいけなくなる線です。[道路交通安全規則第114条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=K0040013&flno=114)は、酒類を飲んで呼気中のアルコール濃度が0.15ミリグラム以上、または血中濃度0.03パーセント以上になった人は運転してはならないと定めています。日本の[道路交通法施行令第44条の3](https://laws.e-gov.go.jp/law/335CO0000000270)が酒気帯び運転の基準とする呼気0.15ミリグラムと同じ数値なので、「日本なら捕まる量」はそのまま台湾でも違反です。

違うのはその先です。刑事罰の線と、処分の重さが変わります。

## 0.25ミリグラムから刑法の犯罪になる

[刑法第185条の3](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0000001&flno=185-3)は、動力交通工具を運転して呼気中アルコール濃度が1リットルにつき0.25ミリグラム以上、または血中濃度0.05パーセント以上だった人に、3年以下の有期徒刑を科し、30万台湾元以下の罰金を併科できると定めています。数値に達していなくても、酒類などを飲んで安全に運転できない状態だったと認められる他の事情があれば、同じ条文の第2号で処罰されます。

人を死なせた場合は3年以上10年以下、重傷を負わせた場合は1年以上7年以下の有期徒刑で、罰金の上限もそれぞれ200万元、100万元に上がります。過去にこの罪で有罪判決または緩起訴処分が確定し、10年以内に再び犯して人を死なせた場合は無期徒刑または5年以上の有期徒刑です。

0.25未満なら、第2号に当たる事情がない限り刑事事件にはならず、次に述べる行政処分だけが問題になります。濃度が0.15未満なら処分はありません。検問で吹いた数字がどの区間にあるかで、その後の手続が分かれます。

## 行政処分：罰鍰、車両の保管、免許の吊扣

[道路交通管理処罰条例第35条](https://law.moj.gov.tw/LawClass/LawOldVer.aspx?pcode=K0040012&lnndate=20260114&lser=001)は、検査でアルコール濃度が基準を超えた運転者に、機車（バイク）なら1万5千元以上9万元以下、汽車（自動車）なら3万元以上12万元以下の罰鍰を科し、その場で車両を移置保管し、免許を1年から2年吊扣（停止）すると定めています。12歳未満の子どもを乗せていた場合や事故で人にけがをさせた場合は吊扣が2年から4年に延び、重傷や死亡の場合は免許を吊銷（取消し）したうえで再取得できません。以上は2026年10月6日時点の施行条文です。罰鍰を引き上げた2026年8月17日公布の[改正35条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=K0040012&flno=35)は[施行日が未定です](https://law.moj.gov.tw/LawClass/LawHistory.aspx?pcode=K0040012)。

同じ条文は、2019年4月17日に改正公布された規定の施行日から10年以内に2回目の違反をした人には罰鍰の上限額を科し、3回目以降はさらに9万元ずつ加算すると定め、車両の移置保管と免許の吊銷も伴います。主管機関は氏名と写真を公表できます。

検査を拒むと処分は重くなります。検問で停止の指示に従わなかった場合、検査を拒否した場合、検査前に飲酒した場合は18万元の罰鍰で、車両は保管され免許は吊銷されます。事故を起こして検査ができない状態のときは、司法警察が検察官の鑑定許可を得て医療機関で採血し、血中濃度を測ることができます。

同乗者にも罰則があります。運転者が0.25ミリグラム以上だった場合、18歳以上の同乗者は6千元以上1万5千元以下の罰鍰の対象です。70歳以上の人や運輸業の乗客は除かれます。レンタル業者が処罰規定を告知する義務を果たしていたのに運転者が違反した場合、運転者の罰鍰は2分の1加算されます。契約書に飲酒運転の注意書きがあるのは、この規定のためです。

免許が吊銷された後の再取得は[第67条](https://law.moj.gov.tw/LawClass/LawOldVer.aspx?pcode=K0040012&lnndate=20260114&lser=001)が定めていて、事由によって1年から5年、あるいは終身にわたって再取得できません。吊銷された人は、酒駕防制教育や酒癮治療を終えなければ再取得の申請ができません。この再取得の制限は、台湾の免許を持っていない人にも適用されます（第67条第7項）。

## 刑事事件になった後の流れ

呼気0.25ミリグラム以上で検挙されると、警察は刑法第185条の3の事件として検察官に送致します。取調べの前に黙秘権と弁護人選任権が告げられ、中国語が分からなければ通訳が付きます（[刑事訴訟法第95条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0010001&flno=95)、[第99条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0010001&flno=99)）。逮捕から取調べ、羈押の判断までの流れは[台湾で日本人が警察の取調べや逮捕を受けたら](/ja/columns/japanese-arrested-questioned-in-taiwan-interpreter-lawyer-detention)で説明しています。

繰り返しの危険を理由にした羈押も関係します。飲酒運転は、[第101条の1](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0010001&flno=101-1)が「同じ犯罪を繰り返すおそれ」を理由にした羈押の対象として明記している罪の一つです。羈押には「繰り返すおそれ」を示す事実が要りますが、条文上は対象だということは知っておく価値があります。

有罪になった場合の刑の執行には、台湾の刑法に二つの緩和の仕組みがあります。[第41条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0000001&flno=41)の易科罰金は、最高刑が5年以下の罪で6か月以下の有期徒刑または拘役を言い渡された場合に、1日を1千元、2千元または3千元に換算して罰金で済ませる制度です。[第74条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0000001&flno=74)の緩刑は、2年以下の有期徒刑などを言い渡された初犯者などに、2年以上5年以下の猶予期間を付ける制度で、公庫への支払いや義務労務、戒癮治療などが条件として付くことがあります。どれが適用されるかは個別の判断で、台湾人と外国人で条文の扱いは変わりません。

## 検察官の段階で終わることもある：緩起訴

死刑、無期徒刑、最低刑が3年以上の重い罪を除き、検察官は[刑事訴訟法第253条の1](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0010001&flno=253-1)により、刑法第57条の事情と公共の利益を考えて適当と判断すれば、1年以上3年以下の期間を定めて緩起訴（起訴猶予に似た処分）にできます。刑法第185条の3の基本の罪は最高刑が3年以下なので、この処分の対象になり得ます。

緩起訴には[第253条の2](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0010001&flno=253-2)の条件が付くことがあります。被害者への謝罪、悔過書、損害賠償、公庫への一定額の支払い、40時間以上240時間以下の義務労務、戒癮治療などで、金銭の支払いと治療・労務については本人の同意が要ります。期間中に条件を守れば起訴されずに終わりますが、刑法第185条の3の再犯加重の規定は「緩起訴処分が確定した」場合も前歴として数えるので、処分が軽く見えても記録としては残ります。

## 事故を伴った場合：相手のけがは親告罪

人にけがをさせた場合は、刑法第185条の3の罪とは別に、[刑法第284条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0000001&flno=284)の過失傷害罪（1年以下の有期徒刑、拘役または10万元以下の罰金、重傷なら3年以下の有期徒刑など）が問題になります。この罪は[第287条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0000001&flno=287)により告訴がなければ起訴できない親告罪で、[刑事訴訟法第237条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0010001&flno=237)により告訴できる人が犯人を知った時から6か月以内に告訴する必要があります。

実務では、被害者との示談が成立して告訴が取り下げられれば過失傷害の部分は終わりますが、飲酒運転そのものは親告罪ではないため、示談だけでは刑法第185条の3の事件は消えません。この二つを分けて考えることが、示談交渉の見通しを立てるときの出発点になります。民事の賠償項目は[台湾の交通事故Q&A](/ja/columns/taiwan-traffic-accident-procedure)で扱っています。

## 帰国の予定と、処分を待つ時間

事件が刑事手続に入ると、帰国便の日までに検察官の処分が出るとは限りません。逮捕そのものは出国を禁じませんが、[第93条の2](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0010001&flno=93-2)の限制出境が命じられると出国できず、保証金を積んで釈放されるときに[第93条の6](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0010001&flno=93-6)で出国制限が併せて付くこともあります。

出国制限がなく帰国する場合でも、事件は台湾で続きます。検察官の[伝票](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0010001&flno=71)に正当な理由なく応じなければ拘提の対象になり、次に台湾へ入ったときに問題が表面化します。帰国前に、台湾で書類を受け取り検察官とやり取りする弁護人を決め、日本の連絡先を届け出ておくのが、事件を放置しないための現実的な手当てです。

検挙後の対応や、帰国と処分の時期の調整については、昊鼎国際法律事務所（wei@hoveringlaw.com.tw）に日本語で相談できます。日時と場所、呼気の数値、受け取った書類、帰国便の予定が分かれば、取るべき手順を具体的に検討できます。
