## §1223 개정 처리 (FINDINGS F-002 중복 보고 아님, 확인 결과만)
- 새 §1223 문언: 「一、配偶之特留分，為其應繼分二分之一。二、直系血親卑親屬…二分之一。三、父母…二分之一。四、祖父母之特留分，為其應繼分三分之一。」(兄弟姊妹 삭제). 民法 沿革 37: 「中華民國一百十五年八月十七日…令修正公布第 1223 條條文；並自公布六個月後施行」.
- 民法繼承編施行法 新增 §12: 「中華民國一百十五年七月二十八日修正之民法第一千二百二十三條，自公布六個月後施行，不適用前條第二項規定。」(§11②는 修正條文 「自公布日施行」 일반 원칙) → 칼럼 L17·L46 「依民法繼承編施行法第12條須自公布六個月後施行」 정확. 시행 예정일은 2027-02-17(공포 2026-08-17+6개월)이고 칼럼은 날짜를 적지 않고 「截至2026年10月4日…仍未施行」로 서술 — 오늘(2026-10-07)도 미시행이라 유효.
- 수정 전 §1223(LawOldVer, 110-01-20판): 「直系血親卑親屬…二分之一。父母…二分之一。配偶…二分之一。兄弟姊妹之特留分，為其應繼分三分之一。祖父母…三分之一。」 → 칼럼 L42(배우자·직계비속·부모 1/2, 형제자매·조부모 1/3) 일치. 칼럼은 새 규칙을 시행 중으로 쓰지도, 옛 규칙을 개정 언급 없이 현행으로 쓰지도 않음.
- 인용 조문 중 2025-01-01 이후 개정: 民法은 §1223뿐. 家事事件法 §3 · 96 · 185는 112-06-21 개정분이 司法院令으로 2026-08-01 시행(칼럼 인용 §3의 丙類 6호 「因繼承回復、遺產分割、特留分、遺贈、確認遺囑真偽…」 문언은 시행본에서도 동일). 涉外民事法律適用法 최종 99-05-26, 民法繼承編施行法 §12 외 변경 없음.
