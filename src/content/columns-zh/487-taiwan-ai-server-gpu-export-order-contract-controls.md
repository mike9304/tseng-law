AI 伺服器訂單已經收取訂金，仍不能據此放行出貨。貨品如屬台灣戰略性高科技貨品（SHTC），《貿易法》第13條以取得許可為輸出原則，並要求據實申報用途及最終使用人，非經許可不得擅自變更；是否符合管理辦法的免發許可證條件，也須另行核對。[貿易法第13條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=J0090004&flno=13)、[管理辦法第15條](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=J0090013)

因此，報價中的交期與付款安排，宜說明許可未取得、客戶用途資料不完整或配置改變時如何處理。「遵守出口管制」六個字，沒有直接回答已付訂金是否返還、備妥的貨物由誰保管，以及等待期間的費用由誰負擔。

## 報價附件要能指認實際交付的配置

採購單只寫「AI 伺服器」，不足以判定品項是否列管。貿易署2026年8月14日公布的判斷流程，先列出型號、功能、技術參數、零組件及軟體、技術文件等資料，再比對管制清單；仍無法判斷時，可備妥規格申請貨品鑑定。[貿易署許可判斷流程](https://www.trade.gov.tw/Pages/Detail.aspx?nodeid=5146&pid=819076)

實務上可由工程確認 GPU 型號、數量、運算配置及隨附軟體，由業務把同一版本納入報價附件。替代料、升級卡或另外交付的技術文件，宜留下變更紀錄。這是供內部審查與履約核對的建議，不是認定所有 GPU 都受管制，也不是由商品名稱直接推定管制代碼。

分類應使用交易時適用的規定。貿易署2026年2月11日修正的軍商兩用貨品及技術、一般軍用貨品清單自該日生效；清單外貨品仍有交易對象與用途的判斷分支，輸往俄羅斯或白俄羅斯另須核對相關高科技貨品清單。[清單修正公告](https://www.trade.gov.tw/Pages/Detail.aspx?nodeid=39&pid=811499)、[貿易署判斷流程](https://www.trade.gov.tw/Pages/Detail.aspx?nodeid=5146&pid=819076)

## 許可由誰申請，資料由誰補齊

需要申請 SHTC 輸出許可證時，出口人須依管理辦法第16條提出申請書、所需用途證明或保證文件、相關交易文件等，並據實申報用途及最終使用人。客戶簽一張保證書，不會把出口人的法定義務移轉出去。[管理辦法第16條](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=J0090013)

契約可約定由哪一方負責申請、誰向實際使用者取得資料，以及補件期限。若買主是經銷商，宜請其交代買主、付款人、收貨人與最終使用人的關係，讓部署地點與用途連得上實際訂單。這些角色不一致並不當然違法，但若只留下買主資料，出口人可能無法回答誰會使用這批設備。

貿易署指引另要求注意列管實體及軍事用途；沒有比中名稱，不能取代用途判斷。當客戶稱供研究使用，文件卻指向不同收貨地點或營運者，宜先請其說明差異，必要時向貿易署提出具體規格與用途疑點。以「民用」二字完成欄位，未必足以釐清矛盾。[貿易署許可判斷流程](https://www.trade.gov.tw/Pages/Detail.aspx?nodeid=5146&pid=819076)

## 交期條款要能處理等待、拒發與客戶改單

以下是供貨契約可協商的事項，並非法律自動給予賣方的免責或扣款權：

| 發生的情況 | 契約宜先說明的處理 |
| --- | --- |
| 客戶尚未交齊用途資料 | 補件期限、通知方式，以及製造或出貨時程如何順延。 |
| 許可仍在審查 | 預估交期是否重新確認、最長等待期限、貨物保管與費用。 |
| 許可遭拒或附帶無法履行的條件 | 是否終止、訂金與已付款返還方式，以及已完成客製部分的處理。 |
| 客戶要求換料、改收貨地或使用人 | 重新審查所需資料、暫緩交付的範圍及增加費用如何確認。 |

客製機櫃已組裝完成與標準品尚未備貨，可能有不同的成本安排。若要主張不可返還的費用，宜在締約時界定項目與計算依據；不能等到許可遭拒，才把所有成本統稱為違約金。反過來，約定退款也不代表貨物可先交出去，再補辦許可。

## 出貨前的最後核對，包含臨時換料與改址

管理辦法第19條要求按許可核准內容輸出，內容變更可在有效期限屆滿前檢附證明申請；許可證有效期限屆滿後不得申請展延。既有許可不能直接拿來涵蓋涉及核准內容變更、卻尚未獲准的新配置或新交易安排。[管理辦法第19條](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=J0090013)

企業可指定人員把實際出貨規格、收貨資訊、用途文件與許可內容逐項對照。有差異時先回到出口管理人員確認所需程序，不宜讓物流人員只因系統顯示「已付款」就放行。這種內部分工與表單格式屬管理建議，重點是讓改單訊息在貨物離開前到達有權處理的人。

## 美國規則的適用，另按交易事實判斷

取得台灣許可，不能直接回答美國出口管理規則（EAR）是否適用。EAR第734.3節涵蓋美國境內、美國原產物項，並在特定條件下及於含受管制美國內容或符合外國直接產品規則的外國製品，另有排除規定。台灣製造不能單獨排除 EAR，使用美國技術也不表示全部產出都當然受管制；應先核對物項來源、組成與相關製造事實，再判斷後續許可要求。[EAR第734.3節](https://www.ecfr.gov/current/title-15/subtitle-B/chapter-VII/subchapter-C/part-734/section-734.3)

台灣管理辦法第21條要求 SHTC 輸出入相關文件或資料保存五年。出貨結束後，仍宜將報價版本、用途資料、許可、實際出貨內容與變更往來連到同一訂單；日後遇到查核或交期爭議，才看得出當時哪一項事實改變，以及雙方如何處理。[管理辦法第21條](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=J0090013)
