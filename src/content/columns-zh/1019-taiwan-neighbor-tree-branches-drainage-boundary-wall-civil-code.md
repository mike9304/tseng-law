# 鄰居的樹枝伸過來、屋簷雨水往我家倒、圍牆蓋過界：透天厝之間的相鄰關係

隔壁芒果樹的果子自己掉進你家院子，就是你的。[民法第798條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=798)寫得很直接：「果實自落於鄰地者，視為屬於鄰地所有人。」唯一的例外，是掉落的鄰地屬於公用地。果實有這麼乾脆的答案。伸過牆的樹枝、鑽過地界的樹根、從隔壁屋簷灌下來的雨水、蓋過界的圍牆和房子，法律都另外安排了順序和條件。

這些問題規定在民法物權編的相鄰關係，也就是第774條到第800條。開頭的[第774條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=774)要求土地所有人經營事業或行使所有權時，應注意防免鄰地之損害。本文只談透天厝、低樓層住宅彼此相鄰的情形。公寓大廈裡的樓上漏水和管委會問題，另見[公寓大廈管委會的文章](/zh-hant/columns/taiwan-apartment-management-committee-fees-rules)；鄰居施工造成的房屋龜裂等損害，也不在本文範圍。

## 越界的樹枝和樹根：先請對方剪，期限過了才自己動手

[民法第797條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=797)第1項規定，鄰地植物的枝根越過地界時，土地所有人得向植物所有人請求於相當期間內刈除。多久算「相當」，條文沒有寫天數。修幾根細枝和處理大樹的根系，需要的時間差很多；用存證信函或其他書面寫明範圍和期限寄給對方，日後爭執期間是否相當時，手上就有東西可以拿。

對方在期間內沒有剪，才輪到第2項：土地所有人得刈取越界之枝根，並請求償還因此所生之費用。能剪的是「越界」的部分。把整棵樹砍掉，或是剪到地界內側，這一條都沒有給這個權利。

沒先通知就直接剪，會怎樣？第797條把「請求」和「期間經過」當作自己刈除的前提。跳過這個順序把樹弄傷，樹的所有人就有機會依[第184條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=184)第1項，以故意或過失不法侵害其權利為由請求賠償。

第3項還有一道門檻。越界枝根對土地利用沒有妨害時，前兩項都不適用。樹蔭讓菜園長不出東西、樹根把排水管或院子地坪頂起來，這類實際影響最好拍照並記下日期，爭執「有無妨害」時派得上用場。

剪樹能不能走進鄰居院子？[第790條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=790)允許土地所有人禁止他人侵入其地內，例外只有他人有通行權，或依地方習慣進入未設圍障的田地、牧場、山林刈取雜草、採取枯枝等情形。從自己這側搆不到的工作，要先取得鄰居同意。

## 雨水與排水：自然流過來的水，和屋簷倒過來的水

下雨時，地勢高的那一邊會把水往低的這一邊送。這種水擋不得。[第775條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=775)第1項規定土地所有人不得妨阻由鄰地自然流至之水；第2項則是說，自然流至之水為鄰地所必需者，土地所有人即使因自己土地利用的必要，也不得妨阻其全部。

人為設施引過來的水，就是另一套規則。[第777條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=777)規定，土地所有人不得設置屋簷、工作物或其他設備，使雨水或其他液體直注於相鄰之不動產。隔壁雨水管出口正對你家院子，或冷氣排水直接從牆頭滴下來（虛構情境），要求對方改管線方向，就從這一條出發。

鄰居如果回一句「水本來就往低處流」呢？第775條保護的是「自然」流至的水。屋簷、雨水管或排水管把雨水直接倒在你家土地上，是設備造成的「直注」，落在第777條禁止的範圍。同樣經過屋頂和雨水管的水，如果先落在鄰居自己的土地，再順著地面流過來，仍是第775條的自然流至之水。兩條要分開看；分辨時，看的是水是否從對方設備直接注入你家的不動產。

| 水從哪裡來 | 條文 | 條文怎麼規定 |
|---|---|---|
| 從鄰地自然流過來 | 第775條 | 不得妨阻；鄰地所必需的水，即使自己土地利用有必要，也不得妨阻其全部 |
| 屋簷、工作物或設備直接倒過來 | 第777條 | 不得設置這類設施 |
| 蓄水、排水、引水設施破潰或阻塞，損害他人土地或有損害之虞 | [第776條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=776) | 設施所在的土地所有人以自己費用修繕、疏通或預防；費用負擔另有習慣者從其習慣 |
| 水流因事變在鄰地阻塞 | [第778條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=778) | 土地所有人得以自己費用為必要疏通之工事；鄰地所有人受有利益者，按受益程度負擔相當費用；費用負擔另有習慣者從其習慣（第2項） |
| 使浸水之地乾涸，或排泄家用及其他用水 | [第779條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=779) | 得使水通過鄰地至河渠或溝道，應擇損害最少之處所及方法，對鄰地損害支付償金 |

第779條另外設了解決爭議的出口。鄰地所有人對通過的處所或方法有異議時，有通過權之人或異議人都可以請求法院以判決定之（同條第4項）。法令另有規定或另有習慣者，從其規定或習慣（第3項）。

損害還沒發生，第776條也能用。隔壁院子的集水井和排水溝被落葉塞住，一下大雨水就從牆腳漫過來（虛構情境），只要有致損害之虞，設施所在的土地所有人就應以自己的費用疏通、修繕。積水的照片和下雨的日期，就是證明「之虞」的材料。

## 說對方圍牆或房子蓋過界，先申請鑑界

界線在哪裡吵不出結果時，先量。依土地法第47條訂定的[地籍測量實施規則](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=D0060053&flno=204)第204條第6款，把鑑界列為申請土地複丈的事由；[第205條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=D0060053&flno=205)規定由土地所有權人或管理人向土地所在地登記機關申請，或利用網路以電子簽章方式為之，也可以委託代理人（同條第3項）。

登記機關排定日期後，會通知申請人和關係人；鑑界時的關係人，就是申請案所載鑑界界址的鄰地所有權人（[第211條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=D0060053&flno=211)第1項、第3項）。鄰居不到場，照樣可以逕行複丈（同條第4項）。申請人自己沒到，或沒有依規定埋設界標，就視為放棄複丈申請，已繳的複丈費不退（同條第2項）。

對結果不服，還有一次機會。依[第221條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=D0060053&flno=221)第1項第2款，申請人可以敘明理由、再繳複丈費申請再鑑界，由直轄市或縣（市）主管機關派員辦理。鑑界和再鑑界測定的界址點，由申請人和到場關係人當場認定，並在土地複丈圖上簽名或蓋章；不簽的，複丈人員要在圖上載明事由（同條第2項）。不服的是鄰居，鄰居可以用自己的土地申請鑑界，走同樣的異議程序（同條第3項）。

## 房子越界，拆不拆有三條規定把關

量出來房子確實越界，也不等於馬上拆。[第796條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=796)第1項規定，土地所有人建築房屋非因故意或重大過失逾越地界，鄰地所有人如知其越界而不即提出異議，不得請求移去或變更其房屋；越界的一方則要對鄰地所受損害支付償金。鄰地所有人也可以請求對方以相當價額，購買越界部分的土地及因此形成的畸零地，價額由雙方協議，談不攏就請法院判決（同條第2項）。

時間點決定結果。鄰居施工看起來越界，當下就用書面提出異議，日後才保得住請求拆除的路，因為第796條擋下拆除請求的條件之一，正是「知其越界而不即提出異議」。

當時有異議，法院仍然可能免拆。[第796條之1](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=796-1)第1項讓法院在鄰地所有人請求移去或變更時，斟酌公共利益及當事人利益，免為全部或一部之移去或變更；但土地所有人故意逾越地界者，不適用。免拆時，第796條第1項但書的償金和第2項的購買請求一併準用（同條第2項）。

圍牆呢？[第796條之2](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=796-2)只把前兩條準用於「具有與房屋價值相當之其他建築物」。一道圍牆夠不夠格，要看構造和價值。不夠格，就沒有這套保護，鄰地所有人回到[第767條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=767)第1項，請求除去妨害其所有權的部分。

## 排除妨害和損害賠償，是兩筆帳

第767條第1項讓所有人對妨害其所有權者請求除去，有妨害之虞者請求防止。要求改雨水管方向、移走越界的構造物，都屬於這一類。已經造成的損害，另外依第184條第1項請求賠償；賠償原則上是回復損害發生前的原狀（[第213條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=213)第1項），債權人也可以請求支付回復原狀所必要的費用，以代回復原狀（同條第3項）。外牆被雨水泡到油漆剝落，修繕估價單就是請求金額的依據。

房客也有份。[第800條之1](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=800-1)把第774條至第800條準用於地上權人、承租人及其他土地、建築物利用人，租透天住的外籍房客，也能自己依第797條請鄰居剪枝、依第777條要求改善。第767條則限於所有權和其他物權（同條第2項），走到拆除越界構造物這一步，和房東一起出面比較順。外國人在台灣取得不動產的條件，整理在[外國人在台灣取得不動產的文章](/zh-hant/columns/foreigners-buying-property-in-taiwan)。

## 起訴前要先調解

相鄰糾紛直接遞狀，多半還是會先被送去調解。[民事訴訟法第403條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0010001&flno=403)第1項把「不動產所有人或地上權人或其他利用不動產之人相互間因相鄰關係發生爭執者」（第1款）和「因定不動產之界線或設置界標發生爭執者」（第2款），列為起訴前應經法院調解的事件，除非有[第406條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0010001&flno=406)第1項各款情形，例如調解顯無成立之望，或已經其他法定調解機關調解未成立。沒有這些事由卻逕行起訴，視為調解之聲請（[第424條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0010001&flno=424)第1項）。

聲請調解時，要表明調解標的之法律關係及爭議情形；有文書為證據的，應提出原本或影本（[第405條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0010001&flno=405)第2項）。寄過的存證信函、鑑界後的土地複丈成果圖、積水和樹根頂起地坪的照片，這時都該一起附上。

離家最近的窗口是鄉、鎮、市公所的調解委員會，民事事件都可以聲請（[鄉鎮市調解條例第1條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=I0020003&flno=1)）。除了勘驗費要核實開支，不收任何費用（[第23條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=I0020003&flno=23)）。民事事件要對方同意才能進行（[第11條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=I0020003&flno=11)）；兩造住同一鄉鎮市，就由那裡的調解委員會處理（[第13條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=I0020003&flno=13)第1款）。調解成立後送法院審核（[第26條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=I0020003&flno=26)），經法院核定的民事調解與民事確定判決有同一效力，同一事件不能再起訴（[第27條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=I0020003&flno=27)）。在公所調不成，正好就是第406條第1項第2款的情形。反過來，案子已經在第一審法院，法院也可以裁定把第403條第1項的事件移付公所調解委員會，期間訴訟程序停止；調解委員會受理後二個月內沒有調成，就把案子送回法院續行訴訟（[第12條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=I0020003&flno=12)第1項第1款、第2項）。訴訟中在公所調解成立並經法院核定，訴訟就終結，原告得於核定調解書送達之日起三個月內，聲請退還已繳裁判費的三分之二（[第28條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=I0020003&flno=28)第1項）。但第一審已經辯論終結的事件，就不能再向公所聲請調解（[第10條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=I0020003&flno=10)第3項）。

真的打官司，管轄也先定好了。因不動產經界涉訟，專屬不動產所在地法院管轄（[民事訴訟法第10條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0010001&flno=10)第1項）；定不動產界線或設置界標的訴訟，不問金額一律適用簡易程序（[第427條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0010001&flno=427)第2項第5款）。

## 律師可以處理的部分

律師可以依第797條擬寫刈除請求並訂出期間，依第777條、第767條寫改善或除去妨害的存證信函，代為申請鑑界、到場會同，撰寫再鑑界的異議理由。調解時代為協商條件，調解不成立則代理除去妨害、確定界線或損害賠償訴訟。所有權人人在國外，鑑界申請也可以委託代理人辦理（地籍測量實施規則第205條第3項）。昊鼎國際法律事務所諮詢信箱：[wei@hoveringlaw.com.tw](mailto:wei@hoveringlaw.com.tw)（[服務說明](/zh-hant/services/civil)）。台北所：103 臺北市大同區承德路一段35號7樓之2；台中所：40453 臺中市北區館前路19號6樓之1。

再鑑界的結果仍然不服，登記機關就不再受理第三次鑑界。界線從那時起，只能交給法院裁判或訴訟外紛爭解決機制決定（地籍測量實施規則第221條第1項第3款）。
