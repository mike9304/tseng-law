## 실행 확인 및 남은 범위

- `node` + 저장소 `gray-matter`로 YAML parsing, FAQ 3개, H1/title 일치, audience `zh-hant`, author 유지, bold 없음, 미디어 AI caption 및 법률 단서 유지 확인. summary 이외 frontmatter 값은 원본과 모두 동일했다.
- URL occurrence multiset 비교: 모든 원본 외부 출처 URL의 개수까지 보존됨. actor 수정 문장 존재·구속결정 과단정과 직접 판례인용 표현 제거 확인.
- `git diff --no-index --check <original> <staged>`: 출력 없음, exit 1. no-index에서 내용 차이 존재로 반환한 상태이며 공백 오류 출력은 없었다. 실제 diff를 별도로 읽어 범위를 확인했다.
- 최초 검증 당시 SHA `bb9a7761a590366b5478063127c979ae7db81963d8182d820f8e9fdb84454444` 이후 summary 첫머리 `認定` 반복만 1회 정리했다. 최종 SHA `e84a46e7c03bb0434eb60d12b648ba106e152b9fc3b55bba3c10648ad6ae219c`를 다시 읽어 확인했다.
- 독립 수정 검수자 `/root/repair_semi_zh/verify_zh_repair`는 원본/수정본과 공식 세 판결을 직접 재열람했다. 마지막 summary 단어 교정까지 재확인한 최종 판정: MUST 0 / NIT 0. 확인 SHA도 `e84a46e7c03bb0434eb60d12b648ba106e152b9fc3b55bba3c10648ad6ae219c`로 일치한다. 69행의 행위자, 147행의 구금/실체판결 구별, 81행의 같은 판단기준 및 출처·author·미디어 caption 보존을 검증했고 파일 변경은 0이었다. 이는 독립 AI 내용검수이며 실제 변호사/원어민 검수라는 뜻이 아니다.
- 최종 `node`/`gray-matter` 재검증 exit 0: `ALL 13 content-preservation checks PASS`. 원본SHA·수정본SHA, bold, FAQ, H1, summary 이외 메타, AI 미디어 고지, 법률 단서, 행위자, 판단범위, evidence의 SHA·독립검수 기록, 출처 URL 순서까지 확인했다.
