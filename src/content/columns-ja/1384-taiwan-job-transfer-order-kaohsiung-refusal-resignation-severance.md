# 台北で採用されたのに高雄へ転勤、断れば自己都合退職になりますか

転勤を断っただけで、本人が辞職したことにはなりません。会社の側から契約を終わらせるには、台湾の[労働基準法（勞動基準法）第11条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0030001&flno=11)や[第12条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0030001&flno=12)に並ぶ事由が要ります。「転勤を拒んだら自己都合退職」という項目は、どちらの条文にもありません。

一方で、会社が出す転勤命令にも条件があります。[第10条の1](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0030001&flno=10-1)は、雇用主が労働者を異動（調動）させるとき、労働契約の約定に反してはならず、さらに五つの原則に従わなければならないと定めています。命令がこれに反するなら、社員の側から予告なしに契約を終え、資遣費（法律で定められた契約終了時の手当）を請求できる場合があります。その終了には30日の期限があります。

2022年1月から台北の営業拠点で働く日本人社員が、人事担当から「来月1日から高雄工場の生産管理に移ってほしい」「断るなら自己都合退職として処理する」と告げられた場面で考えます（架空の例です）。台湾人の配偶者はおらず、永住許可もなく、専門職としての雇用許可で働いています。日本国籍の配偶者と小学生の子が台北で暮らしています。労働契約は台湾法人と直接結んでおり、勤務地欄には「台北本社及び会社が指定する場所」とあります。

## 勤務地条項があっても五つの原則は残ります

第10条の1の原文は「雇主調動勞工工作，不得違反勞動契約之約定，並應符合下列原則」で始まります。契約に反しないことと、原則を満たすこと。求められているのはその両方です。

勤務地欄に「会社が指定する場所」とあれば、高雄への異動を約定違反と言うのは難しくなるかもしれません。それでも五つの原則は外れません。反対に、勤務地を台北に限る約定なら、本人の同意なく高雄へ移す命令は約定違反の問題になります。

| 号 | 条文の原則（原文） | 高雄への転勤で確かめること |
|---|---|---|
| 第1号 | 基於企業經營上所必須，且不得有不當動機及目的。但法律另有規定者，從其規定。 | 高雄工場でその職務が必要な理由、退職へ追い込む目的がないか |
| 第2号 | 對勞工之工資及其他勞動條件，未作不利之變更。 | 基本給・手当・職位・勤務時間が台北より下がらないか |
| 第3号 | 調動後工作為勞工體能及技術可勝任。 | 営業から生産管理へ移るときの経験と技能 |
| 第4号 | 調動工作地點過遠，雇主應予以必要之協助。 | 住居、引っ越し費用、移動手段について会社が何を用意するか |
| 第5号 | 考量勞工及其家庭之生活利益。 | 台北に残る配偶者と子の生活、子の通学 |

台北で出ていた手当が高雄では付かない、肩書が下がる、といった変化は第2号の「不利な変更」に当たるかが問われます。会社に変更後の賃金と条件を書面で示してもらえば、台北との比較ができます。

自宅のある台北から高雄の工場までは、毎日の通勤を前提にしにくい距離です。第4号は、勤務地が遠すぎるときに雇用主が「必要な援助（協助）」をするよう定めていますが、その中身は条文に書かれていません。社宅や住宅手当、引っ越し費用の負担、着任日の調整について何の提示もないまま着任日だけが決まっているなら、その点を会社に書面で尋ねます。

家族が台北に残れば二重生活になります。第5号が求めるのは家族の生活上の利益を「考量」すること、つまり考慮です。家族の事情があれば必ず転勤を拒める、とまでは書かれていません。

「断るなら自己都合退職」という言い方は、第1号を考えるきっかけにもなります。高雄工場で本当にその職務の人手が要るのか、台北の職務がなくなったのか。理由を尋ねた書面と会社の回答は、経営上の必要と動機を判断する材料として残ります。

## 断った社員を会社が辞めさせるには、条文上の事由が要ります

では、社員が転勤を断り続けたら、会社は何ができるのでしょうか？

雇用主が予告して契約を終えられる場面を、第11条は五つに限っています。廃業または譲渡、赤字または業務縮小、不可抗力による1か月以上の休業、業務の性質が変わり人員削減が必要で適当な配置先もない場合、職務に確実に堪えない場合です。この条で終了するなら、会社には資遣費の支払いが伴います。予告の時期は、[第16条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0030001&flno=16)第1項が勤続年数に応じて定めています。

- 勤続3か月以上1年未満：10日前
- 勤続1年以上3年未満：20日前
- 勤続3年以上：30日前

冒頭の社員なら30日前です。この期間を置かずに終了した雇用主は、予告期間の賃金を支払わなければなりません（同条第3項）。

予告なしの終了を定める第12条のうち、転勤拒否と結びつけられやすいのは第1項第4号の「違反勞動契約或工作規則，情節重大者」と、第6号の「無正當理由繼續曠工三日，或一個月內曠工達六日者」でしょう。第4号は労働契約か就業規則（工作規則）への違反で、情状が重大な場合です。第6号は正当な理由のない連続3日、または1か月に6日の欠勤です。

命令が第10条の1を満たしているか、拒否が第4号の「情節重大」に当たるか。どちらも、命令の内容、拒否に至る経緯、会社の説明などを踏まえた個別の判断です。

ここで資遣費の有無が大きく変わります。[第18条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0030001&flno=18)第1号により、第12条で契約を終了された社員は、予告期間の賃金も資遣費も請求できません。会社の側にも期限があります。第12条第1項第1号・第2号・第4号から第6号で終了するなら、その事情を知った日から30日以内にしなければなりません（同条第2項）。

資遣費が出る終了として[労働者退職金条例（勞工退休金條例）第12条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0030020&flno=12)が挙げるのは、労働基準法第11条、第13条ただし書、第14条、第20条などによる終了です。理由を示さない辞職はこの中にありません。辞める意思がないなら、辞職届や「自己都合で辞める」と書かれた書類には署名しないでください。実際に辞職届を出した後の扱いは、[自分から辞めても資遣費が出る場合の解説](/ja/columns/taiwan-voluntary-resignation-severance)で整理しています。

着任日を過ぎても高雄へ行かず、台北でも仕事を与えられない日が続くと、会社が第12条第1項第6号の欠勤を持ち出すかもしれません。異議を述べた書面、台北で出勤を続けた記録、会社とのやり取りは、「正当な理由」があったかを後から示す材料になります。

外国籍なら、就労許可にもかかわります。[就業サービス法（就業服務法）第73条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0090001&flno=73)第3号は、連続3日の無断欠勤で連絡が取れなくなったとき、または雇用関係（聘僱關係）が終了したときに、雇用許可（聘僱許可）が廃止されると定めています。会社との連絡を絶たないことには、この意味もあります。

仕事の中身が変わる転勤なら、もう一点あります。[同法第57条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0090001&flno=57)第3号は、雇った外国人を許可以外の仕事に就かせることを雇用主に禁じています。営業から生産管理へ移すなら、許可の範囲に収まるかを会社に確認してもらいます。同条第4号が勤務場所の変更に許可を求めている相手は、[第46条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0090001&flno=46)第1項第8号から第10号の仕事（海洋漁撈、家事・介護、中央主管機関が指定する仕事）に就く外国人です。第46条第1項第1号の専門的または技術的な仕事（專門性或技術性之工作）は、この列挙に入っていません。

## 違法な命令なら、社員の側から契約を終えて資遣費を求められます

命令が第10条の1に反するとき、社員は[第14条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0030001&flno=14)第1項第6号の「雇主違反勞動契約或勞工法令，致有損害勞工權益之虞者」を根拠に、予告なしで契約を終了できます。同条第4項が[第17条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0030001&flno=17)をこの終了に準用しているため、資遣費を請求できます。額の計算は、勤続のどの部分が新制度に当たるかで変わります。

期限は同条第2項にあります。第6号による終了は、事情を知った日から30日以内にしなければなりません。同項ただし書は、雇用主に第6号の事情がある場合、損害の結果を知った日から30日以内に終了することも認めています。

転勤の場合、どの日を「知った日」とみればよいのでしょうか？ 答えは事実によって変わります。命令書を受け取った日、着任日、条件が下がった最初の給与日。いちばん早い日から数えて準備を進めておけば、期限をめぐる争いを避けやすくなります。

終了は書面で告げます。そこには第14条第1項第6号によること、違反と考える第10条の1の号とその事実を書き、送った日と方法を記録します。会社が「命令は適法だった」と争えば、資遣費の請求もその判断に左右されます。

## 資遣費は勤続の区分ごとに計算します

2026年11月19日現在の条文では、勤続のどの部分が新制度に当たるかで、1年あたりの額が変わります。

| | 新制度が適用された後の勤続 | 旧制度で計算する勤続（新制度へ移る前に保留された勤続、旧制度の継続を表明した人など） |
|---|---|---|
| 根拠 | 労働者退職金条例第12条第1項 | 労働基準法[第17条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0030001&flno=17)（労働者退職金条例第11条第2項・第12条第3項） |
| 1年あたり | 平均賃金（平均工資）の2分の1か月分 | 平均賃金の1か月分 |
| 1年未満 | 比例計算 | 比例計算、1か月未満は1か月 |
| 上限 | 平均賃金6か月分 | 第17条に上限の定めはありません |
| 支払期限 | 契約終了後30日以内 | 契約終了後30日以内 |

どちらに当たるかは、国籍だけでは決まりません。[同条例第7条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0030020&flno=7)第1項が新制度の対象に挙げる外国人は、台湾に戸籍のある国民と結婚して居留を許可された人などと、永久居留を許可された人です。台湾人配偶者も永住許可もない冒頭の社員は、この列挙には入りません。

それでも新制度の対象になりえます。改正後の[外国専門人材招へい雇用法（外國專業人才延攬及僱用法）第24条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=A0030295&flno=24)第1項は、専門的な仕事（專業工作）に就く外国専門人材と外国特定専門人材に、新制度を適用すると定めています。[労働部の説明](https://www.mol.gov.tw/1607/28690/2282/2302/2316/86977/)によれば、この改正は2026年1月1日に施行され、永住許可は要りません。就業サービス法第46条第1項第1号の専門的・技術的な仕事も、同じ説明で「専門的な仕事」に含まれています。

入社の時期で扱いが分かれます。2026年1月1日以降に入社した人は、入社日から新制度です。それより前から同じ会社に勤めていた人は、2026年6月30日までに書面で旧制度の継続を雇用主に表明できました。期限はもう過ぎています。表明した人は新制度へ変更できず（第24条第2項）、表明しなかった人には新制度が適用されています。施行前から新制度だった人や、旧制度の継続をすでに表明していた人は、その扱いのままです（同条第5項）。永住許可を持つ人には、別の経過規定もあります（同条第6項）。

新制度へ移る前の勤続は消えません。第24条第3項は、その勤続を労働者退職金条例[第11条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0030020&flno=11)で扱うとしています。その第2項によると、保留された勤続の資遣費は、契約が労働基準法第11条、第13条ただし書、第14条、第20条などで終了したときに、契約終了時の平均賃金を使って各法の規定どおりに計算され、終了後30日以内に支払われます。

冒頭の社員の仕事がこの「専門的な仕事」に当たるとして、計算してみます（架空の数字です）。旧制度の継続は表明しておらず、平均賃金は月8万台湾ドルです。契約は2026年12月末に終わり、資遣費が出る終了に当たるものとします。2025年末までの勤続は4年です。保留された勤続として第17条の基準で数えると、4か月分の32万台湾ドルになります。2026年の1年は新制度の勤続で、半月分の4万台湾ドルです。合計は36万台湾ドルです。期限内に旧制度の継続を表明していた場合なら、5年すべてが第17条の計算になり、40万台湾ドルです。

台湾の弁護士には、労働契約書・就業規則・転勤の命令書を第10条の1の五つの原則と照らし合わせる作業や、会社に出す異議・条件交渉の書面づくりを依頼できます。地方の労働主管機関での労使紛争の調停（勞資爭議調解）の申立てと代理、解雇の効力を争う手続、第14条による契約終了と資遣費の請求も任せられます（[労働事件の取扱い](/ja/services/labor)）。昊鼎国際法律事務所へ[wei@hoveringlaw.com.tw](mailto:wei@hoveringlaw.com.tw)で問い合わせられます。台中事務所：40453 臺中市北區館前路19號6樓之1。

高雄への着任は来月1日です。それまでに勤務地欄、就業規則の異動条項、命令書の日付と条件を一つの時系列に並べておくと、会社側の第12条の30日と社員側の第14条の30日が、それぞれどの日から進むのかを確かめられます。
