# 台湾の源泉税還付、無申告のまま税額が認定された場合

追加で納める税金がゼロなら、源泉徴収された分は自動で戻るのでしょうか？ [11月12日の経済日報](https://money.udn.com/money/story/6710/9872672)は、南区国税局による未申告者の還付の説明を報じました。申告期限を過ぎた場合も、税務当局が税額を認定する前の申告が必要だという内容です。

[同局の11月11日の発表](https://www.ntbsa.gov.tw/singlehtml/5e0e49a811b74b50b5a6486d38374285?cntId=ebfba52db69445a7961ac8aed6f8739d)が紹介した2024年分の事例では、申告していなかった夫婦について、子の免税額が後から認められた結果、当初求められた追加納税が不要になりました。源泉税は戻りませんでした。賃貸所得から引かれた3万台湾ドルです。税額認定前の申告がなかったためです。

## 申告の省略と還付の申請

この問題の対象は、台湾の[所得税法第7条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=G0340003&flno=7)にいう居住者です。日本人も、この区分に当たれば同じ申告・還付のルールに従います。

[第71条第3項](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=G0340003&flno=71)は、年間の総合所得が、その年の免税額と標準控除額の合計を超えない居住者について、確定申告を省ける場合を定めています。しかし、源泉税の還付を求める場合には申告が必要です。還付は自動ではありません。

給与などから税金が引かれていても、勤務先などの源泉徴収手続だけで、本人の還付申告まで済むわけではありません。源泉徴収票に税額が記載されていることと、自分の申告を受け付けてもらったことは、確認する書類も異なります。

## 個人の総合所得税と申告催告の扱い

所得税法[第79条第2項](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=G0340003&flno=79)は、個人の総合所得税には、同条第1項の15日以内に申告を求める催告の規定を適用しないとしています。申告期限を過ぎた場合、税務当局は把握した資料により所得と税額を認定し、期限内の納付を通知します。

南区国税局が示した期限後申告の条件は、当局の税額認定前に申告を済ませることです。納税通知を受け取った後に申告するつもりでいると、この還付の条件を満たせないおそれがあります。

申告済みの案件は別途判断されます。[第100条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=G0340003&flno=100)は、申告後に過払いが認定された場合の還付を定め、その後の再審査・不服申立て・行政訴訟による還付にも触れています。認定後の還付を一律に禁じる条文ではありません。

納税通知が届いた後に源泉徴収票だけを見ても、申告をいつ行ったかまでは分かりません。対象年度の申告受付の記録と、当局が税額を認定した時点が、この未申告による還付制限に当たるかを検討する手掛かりになります。

台湾の居住者個人の申告・還付に関する一般情報です。具体的な還付の可否は申告と処分の内容によります。確認日：2026年11月16日。
