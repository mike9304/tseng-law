# connectors — ja 003 (신규 텍스트·링크 문구 전부, 원문 그대로)

신규 글자는 3건(C2–C4; R2에서 C1 삭제). 나머지 C5–C8은 기존 글자에 링크만 씌운 앵커 변경이며 글자 추가가 없다.
이동·교체된 문장 조각(C9–C10)은 원문에 있던 말이라 신규 텍스트가 아니지만 편집 위치가 바뀌어 함께 적는다.

## 신규 글자 (3)
- C1. (R2에서 삭제) H2 「## 公式資料」 — 출처 블록을 원문 자리로 되돌리면서 제거. 번호는 유지하지 않고 비워 둠.
- C2. Q1 P3 문말 `（` `）` 괄호 한 쌍: 「…行政上の処分を受けることがあります（[道路交通管理処罰条例第62条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=K0040012&flno=62)）。」 앵커 글자 「道路交通管理処罰条例第62条」는 Q19 s2 원문에서 가져옴.
- C3. Q4 P1(R3-2: Q3 P1에서 이동) `刑法` 1건: 「過失致死については[刑法第276条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0000001&flno=276)を確認します。」 원문 Q17은 「第276条」(앞 반절에 「刑法第284条」가 있어 법명 생략). 이동 후 맥락이 없어 「刑法」 추가.
- C4. Q4 P1 끝 `刑法` 1건: 「[刑法第41条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0000001&flno=41)による罰金への換算にも要件と例外があります。」 원문 Q17은 「第41条」. 같은 이유로 「刑法」 추가.

## 링크 앵커 변경 (글자 추가 없음 또는 위 C2–C4에 포함)
- C5. Q3 P1 s1 `[刑法第284条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0000001&flno=284)は過失傷害と過失致重傷を定めています。` — 기존 「刑法第284条」에 Q17의 [284] 링크 URL 부여.
- C6. Q17 숫자형 앵커 `[284] · [276] · [41]`(문항 말미 링크 줄) → 본문 문장 속 앵커 3개(C3·C4·C5)로 전환. URL 3개 모두 원문 그대로.
- C7. Q19 숫자형 앵커 `[62]` → C2의 앵커. URL 원문 그대로.
- C8. Q17–Q19 링크 줄 중 `[238] · [287] · [185-4]` → 본문 인라인으로 옮기지 않음. 같은 조문 URL이 「Q1–Q5 公式資料」에 남아 있어 링크 소실 없음(ledger 참조).

## 이동·교체된 원문 조각 (신규 글자 아님)
- C9. Q5 P3 s1: 「口頭弁論終結まで」 → 「弁論終結前まで」 (Q18 s1 원문 표현으로 교체, 근거 刑事訴訟法第238条 원문 「辯論終結前」).
- C10. Q5 P3 s3: 「非親告罪は」 → 「過失致死など非親告罪は」 (Q18 s3의 「過失致死など」 이동).

개수 요약(R3 최종): 신규 글자 3건(괄호 한 쌍, 「刑法」×2) / 링크 앵커 변경 4건(62·284·276·41) / 조각 교체·이동 5건(C9, C10, C11, C12, C13).
- C11(R2). 도입 끝 「特定の結果や賠償額を事前に保証することはできません。」 — 원문 Q20 s2를 그대로 옮김(신규 글자 아님).
- C12(R3-3). Q1 P1 s2 「その措置を終えずに」 → 「必要な措置を終えずに」 — 「必要な」는 R1에서 삭제한 앞 절(「必要な措置の代わりにはならず、」)에 있던 원문 글자(신규 글자 아님).
- C13(R3-1). Q15 마지막 문단 끝 「保険会社が担当する範囲、必要書類、通知期限を確認しましょう。」 — 원문 Q16 s1을 글자 그대로 이동(신규 글자 아님).
