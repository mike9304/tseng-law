# fixspec 006 taiwan-massage-history-law (리드 원문 확인 2026-10-06 21:1x)

1. F-019-1 금지 조항 존속 기간: 身心障礙者權益保障法 §46⑥ 「第一項規定於中華民國一百年十月三十一日失其效力。」 린 씨 단속은 2003년(北高行 92年度簡字第847號 사건). "이 법은 2003년까지 계속되었는데, 당시 …" → "이 제한은 2011년 10월 31일까지 유지되었는데, 그 사이인 2003년에 …".
   URL https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=D0050046&flno=46
2. F-019-2 처분의 성격: 釋字649 聲請書 「臺北市政府社會局以違反「身心障礙者保護法第 37 條第 1 項」規定為由，按同法第 65 條第1、2項分別裁處新臺幣 4 萬元、1萬元、2萬元之罰鍰」 → 형사 "벌금"이 아니라 시 사회국의 행정 罰鍰. ko "벌금을 부과받았습니다" → "타이베이시 사회국으로부터 … 과태료(罰鍰)를 부과받았습니다", en "was fined" → "the Taipei City Social Affairs Bureau imposed administrative fines of …", ja 「罰金が科されました」 → 「台北市社会局から…の過料（罰鍰、行政上の制裁金）が科されました」. zh는 이미 「罰鍰」이면 해당 없음.
   URL https://law.moj.gov.tw/LawClass/ExContent.aspx?ty=C&CC=D&CNO=649
3. F-019-3 위헌 해석 날짜·유예: 釋字649(民國97年10月31日) 「…應自本解釋公布之日起至遲於屆滿三年時失其效力。」 → "대법관은 … 위헌으로 선언했습니다" 문장에 "2008년 10월 31일 해석 제649호에서"와 "이 조항은 늦어도 3년 뒤인 2011년 10월 31일에 효력을 잃었습니다" 반영(1문장 안에서 최소로).
