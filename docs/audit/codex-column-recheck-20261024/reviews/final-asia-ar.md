## 문체·현지화·중복과 첫 두 문단

각 글의 첫 두 문단을 삭제 시험으로 읽었다. 실제 기한·기관·입국 경로·예외·증빙 역할을 잃는 문장은 유지했고, 일반적인 “준비하면 알 수 있다” 식 효용 문구는 제거됐다. 제목·요약·FAQ·마지막 실무 문단도 따로 읽었다.

- 704: TH/ID는 최초 30일과 방문자 자격 차이를, HI/AR는 입국일과 대만 내 비자 발급일의 차이를 빠르게 설명한다. 조건 없는 체크리스트가 아닌 신분별 문서·창구 안내로 이어진다.
- 705: TH는 14일 시험 면제와 학업 목적, ID는 TAC와 이주노동자/전문직 차이, HI는 비자/직접 신청 선택과 증빙, AR는 여권 국적·현재 거주국·문서 발행국을 다룬다. 언어가 자격을 결정하지 않는다는 편집자용 메타 문장은 제거하거나 실제 자격 기준으로 바꿨다.
- 706: TH는 주소 변경, 나머지는 기존 거류 사유 소멸/기한 구별로 시작한다. 실무 끝맺음은 현재 서류·신청 번호·귀국 날짜에 관한 것이며 상담 영업문구를 반복하지 않는다.
- ID의 가족 문단별 반복 경고, 706의 중복 기산일·접수증 설명과 가상의 동급생 비교, AR의 중복 입학 경고·일반적인 여행 선언, TH의 중복 실제주소 단문·법조문 메타설명은 작성자 수정 후 실제 제거/통합을 확인했다. 필요한 법적 제한까지 삭제하지 않았다.
- 태국어 704를 제외한 글에 새 차단 수준의 단조로움은 찾지 못했다. 숫자 결과만으로 자연스러움을 인증하지 않았다. 힌디어 है 종결 경고는 자연스러운 문법과 실제 서술어 다양성을 직접 읽고 비차단으로 판단했다.

## 출처·숫자·이미지·정체성 보존

## 판정의 한계

이 보고서는 12개 지정 파일의 편집·법률 근거 검수다. 인간 원어민 또는 대만 변호사의 검토를 주장하지 않으며, 인증된 실제 포털 제출, 독자별 법률 결론, 브라우저 RTL/모바일 레이아웃, 검색노출, 배포·게시 성공을 확인하지 않았다. Arabic 원문과 삽입된 약어/숫자·문장부호는 읽었으나 실제 RTL 화면은 root 검증 영역이다. 타 언어 30편과 오늘 다른 칼럼 45편은 별도 검수 범위다.

후속 조치: 11개 PASS는 정확한 해시의 검수 결과로 전달한다. TH704는 현재 파일과 실패 증거를 보존하여 검토 필요 상태로 전달한다. 이 검수자가 게시를 승인하거나 배포하지 않는다.
