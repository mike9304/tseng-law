## 2. 제품 잠금

- 대만 법률 용어는 **번체 한자를 괄호로 병기**한다(工作許可, 資遣費, 勞動契約, 外僑居留證 …).
  키릴로 음역하지 말 것. TWD·USD·PE·ARC 같은 라틴 약어도 원문 그대로.
- 대표 변호사는 여성이다. 이름은 `Wei Tseng (曾雋崴)` 라틴 표기 그대로 쓰고 키릴 음역하지 말 것
  (001·002가 그렇게 돼 있다).
- 한국 기업 → 외국 기업으로 일반화(fr·de 선례와 동일). 러시아·독립국가연합 관련 서술 추가 금지.

## 3. 형식 패리티 (체커가 검사한다)
- frontmatter 키 집합·순서는 원본과 같게. `url` `lastmod` `featured_image` 는 **원본 값 그대로**.
  `date_display`는 러시아어 표기(예: "13 сентября 2025"), `read_time`은 "N минут чтения".
- `faq` 항목 수는 원본과 정확히 같게. 없으면 만들지 말 것.
- 본문 블록 수·순서가 원본과 일치. 합치거나 쪼개지 말 것. 이미지 경로 그대로, 대체 텍스트만 번역.
- 링크: `/ko/columns` `/ko/contact` `/ko/services` `/ko/faq` `/ko/pricing` 만 `/ru/...` 로 바꾼다.
  `/ko/services/investment` 같은 상세 경로와 외부 링크는 **그대로**.
- **숫자는 아라비아 숫자로.** 원본과 개수가 같아야 한다. 천단위는 점(TWD 3.000.000).
  단, 러시아어 관용상 낱말로 쓰는 분수·수사는 사전에 등록돼 있다
  (две трети, двух третей, одну треть, одна/одну/одной …). 그 외는 숫자로 쓰는 편이 안전하다.
- 한글이 남아 있으면 안 된다. `url` 값 안의 한글은 예외(원본 주소 그대로).
