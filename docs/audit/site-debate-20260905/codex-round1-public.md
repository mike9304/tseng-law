# Codex 독립 진단 및 토론안 — 공개 실측, 2026-09-05

검사: PC 1440×900, 모바일 390×900 및 390×844, reduced-motion. 직접 요청한 현재 공개 페이지 + 일회용 Chromium 화면. 검색엔진 캐시의 옛 LINE/Kakao 표시는 현재와 달라 폐기했다.

1. 문의 접근성: /ko/contact 모바일 390×844의 첫 이메일 링크는 문서 y≈1780px, /en/contact≈1969px, /ja/contact≈1834px. 준비 안내가 상단을 차지한다. 코드 오류라기보다 정보 우선순위 문제다. 연락처 페이지 첫 화면에 공식 이메일·메일 작성·복사·최소자료 안내를 배치하고 긴 준비 안내를 뒤로 보낸다. 메일 접수를 유지해도 해결 가능하다.
2. CTA 예상과 실제: /ko/pricing의 ‘상담 예약하기’ href는 mailto이며 예약 UI가 아니다. 메일 작성 후 일정 조율을 한다는 설명과 ‘이메일로 상담 일정 문의’처럼 실제 동작을 명확히 하는 카피를 권장한다. 예약 시스템을 새로 구현하는 근거로 사용하지 않는다.
3. 언어 불일치: 홈과 변호사 프로필은 일본어 상담을 안내하나 KO/EN/ZH-HANT mailto의 희망언어 목록에는 일본어가 없다. JA mailto에는 네 언어가 모두 있다. 상담 가능 언어와 직원의 접수 가능 언어를 섞지 말고 사실에 맞춰 일관되게 표기한다. 영어 미지원이라 단정하지 않는다.
4. 홈 첫 화면: 현재는 브랜드와 본문 진입 버튼만 보이지만 버튼 실제 클릭 후 H1·CTA·헤더가 정상 노출된다. 모바일 메뉴도 실제 클릭으로 열리고 Escape로 닫힌다. 인트로 고장/SEO 제목 없음으로 판정하지 않는다. 브랜드 연출을 유지하면서 첫 화면에 짧은 업무 설명·상담 연락처 진입을 추가하는 선택안을 권장한다. 이는 UX 개선 가설이며 효과 수치는 모른다.
5. 고객용 문구: 홈 칼럼 소개에 ‘실제 수집된 칼럼 본문과 이미지를 기반으로’라는 제작 설명이 공개된다. 독자에게 제공하는 주제·도움 중심으로 바꾼다. 리뷰 이벤트 문의 CTA도 일반 상담과 동일한 제목을 사용해 목적이 보존되지 않는다(확인된 href). 운영 중인 이벤트 기간/조건을 확인한 뒤 목적 명시; 이벤트 법적 위법이나 리뷰 조작이라는 근거는 없다.
6. 정상 확인: KO/EN/JA/ZH-HANT 홈 및 수집한 연락처·비용·변호사 페이지 렌더 정상, 가로 넘침 없음, pageerror 없음. 중국어 정식 경로는 /zh-hant이고 /zh 404는 검사자의 추정 실수다. 비용 정보·변호사 소개·민감정보 안내·메일 복사·모바일 메뉴는 이미 있다.
