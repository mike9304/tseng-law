현재 918 SHA는 `18706d6b788879e3f3d6dff97136cee18f65321163adadb58d6bd23215fc4a05`다. 직접 역치환하면 R2 SHA `7e59a55f865bc4b3617c5d12371546be42aade935b4ab9fa6a775177ea6bcc49`가 복원된다. 나머지 다섯 원고와 기존 30개 기록은 불변이다. frontmatter·FAQ·URL 순서·숫자 문자열도 같다.

저자의 같은 원고·도구 SHA 실제 공유 실행(exit 0, CV .493)을 연결했다. 재실행은 하지 않았다. 실제 46개 분절 중 한 문장만 바뀌었고 나머지 45개는 동일하다. 변경 문장과 앞뒤를 직접 읽었으며 추가 경계 문제는 발견하지 않았다. R2의 구조 검사와 현재 메타데이터·링크 불변 증거를 구별해 재사용한다. 최신 LESSONS 15:05판 전문을 읽었고 SHA를 [독립 대조 증거](../checks/et-independent-r3-checks.json)에 남겼다.
