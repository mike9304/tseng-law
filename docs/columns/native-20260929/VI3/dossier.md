## 조문 vs 기관 자료 불일치 기록
- 臺南市學甲戶政事務所 頁(xuejia.tainan.gov.tw, 외래인구 이혼 후 居留)는 구법(§31 IV 3~5款, 「取得監護權」「經法院判決離婚」)을 인용 → 2023 개정 전 내용. 조문 원문 우선, 본문 미인용.
- 브리프 가설 "DV 이혼+保護令 필요" → 틀림. §31 IV(2)는 보호령 불요(NIA 2023-05-30 확인).
- 브리프 가설 "Art.62 외국인 피해자 보호" → §62는 통보의무 위반 과태료; 외국인 관련은 §4 II(7)뿐. 사용 안 함.
- 1990 은 브리프 가정(다국어 24h)과 달리 베트남어는 평일 9-17시만.

## 확인 못 해서 본문에서 뺀 것 / 본문에서 "확인 못함"으로 명시한 것
- 移民署 §31 IV(3) 신청서류 공식 목록(法院裁定/學校證明/訪查 등은 검색요약에서만 나옴, 공식 페이지 미확인) → 본문은 "서류 목록은 서비스站에 문의", 예시는 일반적 성격으로만.
- 귀화 심사 중 이혼 시 기존 신청의 처리(유지/재신청/기각) 공식 지침 → 못 찾음. 본문에 명시.
- 兩願離婚도 §31 IV(2)「因遭受家庭暴力離婚」에 해당하는지 → 공식 지침 못 찾음. 본문에 명시.
- 固有國籍/無國籍: 베트남 측 국적 이탈 법·절차는 미확인 → 삭제. 대만 §26(2) 문언만 인용하고 개별 적용은 미확인 명시.
- 이혼 후 체류 유예/허가 절차의 처리기간, 수수료, 통계 → 미조사, 미기재.
- 법률구조재단 전화 (412-8518)는 검색요약에만 나와 미기재.
