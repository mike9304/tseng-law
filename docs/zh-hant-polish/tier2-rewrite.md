## 總結

**改了哪些類型的問題**
1. 韓文直譯：台灣法下的、訴訟應對、刑事應對、聯絡處（연락사무소）、地址候選、點檢、現場對應、過失致傷、「·」並列排版。
2. 日文法律／商務用語：特定（作動詞）、原本、成功報酬、預定損害賠償、登記事務所、業種、最適、以足夠精度。債權回收頁（taiwan-debt-recovery-lawyer）原為英日稿轉譯，此類問題最多，幾乎全頁重寫句構。
3. 大陸用語與 AI／行銷套話：對接、一條龍、推進、上線、節奏、優化、提交、違紀解僱、轉人工；「提供完整的一條龍服務」「無論是～都歡迎」。
4. 台灣法律與行政用語：辦事處、違約金條款、後酬、正本、總公司（對分公司）、個資法「利用目的／委託／國際傳輸」、法定代理人、過失傷害罪、出進口廠商登記、懲戒解僱、審閱。
5. 可能誤導的表達：AI 諮詢來源標籤的「時效」（易與消滅時效混淆）、Messenger 區塊的「官方電子郵件收件」、快速回覆引用的按鈕名稱「諮詢預約」與實際按鈕不一致（改為「預約正式諮詢」）。
6. 全站一致：電子郵件諮詢（債權回收頁、公司設立指南的 mailto 按鈕）、專欄（intent 頁、聊天元件「參考專欄」）、「勞動與僱傭」、籌備帳戶、「A與B」並列。
