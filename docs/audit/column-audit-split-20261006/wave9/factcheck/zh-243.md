## 참고 메모 (판정 아님, 수정 불요)
1. §89 관련 칼럼 문장 「本案的結果若和它不同，不同的部分原則上失效」: §89③은 本案 請求 「經裁判准許確定、調解或和解成立」 내용과 상이한 부분이 대상(①은 本案請求 駁回確定 시 전체 失效). 「原則上」 한정이 있어 오판 유발 수준 아님.
2. 臺南分院 裁定은 「上訴中」 본안 중 이미 二審 판결이 난 단계의 暫時處分(本案 三審 上訴 계속)이며, 칼럼은 「本案是上訴中的離婚等事件」로 요약 — 정확.
