# ARC·비자 704–706 감사 자료

14개 언어 42편. 공개 게시 전 로컬 원고·검수·빌드 묶음입니다.

현재 결과는 `manifest.json`, `checks/variety-audit.json`, `checks/static-content-audit.json`, `checks/source-preservation.json` 및 최종 검수 보고서의 마지막 판정입니다. 보고서의 앞부분에는 당시 미지원·실패·수선 대기 기록이 그대로 남아 있습니다. 그 기록을 삭제하거나 소급해 통과로 바꾸지 않았습니다.

`authors/`는 저자 자체 점검, `reviews/*-locale-r1.md`는 저자와 분리된 AI 언어 검수, `reviews/final-*.md`는 별도 AI 최종 검수입니다. 사람 원어민·변호사의 검수·승인을 주장하지 않습니다.

PC·모바일·RTL 브라우저 확인은 관리자 정책 검증 실패로 미완료입니다. source/HTML 보존, 서버 렌더링과 자동 테스트는 이 제한을 대체하지 않습니다. main push·공개 게시를 수행하지 않았습니다.

`verification-scripts/`는 원래 격리 작업 폴더의 경로와 도구를 이용하는 재현 자료입니다. 다른 머신에서 실행하려면 경로를 검토해야 합니다. `tooling/vi/`에는 사이트 코드와 별도로 보완한 공유 VI 측정기의 중립 승인·회귀 증거가 있습니다. 태국어 승인 경계는 인접한 `../variety-segments/`에 있습니다.
