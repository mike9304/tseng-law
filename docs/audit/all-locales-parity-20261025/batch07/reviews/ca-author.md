## 입력과 읽기 범위

B7 BRIEF 전문과 B6 authoring-contract-draft/source-freeze/source-register, 현재 정본 여섯 전문을 읽었다. six-source-facts와 공통 문체 규칙은 같은 연속 작업에서 이미 전문을 읽은 동일 SHA를 재사용했다. 같은 문서를 읽은 횟수를 새 연구 성과로 세지 않는다. 마지막 대조에서 LESSONS가 03:05 KST 자동 생성본으로 바뀐 것을 발견해 최신 25개 항목의 전문을 다시 읽었다. 최초 무결성 검사는 이 차이에서 멈췄고, 차이를 설명하지 않은 PASS 기록은 만들지 않았다.

홈 editorial-voice.md는 현재 없으므로 BRIEF에 지정된 R/docs/columns/EDITORIAL-VOICE.md를 적용했다. 프로젝트 AGENTS, COLUMN-VOICE-RULE, SENTENCE-VARIETY-RULE, LESSONS 및 FRONTMATTER의 실제 경로·SHA는 ca-inputs.json에 있다. 퇴역한 Fable 의무는 적용하지 않았다.
