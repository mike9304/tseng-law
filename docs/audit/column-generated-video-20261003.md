## 제품 검증

직접 재생 요소는 네이티브 `video`이며 사용자가 재생한다. `preload="none"`, `playsInline`, 포스터와 연결된 설명을 제공하고 자동재생·반복재생은 사용하지 않는다. 본문 숨김 설정도 따른다. 교통사고 게시판의 영상 필터는 새 자산이 검수된 언어·출처에서만 해당 글을 포함한다.
