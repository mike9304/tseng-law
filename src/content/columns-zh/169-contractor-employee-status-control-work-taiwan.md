# 「承攬」契約下的打卡與工作指示：勞工身分怎麼判斷

合約寫「承攬」，仍須把實際工作情形與契約內容一併判斷；依[勞動基準法第2條第6款](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0030001&flno=2)及勞動部的[勞動契約認定指導原則](https://www.mol.gov.tw/media/seljrmqo/%E5%8B%9E%E5%8B%95%E5%A5%91%E7%B4%84%E8%AA%8D%E5%AE%9A%E6%8C%87%E5%B0%8E%E5%8E%9F%E5%89%87.pdf?mediaDL=true)，具有一定程度的從屬關係，可能成立勞動契約。

每天打卡是其中一項線索，還不能單憑這件事認定就是勞工。勞動部的[從屬性判斷檢核表](https://www.mol.gov.tw/media/a3tjzyan/%E5%8B%9E%E5%8B%95%E5%A5%91%E7%B4%84%E8%AA%8D%E5%AE%9A%E6%8C%87%E5%B0%8E%E5%8E%9F%E5%89%87%E9%99%84%E4%BB%B6-%E5%8B%9E%E5%8B%95%E5%A5%91%E7%B4%84%E5%BE%9E%E5%B1%AC%E6%80%A7%E5%88%A4%E6%96%B7%E6%AA%A2%E6%A0%B8%E8%A1%A8.pdf?mediaDL=true)列出25項特徵，但不是勾到固定項數就能得到答案，仍須綜合判斷工作者實際受到的拘束。

## 工作時間、方法與調度，誰能決定

人格上的從屬性，著重工作者提供勞務時受到多少指揮與監督。例如，工作及休息時間能否自行安排、能否拒絕指派的工作、請人代做是否須經同意，以及不遵守規定時是否會受到處分。主管對工作表現的考核，也是判斷資料的一部分。

因此，打卡紀錄要連同排班、請假方式及未依排班出勤的後果一起看。契約雖寫「自由接案」，實際上卻必須依公司安排到班，拒絕工作又會被停止派工，這些做法就值得逐項核對。若工作者仍能自主安排部分事項，也一併列出，供判斷實際拘束的範圍。

有些限制來自工作本身。指導原則明定，提供該勞務所必須遵守的方法、工作場所或服務紀律，不列入相應的指揮監督因素。例如，修理固定設備必須到設備所在地，與公司基於管理需要指定日常工作地點，限制的原因並不相同。這個差別仍須依實際工作內容確認。[勞動契約認定指導原則第三點第一款](https://www.mol.gov.tw/media/seljrmqo/%E5%8B%9E%E5%8B%95%E5%A5%91%E7%B4%84%E8%AA%8D%E5%AE%9A%E6%8C%87%E5%B0%8E%E5%8E%9F%E5%89%87.pdf?mediaDL=true)

## 報酬與經營風險，要放在一起看

按件計酬不當然就是承攬。[勞動基準法第2條第3款](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=N0030001&flno=2)所定的工資，本來就包括計件給付的報酬；同樣地，固定按月付款也不能單獨決定契約性質。

經濟上的從屬性，要看工作者是否為自己的事業經營承擔風險。例如，提供勞務就能取得報酬，或須完成特定成果才有報酬；設備、材料由誰準備並負擔成本；報酬標準能否協商，或由公司單方訂定、變更；能否自己向其他客戶接案、交易。這些條件須放在整體關係中評估，不能只拿付款週期或一項設備的所有權下結論。

組織上的從屬性則看工作者是否被納入公司的分工，必須和同事配合才能完成工作。例如，日常工作是否依公司排班輪值、與其他人接續完成同一流程。公司有沒有辦理勞工保險、提繳勞工退休金，或將報酬列為薪資所得扣繳，也是指導原則列出的參考事項，並非各自獨立的認定標準。[勞動契約認定指導原則第三點第二至第四款](https://www.mol.gov.tw/media/seljrmqo/%E5%8B%9E%E5%8B%95%E5%A5%91%E7%B4%84%E8%AA%8D%E5%AE%9A%E6%8C%87%E5%B0%8E%E5%8E%9F%E5%89%87.pdf?mediaDL=true)

## 契約約定與實際做法，分開整理

準備資料時，可以用自己持有或可合法取得的紀錄，對照契約約定與實際工作，並標明相關爭點：

| 待釐清的事項 | 可對照的自身資料 |
|---|---|
| 能否決定工作時間、拒絕指派 | 自己的排班、出勤及請假紀錄，主管對工作安排的訊息 |
| 誰決定做法，能否由他人代做 | 契約條款、工作指示及代班申請的往來 |
| 報酬如何計算，成本與風險由誰承擔 | 自己的付款明細、報價、費用負擔約定及相關收據 |
| 如何參與公司的分工 | 自己收到的交接、輪值與工作分配紀錄 |

例如，契約寫可自行安排時間，但主管訊息要求固定到班，就把條款、訊息日期與實際執行情形列在一起。涉及公司機密或他人個資時，應先確認合法取得及提出資料的範圍。

## 雙方對身分有爭議，可以找誰

依勞動部[勞動契約認定問答](https://www.mol.gov.tw/1607/28690/2282/2326/2288/82217/)，雙方仍有爭議時，可檢具契約等相關資料，向工作所在地的勞工行政主管機關請求協處。指導原則也保留工作者循民事司法途徑救濟的方式。

提出問題時，可說明雙方從何時開始合作、工作安排曾否改變，以及目前爭議涉及哪一筆報酬或哪項權利。勞動契約的認定與個別款項的計算是不同問題；如另有加班費爭議，仍要核對工作時間、已付金額及適用規定，不能只憑身分認定就得出應付金額。
