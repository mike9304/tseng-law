## 오류 판정

### M-1 MISSING-COND (경미): §6③ 서술에 시점 한정이 없음 (2026-09-11 공포 이전 사망에는 원칙적으로 안 맞음)
- 줄: L66 (표 제목 L56 「2026年に亡くなった場合」와 같은 해 사망 독자를 상정)
- 칼럼 문장: 「ただし、第15条により遺産に加算される死亡前2年以内の贈与財産に対応する税額は、第6条第3項により受贈者が納めます。」
- 1차 원문:
  - 遺產及贈與稅法 §6③：「依第十五條第一項併入被繼承人遺產總額課稅之受贈財產，按各受贈財產占遺產總額比例計算之遺產稅額，應以受贈人為納稅義務人，並以受贈財產為限負繳納義務，…不適用第一項規定。」
  - §6⑤：「自中華民國一百十三年十月二十八日起至本法一百十五年八月二十一日修正之條文施行前發生死亡事實之案件，被繼承人之配偶拋棄繼承或喪失繼承權者，適用第三項規定。」
  - §59：「本法自公布日施行。」 / 沿革 16：「中華民國一百十五年九月十一日總統華總一經字第 11500086661 號令修正公布第 6、17-1、23、26、30、41、51 條條文」
- URL: https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=G0340072&flno=6 ; …&flno=59 ; https://law.moj.gov.tw/LawClass/LawHistory.aspx?pcode=G0340072
- 무엇이 문제: §6③은 신법 시행 후(2026-09-11 공포·§59 公布日施行) 사망분에 일반 적용되고, 그 이전(2024-10-28~) 사망분은 「被繼承人之配偶拋棄繼承或喪失繼承權者」일 때만 적용(§6⑤). 칼럼은 무조건 서술. 표가 「2026年に亡くなった場合」 금액이라 1~9월 사망 독자가 오독할 수 있음. §6⑤의 「八月二十一日」이 三讀일인지 시행일인지는 법문만으로 확정 못 함(U-1).
- 고친 문장 제안: 「改正後（2026年9月11日公布）に亡くなった場合、第15条により遺産に加算される死亡前2年以内の贈与財産に対応する税額は、第6条第3項により受贈者が納めます。2024年10月28日以後で改正前の死亡については、被相続人の配偶者が相続を放棄したか相続権を失った場合に限って同項が適用されます。」
- 같은 문장이 ko/en/zh 249에도 있음(F-031 4개 언어) — 같은 처리 필요.

### M-2 MISSING-COND (경미~중간, 리드 판단): §17-1 剩餘財產差額分配請求權 공제가 §17② 적용 제외에 없다는 점을 안 씀
- 줄: L62 「妻が台湾籍でも、亡くなった方が韓国籍であれば配偶者控除はありません。」, L54 「控除は大きく減ります」, 표 L59
- 1차 원문:
  - 遺產及贈與稅法 §17-1①：「被繼承人之配偶依民法第一千零三十條之一規定主張配偶剩餘財產差額分配請求權者，納稅義務人得向稽徵機關申報自遺產總額中扣除。」
  - §17② (적용 제외 범위는 「前項」=§17①뿐)：「被繼承人如為經常居住中華民國境外之中華民國國民，或非中華民國國民者，不適用前項第一款至第七款之規定；前項第八款至第十一款規定之扣除，以在中華民國境內發生者為限；…」
  - 涉外民事法律適用法 §48②：「夫妻無前項之合意…其夫妻財產制依夫妻共同之本國法；無共同之本國法時，依共同之住所地法；…」
- URL: https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=G0340072&flno=17-1 ; …&flno=17 ; https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000007&flno=48
- 무엇이 문제: 칼럼 사례(한국 국적 남편·대만 국적 아내가 대만에 거주)는 공통 본국법이 없어 共同의 住所地法=대만법이 부부재산제를 정할 수 있고, 그러면 民法 §1030-1 청구와 §17-1 공제가 문제될 수 있음. §17-1은 §17②의 제외 대상이 아님. "配偶者控除はありません"은 §17①1(553万)만 뜻하지만 독자는 배우자 공제 전반이 없다고 읽을 수 있음. 비국민 피상속인에게 §17-1이 실무에서 어떻게 적용되는지는 확인 못 함(U-2) — 조문 문언 근거만.
- 고친 문장 제안(L62 해당 문장 뒤에 1문장): 「ただし、第17条の1の剰余財産差額分配請求権の控除は第17条第2項で除外されていません。夫婦の財産制が台湾法によるときは、この控除の適用を検討する余地があります（民法第1030条の1）。」
- 참고: 같은 조항을 설명하는 ja 231이 있어 링크 연결 가능.

### O-1 OVERBROAD (경미): 「税の手続きが終わるまで、財産は動かせません」
- 줄: L72 (첫 문장)과 같은 문단의 第8条 문장
- 칼럼 문장: 「税の手続きが終わるまで、財産は動かせません。第8条は、遺産税を完納するまで遺産の分割、遺贈の引渡し、移転登記を認めていません。」
- 1차 원문: 遺產及贈與稅法 §8①：「遺產稅未繳清前，不得分割遺產、交付遺贈或辦理移轉登記。…但依第四十一條規定，於事前申請該管稽徵機關核准發給同意移轉證明書，或經稽徵機關核發免稅證明書、不計入遺產總額證明書或不計入贈與總額證明書者，不在此限。」 / §41①：「…其有特殊原因必須於繳清稅款前辦理產權移轉者，得提出確切納稅保證，或同意以符合稅捐稽徵法第十一條之一規定之應稅不動產設定抵押權予稽徵機關，申請該管主管稽徵機關核發同意移轉證明書。」
- URL: https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=G0340072&flno=8 ; …&flno=41
- 무엇이 문제: §8은 분할·유증 인도·이전등기를 막고 同意移轉證明書 등의 예외가 있는데, 「財産は動かせません」은 그보다 넓고 예외도 안 씀(230 3개 언어는 예외를 씀). 보수 방향이라 독자 손해 가능성은 낮음.
- 고친 문장 제안: 「遺産税の手続きが終わるまで、遺産の名義は原則として動かせません。第8条は、遺産税を完納するまで遺産の分割、遺贈の引渡し、移転登記を認めていません（事前に同意移転証明書の発行を受けた場合などを除きます）。」

## UNVERIFIED

- U-2: §17-1 공제가 비국민 피상속인(한국 국적)에도 실무상 허용되는지(국세국 적용례·해석 函釋). 조문 문언상 제외 근거는 못 찾았으나 적용례는 못 찾음 — M-2 제안 문구를 "検討する余地"로 헤지한 이유.
- 참고(미판정): 財政部稅務入口網 3111의 최종 갱신일이 112-04-27, 3108이 112-04-27로 표시. 현행 여부는 사이트 표시 기준으로만 확인(2026-10-07 접속 시 열림).
