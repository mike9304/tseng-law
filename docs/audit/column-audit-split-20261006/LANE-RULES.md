# 칼럼 감사 레인 운영 규칙 (2026-10-06~07 작업에서 확정, 다음 세션용)

정책 본문은 `POLICY.md`. 아래는 실제 작업에서 정해진 세부 규칙과 함정이다.

## 편집 범위
- 변호사 명의 글(author 필드 없음): 원문 문장 선택·이동·삭제, 리드가 원문으로 확인한 사실 정정, 최소 연결 구만. 새 법률 설명 금지. 편집한 파일은 **변호사 직접 검토 미경유**로 보고한다.
- AI 작성 글(author: legal-ai-assistant): 연결 문장을 새로 쓸 수 있으나 법적 내용은 원문이나 확인된 정정에서만. 새 문장은 connectors 기록.
- 사실 정정은 대조 에이전트의 제안을 그대로 쓰지 않는다. 리드가 1차 원문(law.moj.gov.tw, law.go.kr, 판결 원문, 정부 공고)을 직접 열어 확인한 문구만 fixspec에 올린다. 같은 서술이 있는 다른 언어판에 같은 ID로 전파한다.
- 테스트가 본문을 해시로 고정한 "reviewed" 칼럼(예: zh 087)은 손대지 않는다. 편집 전 `grep -l createHash src/**/__tests__` 확인.
- 다른 레인이 잡은 칼럼(Studio items의 .claim/.ready/.rewritten)은 slug 단위로 제외하고, 편집할 slug는 Studio `items/<lang>-<num>-<slug>/.parked`로 표시했다가 배포 후 해제한다.

## 줄이는 기준
- 분할(SPLIT)은 독자 질문이 둘 이상이고 각 편이 언어 중앙값 0.6배 이상일 때만. 길이·법령 수·소제목 수는 선별용일 뿐 분할 근거가 아니다.
- TRIM에 분량 숫자 목표를 두지 않는다(단서 문장이 잘린 실증이 있다).
- HUB-TRIM(겹치는 절을 첫 문장 + 링크로)은 링크 대상 칼럼이 같은 깊이로 다룰 때만. 대상에 없는 내용은 남긴다 — 감소폭이 작아도 그것이 맞다.
- FAQ 답을 질문 없이 본문 첫 문단으로 복사한 것(D-001)은 삭제. 단 소제목이 곧 질문인 Q&A형 칼럼은 해당 없음. 페이지가 프런트매터 FAQ를 "자주 묻는 질문" 절로 렌더링하므로 본문에 같은 절이 있으면 중복.
- 작성 지시문 유출(D-002: "Do not state…", "…적어서는 안 됩니다")은 평서문으로.

## AI 반복 구조
- R-Q1: 독자를 재판관으로 부르는 2인칭 수사 질문(「如果由你來判…」 「여러분이 재판부라면…」 "If you were the judge…" 「あなたが裁判官なら…」)은 대체 문장 없이 삭제.
- R-Q2: 2인칭 없는 쟁점 제시 질문은 글당 1개까지, 소제목과 같은 질문이면 본문 쪽 삭제.
- 규칙 B(판결 링크 반복): 판결마다 본문 첫 인용 1회 + 심급 표 각 행 + 출처 목록 + 블록 인용 직후 1회만 링크. 괄호가 그 문단의 유일한 귀속이면 링크 없는 짧은 표시로: zh 「（一審判決）（高院判決）（最高法院判決）」, ko 「(1심 판결)(고등법원 판결)(최고법원 판결)」, ja 「（一審判決）（高等法院判決）（最高法院判決）」, en "(first-instance / High Court / Supreme Court judgment)". 같은 심급 판결이 둘이면 형사·민사로 구분. 출처 목록이 없는 칼럼은 먼저 資料來源 목록을 만든다.
- 금지: 지운 내용을 예고문(「예외도 있습니다.」 류)이나 자문자답 질문으로 대체하지 않는다. 짧은 문장 지표를 올리려고 문장을 쪼개지 않는다.

## read_time
- 테스트가 쓰는 공식에 맞춘다: zh Math.ceil(보이는 한자/400), en Math.ceil(단어/200), ja 600字/분, ko는 기존 값×어절 비율. 본문 변화가 10% 이하면 그대로 둔다.

## 함정
- law.moj.gov.tw `LawSingle`은 공포됐지만 시행일이 정해지지 않은 개정본을 기본으로 보여 준다(상단 「尚未生效…最後生效日期：未定」). 시행 중 문언은 `LawOldVer.aspx?pcode=…&lnndate=…`로 확인(F-030 음주운전 과태료 사례).
- 法規整編 기준일 이후 개정(예: 산업혁신조례 2026-09-30)은 沿革에 아직 없다 — 法務部 최신 소식으로 확인.
- 사건 당시 시행판과 현행판이 다른 금액은 "현행(시행일)"과 "사건 당시"를 구분해 쓴다(F-027).
- Python urllib은 law.moj.gov.tw 인증서 검증에 실패한다 — curl 사용. judgment.judicial.gov.tw는 봇 차단될 때가 있어 다른 호스트에서 열었다.
- zsh: `$var`는 단어로 나뉘지 않는다(`${=var}`), `read`는 연속 탭을 합친다(빈 칸이 있는 TSV는 다른 방식으로 파싱).
- 기존 칼럼 수정은 임베딩 대기 목록(`column-embeddings-pending.json`, 새 칼럼 전용)에 올리지 않는다. content-sync 테스트 통과로 충분.
- 고정 테스트가 lastmod를 발행일과 같게 고정한 경우, 정정한 파일만 예외 집합으로 명시한다(검사 자체는 유지).
- Vercel 배포는 다른 레인 커밋과 겹치면 15분 이상 걸린다. 실서비스 확인은 배포 상태가 아니라 페이지 내용으로.
