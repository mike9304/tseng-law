# notes — ko 003 TRIM

## 확인한 원문 (2026-10-06, law.moj.gov.tw LawSingle.aspx 직접 열람)
- 형법 제276조 (pcode=C0000001&flno=276): 「因過失致人於死者，處五年以下有期徒刑、拘役或五十萬元以下罰金。」 → Q4로 옮긴 "과실치사는 제276조" 맞음.
- 형법 제287조 (flno=287): 「第二百七十七條第一項、第二百八十一條及第二百八十四條之罪，須告訴乃論。但公務員於執行職務時，犯第二百七十七條第一項之罪者，不在此限。」 → 제276조는 열거에 없으므로 비친고죄(Q5의 "과실치사 등 비친고죄" 근거). 제284조는 항 구분 없이 통째로 열거되어 Q3의 "과실치상·과실중상 모두 친고죄" 서술과 충돌 없음.
- 형법 제284조 (flno=284): 과실상해 1년 이하/10만 원 이하 벌금, 중상 3년 이하/30만 원 이하 벌금. Q3 문장과 모순 없음.
- 형법 제41조 (flno=41): 최고 본형 5년 이하의 죄로 6개월 이하 선고 시 易科罰金 가능(단서 예외 있음), 易服社會勞動도 규정. Q4로 옮긴 "벌금 대체 집행도 적용 요건과 예외가 있어 자동으로 허용되는 것은 아닙니다"와 모순 없음. 제41조는 사회봉사 환산(易服社會勞動)도 규정하나 원문 문장은 그대로 둠(새 법률 내용 금지).
- 형법 제185조의4 (flno=185-4), 도로교통관리처벌조례 제62조 (pcode=K0040012&flno=62), 형사소송법 제238조 (flno=238): Q1·Q5 이동 문장과 모순 없음. 제62조 제1항은 인명 피해 없이 규정대로 처리하지 않은 경우의 과태료(1,000–3,000 TWD)와 도주 시 면허정지, 제3항 이하는 부상·사망 사고의 구호·신고 의무를 정함 — 이동한 "물적 피해만 있는 경우에도 … 사고 처리 의무와 행정상 책임" 문장은 제1항과 맞음.

## 확인 못 한 것 (확인 필요)
- 위 7개 조문 외의 본문 숫자·기한·금액·링크는 원문 그대로 두었고 이번 작업에서 재검증하지 않았다(예: Q3 제237조 6개월, 제197조 2년·10년, Q6 감정 규정 제3·10·11조의 6개월·30일, Q15 2026-05-29 개정 급부 기준 TWD 200,000/80,000–3,000,000/3,000,000/3,200,000). 사실점검(B) 레인 대상.
- 출처 블록의 링크 대부분(규칙 제10조부터 제15조, 사법원 PDF 판결 3건 등)은 열어 보지 않았다. URL은 원문과 정규화 비교로 44개 전부 동일함만 확인.

## 숫자
- 본문 길이(공백 제외, H1·H2 제목 포함, 이미지·링크 URL·"더 보기"·출처 제외): 전 6,191자 → 후 5,678자(−513). 내역: Q16–Q20 삭제 −600(제목 포함), 문항 안 삭제 −165, 이동분 재도착 +180(Q16 S1 +28 포함), 사실 정정 F-006·F-007 +44. (R2 복원 3문장은 위 삭제 합계에 이미 반영.)
- inventory.py 방식(출처 블록·더 보기 포함 전체): 6,746자(inventory.tsv와 같음) → 약 6,233자. 원문에는 "## 출처" H2가 없어 inventory가 출처 블록 링크 문구까지 본문으로 센 것이다.
- 목표 범위(ko 3,000–5,000자)에는 약 680자 초과. R2 기준(분량 목표보다 정확성·원문 보존 우선, 문항 사이 중복은 지우지 않음)에 따라 더 지우지 않았다. 5,000자 이하가 필요하면 TRIM이 아니라 분할 여부(손해배상 Q7–Q15 묶음 등)를 따져야 한다.
- read_time: 5,678자 ÷ 500자/분 = 11.4 → "11분 분량". 출처 섹션 제외 기준. 원문의 "8분 분량"은 수기 값이라 이 산식과 맞지 않았다.
- variety_metrics(ko): 원문 FAIL 3건(len_cv 0.439, short 0.062, consec_same_start 3) → draft FAIL 2건(len_cv 0.424, short 0.044), consec_same_start는 2로 통과. WARN 2건(문장 92%가 "니다."로 끝남, 다만·그러나 류 시작 5개)은 원문과 같다. 이 도구는 조문 링크 라벨("284 · 276 · 41" 등)과 "---"도 문장으로 세어 짧은 문장 비율이 부풀려져 있었고, 그 라벨이 사라져 short가 내려갔다. 남은 FAIL 2건은 새 문장 없이 선택·이동·삭제만으로는 고칠 수 없어(문장 쪼개기·짧은 문장 추가 불가) Studio 재작성 레인 몫으로 남긴다.

## 판단이 애매한 곳 (리드 확인 요청)
1. Q20 S2(결과·배상액 비보장)를 도입 문단 끝으로 옮김. 법적 사실은 아니지만 "면책 문구 유지" 지시 때문. 필요 없다고 보면 도입의 마지막 문장 하나를 지우면 된다.
2. Q16 S1("보험사의 처리 범위와 필요한 서류, 통지 기한을 먼저 확인하세요.")은 R3에서 Q15 마지막 문단 끝으로 글자 그대로 옮겼다. 실제 통지 기한 수치는 원문에 없고 이번에 확인하지 않음("확인 필요: 대만 강제보험·임의보험 통지 기한").
3. Q17 S2("실제 형은 … 개월 수로 예측할 수 없습니다")는 유보문에 가깝지만 도입 S2가 양형을 다루지 않고 S3의 "도"가 이 문장을 받아서 S3와 함께 옮겼다. 지우려면 S3의 "도"도 손봐야 한다.
4. Q4 P1이 5문장으로 길어졌다. 문단을 나누려면 "과실치사는 …" 문장 앞에서 자르면 된다(나누면 Q17 이동분이 독립 문단이 됨).
5. Q7 S2를 지우지 않았다(ledger 참조: 목록 도입 + 같은 시작 연속 방지).
6. 출처 블록 3개는 R2에서 원문 자리로 되돌렸고 끝머리 H2도 없앴다. 앵커는 위치 기반(sec-N)이라 Q1–Q15의 앵커는 그대로이고, 외부에서 들어오는 이 칼럼 앵커는 050번 4개 언어와 scripts/qa-traffic-hub.mjs의 `#sec-3`뿐이라 영향 없다(grep으로 확인). sec-16~20은 어디서도 참조하지 않는다.
7. 본문 H2 수가 20 → 15(Q1–Q15)로 바뀐다. H3 3개는 원문과 같다. H2 개수나 Q16–Q20 제목을 고정한 테스트·스냅숏이 있으면 재고정이 필요하다(이 작업에서는 repo를 읽기만 했고 테스트를 돌리지 않음).
8. Q5 P3 S2("합의했다고 무조건 고소를 취하해야 하는 것은 아닙니다")는 원문에서 비친고죄 절에 붙어 있어 읽기 어색하지만 새 문장 금지라 그대로 둠. Q6 P1 S3도 문장이 어색함("이 표·법정 감정·재심의가 자동 절차가 아니고 필수 단계도 아닙니다"). 둘 다 재작성 레인에서 다듬을 대상.
