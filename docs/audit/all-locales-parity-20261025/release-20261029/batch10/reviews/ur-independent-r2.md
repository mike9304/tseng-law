# UR918 독립 R2 — 승인된 두 변경의 표적 종결

판정: M01·O01 해소. 이번 검토 범위의 필수0·선택0이다. 원 R1 보고서와 기록은 그대로 보존했고 원고는 고치지 않았다. 전체6편의 새 독립 검수나 원어민·법률가 승인을 뜻하지 않는다.

현재918 SHA는 `b9b0b439dffac3a438ca215cc42cbf416c68b495714e68491c6b7d7276e7ea84`다. 다른5편은 R1 SHA 그대로다. 저자 R2 manifest `fefe685a9c422ddd807f969158fed408dae0ae5524647ab84cf158f8618b61bc`와 실제 파일을 대조했다.

M01: `اگست میں خریدار نے ایک رضامندی نامے پر دستخط کیے، جس کے بعد اسے اندرونی کام اور صفائی کے لیے گھر میں داخل ہونے کی اجازت ملی۔`를 변경 문단과 앞뒤 대출서신·주택 상태·지급 기록에서 다시 읽었다. 동의서에 서명한 매수인이 작업·청소를 위해 출입 허가를 받은 관계가 명확하다. 다음 문장의 동의서 지칭, 계약상 인도 완료의 증거가 아니라는 법원 판단, 제한된 출입 목적은 유지된다. R1에서 직접 확인한 공식 판결/정본 범위와 맞으며 새 법적 조건을 만들지 않는다.

O01: 소제목 `خط قرض کی پیش رفت کے بارے میں تھا، گھر کی تیاری کی اطلاع نہیں تھی`는 대출 진행상황에 관한 문의와 준비된 주택의 인도 통지의 구별을 자연스럽게 표현한다. 선택 지적을 해소했으며 새로운 필수 법률 오류로 분류하지 않는다.

독립 R1에 직접 보존한 전문에서 제안한 정확 두 치환을 적용해 현재918 바이트를 만들었고, 역치환해 R1 SHA를 복원했다. 프런트매터/FAQ17, URL·숫자 순서는 불변이다. 원 R1 및 저자 보존 기록의 SHA도 직접 확인했다.
