# 台湾で退職後の転職を制限されたら：競業避止条項と補償の確認点

転職先が決まった後、今の会社から「退職後2年間は同業他社で働けない」と言われたら、まず署名済みの契約書と補償の条件を確認してください。署名していることだけで制限の有効性は決まりません。反対に、補償の支払いに疑問があるからといって、入社予定日までに争いが解決するとも限りません。

台湾法でいう「離職後競業禁止」は、退職後の一定期間、競合する仕事などを制限する合意です。日本語では退職後の競業避止義務と呼びます。台湾の労働基準法（勞動基準法）第9条の1は、その合意に4つの要件を求めています。[労働基準法第9条の1](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=N0030001)

この記事は、台湾で現地法人などに直接雇用され、台湾の労働基準法が適用される日本人従業員を対象とします。適用は国籍だけでは決まりません。日本企業からの駐在・出向、委任関係にある董事などの役員、国外勤務や外国法を準拠法とする契約では、雇用関係と適用法を別に検討する必要があります。

## 署名済みでも、4つの要件を満たす必要があります

第9条の1が求めるのは、次の4つすべてです。

| 要件 | 自分の契約・職務で確認すること |
| --- | --- |
| 会社に保護すべき正当な営業上の利益がある | 会社は何を守るために転職を制限するのか。その利益を具体的に説明しているか |
| 担当する地位・職務上、会社の営業秘密に接触し、または利用できる | 肩書だけでなく、実際の担当業務と情報へのアクセス権限はどうなっていたか |
| 期間・地域・職業活動・就業先の範囲が合理的である | いつまで、どこで、どの仕事を、どの相手先で行うことが制限されるのか |
| 競業をしないことで受ける損失に合理的な補償がある | 補償額と支払時期が明確で、制限による負担に見合っているか |

この4要件のどれか1つに違反する合意は無効です。「全社員が同じ書式に署名している」「給与が高かった」といった事情が、各要件の代わりになるわけではありません。[労働基準法第9条の1](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=N0030001)

また、施行細則第7条の1は、合意を書面で行い、制限の範囲と補償の内容を詳しく記載し、会社と従業員の双方が署名または押印したうえで、各自1通を保有することを求めています。入社時の誓約書、昇進時の追加合意、退職時の確認書がある場合は、どの版のどの条項が問題になっているのかをそろえて確認します。[施行細則第7条の1](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=N0030002)

## 「2年以内」でも、制限の範囲を確認します

退職後の競業避止期間は最長2年です。2年を超える期間を定めた場合は、法律上2年に短縮されます。ただし、2年と書けば常に合理的になるわけではありません。施行細則第7条の2は、保護したい営業秘密や技術情報の有効な存続期間を超えないことも求めています。[労働基準法第9条の1](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=N0030001)、[施行細則第7条の2](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=N0030002)

ほかの制限にも、それぞれ基準があります。

| 制限する項目 | 施行細則の基準 | 契約を読む際の確認点 |
| --- | --- | --- |
| 地域 | 元の会社が実際に営業活動を行う範囲に限る | 「全世界」「アジア全域」などの文言が、実際の営業地域と対応しているか |
| 職業活動 | 具体的かつ明確で、従前の職業活動と同一または類似する範囲 | 業界名だけでなく、制限される担当業務が分かるか |
| 就業先 | 具体的かつ明確で、元の会社と営業活動が同一または類似し、競争関係にある相手に限る | 対象企業を特定できるか。会社名や業種だけでなく、競争関係を説明できるか |

例えば、同じ半導体関連企業への転職でも、これまで担当した製品・工程と、転職後に担当する仕事が同じとは限りません。転職先の業種だけで判断せず、旧職と新職の職務内容、勤務地、対象製品などを条項の文言と照合します。これは個別事情を整理するための方法であり、職種名を変えれば制限を免れるという意味ではありません。[施行細則第7条の2](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=N0030002)

## 補償は「基本給の半分」で決めるものではありません

施行細則第7条の3は、毎月の補償額について、退職時の1か月平均賃金の50％を下回らないことを求めています。ここでいう平均賃金は、基本給や最後の給与明細の支給額をそのまま使うものではありません。[施行細則第7条の3](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=N0030002)

労働基準法第2条第4号の平均賃金は、原則として算定事由が生じた日の前6か月の賃金総額と、その期間の総日数を基礎にする法定の概念です。勤続6か月未満の場合や、日数・時間・出来高により賃金を計算する場合には、同号の別の定めも確認します。また、施行細則第2条には、業務上の災害による療養期間、普通傷病休暇、留職停薪（雇用関係を維持した無給休職）など、算定から除外する日・期間の規定があります。給与明細に加え、休暇・休職の記録をそろえ、何を賃金に含め、どの期間を使って1か月平均賃金を算出したのか、計算根拠を確認してください。[労働基準法第2条第3号・第4号](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=N0030001)、[施行細則第2条](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=N0030002)

50％という水準を満たしていても、検討は終わりません。第7条の3は、制限期間中の生活を維持できる額か、期間・地域・仕事・就業先の制限による損失に見合うか、その他の事情も総合的に考慮すると定めています。狭い範囲の制限と、経験を生かせる仕事の多くを長期間失う制限とでは、補償の合理性を判断する事情が異なります。[施行細則第7条の3](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=N0030002)

支払いの条件も確認します。合理的な補償は、退職後に一括して前払いするか、毎月支払うかを合意しなければなりません。在職中に受け取った給付は、この補償に含まれません。「給与に織り込み済み」「以前支給した賞与で補償した」という説明で、退職後の補償に置き換えることはできません。[労働基準法第9条の1第2項](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=N0030001)、[施行細則第7条の3第2項](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=N0030002)

契約書には、対象期間、月額または一括額、その計算式、初回の支払日と以後の支払日がどう書かれているでしょうか。一括払いなら、何か月分に対応する金額なのかも確認します。約束した補償が未払いの場合は、入金記録と支払期限を残し、合意の有効性と、支払義務が履行されているかを分けて整理します。

## 入社予定日から逆算し、会社の主張を書面で確かめます

転職先から内定を得たら、雇用条件書などで新しい職務、勤務地、入社予定日を確認し、競業避止条項と並べます。会社に照会する際は、少なくとも次の点について、回答を記録に残せる形で求めると整理しやすくなります。

1. どの署名済み条項に基づき、いつからいつまでの制限を求めているのか。
2. 新しい仕事のどの活動・地域・就業先が、その制限に当たると考えているのか。
3. 補償はいくらで、どの平均賃金と計算式を使い、いつ支払うのか。

会社が制限を求めない、対象から外す、期間を短くすると回答した場合も、対象の合意・職務・企業・期間を明示した書面を確保します。制限の免除・撤回について契約に通知期限や条件があるなら、その文言と通知日、既に制限を守った期間の補償を併せて確認してください。口頭での「問題ない」という説明だけでは、どこまで合意したのかが後から分かりにくくなります。

これらは、事実と争点を整理するための確認事項です。条項が無効であれば、それだけで転職できなかった期間の損害賠償まで当然に認められる、という関係にはありません。請求する場合は、法的根拠や損害などを別に検討する必要があります。裁判所の仮処分などの命令を受けている場合も、条項への疑問を理由に自己判断で無視せず、命令の内容・効力と不服申立ての手続を確認します。

## 秘密保持義務や最低勤務期間とは分けて考えます

競業避止義務は、退職後に行う仕事を制限するものです。秘密保持義務は、情報の使用・開示・管理などを扱います。競業避止条項が無効でも、また期間が終わっても、会社の営業秘密を自由に持ち出したり、転職先で使ったりできるわけではありません。台湾の營業秘密法は、営業秘密の要件や侵害行為を独自に定め、侵害の排除・予防も認めています。[營業秘密法第2条・第10条・第11条](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=J0080028)

確認資料は、適法に保有できる自分の契約書、給与明細、通知などを中心にそろえます。担当業務やアクセス権限は、まず秘密の内容を書かない概要にまとめます。証拠を残す目的でも、会社の技術資料や顧客情報を無断で私用メール・端末に移す方法は避けてください。

一方、「研修を受けたので一定期間は勤務する」「早期退職時は研修費を返す」といった最低勤務期間の合意は、労働基準法第15条の1の問題です。競業避止条項とは成立要件が異なるため、同じ誓約書に書かれていても、別々に確認します。詳しくは[台湾の最低勤務期間条項：効力・研修費・違約金の判断基準](https://tseng-law.com/ja/columns/taiwan-mandatory-employment-period)を参照してください。[労働基準法第15条の1](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=N0030001)

## 手元にそろえたい資料

| 資料 | 確認する内容 |
| --- | --- |
| 署名済みの雇用契約、誓約書、追加合意、退職時の書面 | 締結日、適用される版、双方の署名または押印、制限と補償の条項 |
| 旧職・新職の職務内容が分かる資料や概要 | 担当業務、製品・サービス、勤務地。秘密の内容を含めない形で整理する |
| 制限対象の企業・地域・業務を示す別紙や通知 | 対象を特定できるか、会社が主張する範囲と契約が一致しているか |
| 退職前6か月分を出発点とする給与明細、賃金内訳、休暇・休職記録 | 平均賃金の算定対象。勤続期間や除外期間に応じて必要資料を追加する |
| 補償の計算書、支払予定、入金記録 | 算定式、月額換算、支払日、対象期間、実際の支払い |
| 制限の免除・撤回・短縮に関する条項と通知 | 誰がいつ、どの範囲について回答したか、補償の取扱い |
| 内定・雇用条件書、退職日と入社予定日の記録 | 制限期間との重なり、実際に予定している仕事 |
| 会社からの請求・警告書、裁判所の書類 | 相手が求める内容、回答や手続の期限 |

最初にそろえるべきなのは、署名済み条項、旧職と新職の内容、補償の計算根拠です。この3点を並べると、「会社が求める制限」「実際に予定する仕事」「その制限に対する補償」のどこに食い違いがあるかを具体的に確認できます。
