审阅范围：本次新建的三篇简体中文稿，以及输入包内现行繁体中文、英文、韩文版本和官方资料复核记录。以下是作者自审，不是独立法律审查、母语者审校或律师核准。

## 具体句子修改与保留条件

### 704：首次申请ARC

1. 原表达：“持居留签证来台，入境后还要向移民署申请ARC。”
   - 问题：没有把取得居留许可、起算日和整合证件例外放在同一法律命题中，读者可能把30天误用于所有入境者。
   - 改为：“30天，从哪一天算起？持居留签证来台并取得居留许可的人，应从入境次日起算……已经持有有效就业金卡等包含ARC功能的证件，属于免另行申请的例外。”
   - 保留：移民法第22条第2项、入境次日、30天、有效四证整合等ARC功能证件的例外；没有把免签入境写成普遍转换资格。
2. 原表达：“照片则采ARC须知的规格，申请签证时用过的照片未必适用。”
   - 问题：只说“未必适用”，没有解释两个阶段的时间规格不同。
   - 改为：“ARC须知采用最近两年的照片，领事事务局学生居留签证须知等签证阶段则要求最近六个月的照片，应分别符合当次申请规定。”
   - 保留：ARC两年与签证六个月没有混用；补上学生签证官方链接。
3. 原表达：“核准后5个工作日内缴费，缴费后等3个工作日再领卡。”
   - 问题：省略申请系统和证件形式，会把学生规则扩及所有柜台申请，也会混淆电子ARC与芯片卡。
   - 改为：限定“学生线上申请”，分别写明核准日起五个工作天内缴费、六个月以下电子ARC缴费后下载打印、芯片ARC打印收据并在缴费完成三个工作天后到指定服务站领卡。
   - 保留：缴费起算点、两种领证路径及“柜台申请依自己的通知办理”的边界。
4. 原表达：“一般ARC每年新台币1,000元，可缴三年。”
   - 问题：缴费可能被误读为选择居留年限。
   - 改为：“期限由移民署核定……费用按核定期限计算”，并列出一般三年、首次国民配偶依亲一年、受聘外国特定专业人才五年的不同上限。
   - 保留：不满一年按一年计、直接居留路径加收2,200元、侨生减半而不扩及所有国际学生。

### 705：工作、就学与家庭路径

1. 原表达：“有聘书或入学许可，可以先免签入境再办居留吗？”
   - 问题：问句若单独放在开头，容易把专业人士的法定路径暗示为一般规则。
   - 改为：“一纸聘书或入学许可，并不能单独决定能否在入境后转成居留。符合条件的外国专业人才……正式就学与华语研习则另有签证目的要求。”
   - 保留：专业人才法第16条及学生、华语的不同入境条件，没有以国籍假设读者身份。
2. 原表达：“就读满4个月，并继续注册3个月以上。”
   - 问题：英文资料中“more than three months”和“at least three months”并存，需避免写成必须超过三个月。
   - 改为：“就读满四个月，并继续注册至少三个月。两个学习条件都要满足。”
   - 保留：四个月完成学习与继续注册至少三个月是AND条件；依现行法第23条第4项第3款“三個月以上”采用“至少三个月”。另保留认可大学附设机构、原签证目的、每周15小时、请假计入缺课且不超过四分之一。
3. 原表达：“专业人才的家属可以免签入境后申请居留。”
   - 问题：主申请人类别和家属范围过宽，可能把父母、所有成年子女或其他ARC持有人都纳入。
   - 改为：限定在台从事专业工作的外国专业人才或外国特定专业人才已获居留或永久居留，家属仅列配偶、未成年子女、因身心障碍无法自理生活的成年子女。
   - 保留：第16条第2项、免签或停留签证入境路径、父母及其他成年子女不在该名单、其他居留类别另审及第23条排除规定。
4. 原表达：“依亲配偶可依第15条申请工作许可。”
   - 问题：没有区分国民配偶免许可与特定、高级专业人才配偶自行申请许可。
   - 改为：分列就业服务法第48条第1项第2款的免许可，以及专业人才法第15条仅适用于外国特定专业人才及外国高级专业人才配偶的本人申请。
   - 保留：两条路径没有扩及所有外国居民配偶或学生。

### 706：延期、异动与再入境

1. 原表达：“地址变更和居留原因变更都要在30天内办理。”
   - 问题：期限相同但起算日不同，且第23条之1以外还有15天路径。
   - 改为：用表格分列次日起30天、发生日起30天、发生日起15天，正文再次说明“两种‘30天’不能混用”。
   - 保留：地址及服务处所依第31条第6项从次日起算；第23条之1事由变更依办法第7条从当日起算；范围外先向领事事务局或分支机构重新申请居留签证，再办移民署手续。
2. 原表达：“离职或毕业后可申请六个月或一年延期。”
   - 问题：会把办法第10条、专业人才法第17条和毕业后的第11条混成同一资格。
   - 改为：分三项列明应聘、投资等外国人的六个月加一次、符合第17条者的六个月加一次，以及正式学制毕业者的一年加一次。
   - 保留：均须届满前申请；分别总计最长一年、一年、两年；第17条从原期限届满次日起算且不自动延长工作权限，华语课程结业不等于正式毕业。
3. 原表达：“毕业后的延长居留仍须雇主申请工作许可。”
   - 问题：会漏掉2026年1月1日起施行的专业人才法第12条法定豁免，也会把豁免扩及所有毕业生。
   - 改为：仅对“已在台湾取得副学士以上学位、以应届毕业生身份获移民署核准毕业后延长居留者”写明许可期间免申请工作许可，并明确排除学位尚未取得者、所有毕业生或所有求职ARC持有人的概括适用。
   - 保留：学位、应届毕业生身份、移民署许可及许可期间四个条件；与第17条居留延长分开表述。
4. 原表达：“申请中出国可能影响案件。”
   - 问题：范围不清，容易被读成所有延期申请一律禁止出国。
   - 改为：只说明专业人才及眷属试行线上申请在审查中出国时不继续审查、返台须具备资格后重新申请，并明确不是所有延期案件一律禁止出国。
   - 保留：该试行路径的特定规则；申请收据不等于重入国许可的一般提示。
5. 原表达：“ARC遗失须附报案证明。”
   - 问题：把声明或报案的选择关系写成唯一必需文件。
   - 改为：“遗失声明书或报案证明等，无须一律提出警察报案证明。”
   - 保留：补发规费500元、在台与海外路径不同、本人账号与他人账号或代理申请的验证要求不同、旧式移工卡及单次重入国许可另依公告第4点。

### 704

- R02：BOCA境内居留签证说明 → 签证签发日起30天。
- R08、R19：规费标准第3条、移民法第22条、专业人才法第8条及办法第12条 → 1,000元/年、不满一年按一年、2,200元加收、侨生减半、一般三年、首次国民配偶一年、特定专业人才五年。
- R09：NIA 0902 → 国民配偶首次申请同行及台湾结婚登记；一年上限另由办法第12条支持。
- R18：就业服务法第43、48条 → ARC不等于所有工作许可；国民配偶免许可有身份及居留条件。
- NIA 0902行政细节 → 两年照片、正副本、在职/在学/亲属与住址材料、十个工作天、补件后重算、次日起15天及海外材料三个月。

- R12：专业人才法第16条第1、2项 → 专业工作许可或免许可、入境方式、主申请人居留状态与限定家属范围均为条件。
- R13：移民法第23条第1、4项 → 一般停留签证60天以上及无限制注记；就学的入境目的与居留目的须一致，并保留法定排除。
