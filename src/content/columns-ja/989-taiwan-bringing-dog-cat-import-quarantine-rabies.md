# 東京の猫を連れて台湾へ引っ越すとき、空港からそのまま家に帰れるのか：犬猫の輸入検疫

東京で飼っている猫を連れて台北へ赴任する場合、到着した空港からそのまま新居へ連れて帰れるのでしょうか？日本から出発するなら、書類がそろっていれば隔離はありません。台湾農業部が公告する狂犬病の非発生地域（狂犬病非疫區）に日本が入っているからです。ただ、乗り継ぎの経路と、日本で飼っていた期間しだいで結論が変わります。

## 日本は「非疫區」に入っている

農業部動植物防疫検疫署（以下「防検署」）が示す狂犬病非疫區は、日本、シンガポール、オーストラリア、ニュージーランド、米国ハワイ州とグアム、英国、スウェーデン、アイスランド、ノルウェー（スバールバル諸島を除く）、エストニア、チェコです。防検署は、この一覧にない国・地域には狂犬病発生地域（疫區）の規定を適用すると明記しています。韓国、米国本土、中国大陸は一覧の外です。

細かな要件は「犬貓輸入檢疫條件」（犬猫輸入検疫条件）に書かれています。現行版は農業部が2024年2月27日付の農防字第1131867278號公告で改正し、同月29日から施行されたものです。根拠法は動物傳染病防治條例で、その[第33條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=M0130003&flno=33)第1項が、外国の動物伝染病の状況を公告したうえで、輸入前の検疫同意文書の申請、輸出国の検疫証明書の提出、隔離検疫といった措置をとるよう定めています。

判定の基準時は、検疫条件の第2点にあります。動物が元の国を離れて輸送手段に積み込まれた時点の公告内容で決まります。第3点はさらに、非疫區の規定を使える犬猫を次の三つに限っています。

- 生後180日未満で、生まれてからずっと非疫區で飼育されている
- 生後180日以上で、台湾への輸入前180日間ずっと非疫區で飼育されている
- 台湾から出国した犬猫で、出国後から戻るまでずっと非疫區で飼育されている

ソウルで3年暮らし、3か月前に東京へ移ってきた犬はどうなるでしょうか？（架空の例です）東京から出発しても、疫區からの輸入として扱われます。180日に足りないからです。

## 日本から出発する場合の要件

第4点が求めるのは、マイクロチップの装着と、輸入の1年前から30日前までの間の狂犬病ワクチン接種です。接種時に生後90日を過ぎていること、ワクチンは不活化ワクチンか台湾で使用が認められた狂犬病ワクチンであることが条件です。3年有効のワクチンを打っていても、直近の接種日が輸入前1年以内に入っていなければなりません。防検署の問答集もそう説明しています。

申請は輸入の20日前までです。到着する空港・港を管轄する検疫機関に輸入検疫同意文書（輸入檢疫同意文件）を申請し、本人確認書類と獣医師が発行した狂犬病ワクチン接種証明書の写しを付けます（第5点）。接種証明書には、動物の種、性別、年齢、マイクロチップ番号、接種日、ワクチンのメーカーまたは種類を中国語か英語で記載します。防検署は「輸入犬貓檢疫資訊網」でのオンライン申請を案内しています。

出発前には、日本の動物検疫所で輸出検疫証明書を取ります。台湾側が求める記載事項は、狂犬病の臨床症状がないこと、接種日とワクチンの情報、そして輸出前180日間または出生以来ずっと非疫區で飼育されていたことです（第6点）。到着時には同意文書の写し、検疫証明書の原本、航空運送状か税関申告書の写しを出して検疫を申請します（第7点）。内容が合っていて法定伝染病の感染のおそれがなければ輸入動物検疫証明書が発行され、隔離はありません（第8点）。

見落としやすいのが乗り継ぎです。問答集は、日本を出発して韓国で乗り継ぐケースを、疫區経由の例として挙げています。その場合、輸出国の検疫機関が番号入りの封印で輸送ケージを封じて証明書に番号を記載するか、乗継地の検疫機関・税関・航空会社などが「空港・港の外に出ておらず、他の感受性動物と接触していない」ことを証明する書類が要ります。どちらもなければ7日間の隔離です（第9点）。

## 韓国など疫區から来る場合

疫區からの一般の犬猫には第10点が適用されます。マイクロチップとワクチンの要件は同じです。違いは、狂犬病中和抗体価の検査が加わる点にあります。

検査は世界動物保健機関（WOAH）の狂犬病参照検査施設か、防検署が指定した検査施設で受け、0.5IU/ml以上で合格です（第1点）。採血の時期は、原則として輸入の90日前から1年前までの間です。前回合格した検査がある場合はその採血日から90日～1年の間に採り直して輸入前1年以内に入る方法があり、台湾から出国する前に採血した場合は輸入前1年以内であれば足ります。

採血日から入国日まで、少なくとも90日。引っ越しの日取りが決まってから検査を始めると間に合わないことがあります。

申請はやはり輸入の20日前までで、隔離施設の手配も同時に行われます（第11点）。問答集によれば、同意文書が届いた時点で隔離ケージの予約も済んでいます。到着後は検疫官が指定隔離施設まで動物を護送し、7日間の隔離を終えて法定伝染病の感染のおそれがなければ、輸入動物検疫証明書が出ます（第14点、第24点）。

2024年の改正で、7日間の隔離を免除される道ができました。輸入前180日から1年の間に採血して合格し、さらに次のどちらかを満たす場合です（第11点第2項）。

- 輸入の120日前までに同意文書を申請した
- 輸出国の動物検疫機関が検査結果の声明書を、または検査施設が合格報告書を、防検署へ直接送った

輸入前180日以内の採血でも、その採血日が前回合格した検査の採血日から180日～1年の間であれば、同じ方法で免除を受けられます。台湾から連れ出す前に台湾で採血して合格し、その採血日から1年以内に戻る犬猫も隔離なしです。

## 隔離施設と費用

防検署が公表している隔離施設は現在3か所です。桃園空港、松山空港、台北港、台中空港から入る場合は桃園分署觀音檢疫站、高雄空港から入る場合は國立屏東科技大學附設獸醫教學醫院です。國立中興大學の獣医教学病院は一時休止と表示されています。

費用は申請者が負担します。留置、運送、隔離中の飼育管理と医療、検体の採取・送付、マイクロチップの装着、ワクチン接種、さらに返送や殺処分の費用まで含まれます（第23点）。隔離中にワクチン接種日から1年を過ぎると、追加接種が1回行われます（第25点）。週末や祝日の到着には護送と受入れの対応ができないという防検署の案内もあるので、到着日は平日にしておくのが無難です。

日程が変わったときは、同意文書の有効期間が切れる前で、かつ変更後の輸入日の10日前までに、1回に限って変更を申請できます（第5点第3項、第11点第6項）。2回目は新規申請になります。

## 書類に不備があったら

動物傳染病防治條例[第34條之2](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=M0130003&flno=34-2)は、検疫証明書を出さなかったり記載が規定と違ったりした場合、検疫機関が隔離期間の延長、診断検査、追加接種、期限を付けた書類の補正、それができなければ返送か殺処分を命じられるとしています。検疫条件はこれを日数に落とし込んでいます。疫區からの一般の犬猫について定めた第15点の内容は次のとおりです。

| 不備 | 扱い |
|---|---|
| マイクロチップなし、証明書に抗体検査の記載がなく報告書原本もない | 返送・殺処分または隔離。隔離の場合は生後90日以降に接種し、30日後に採血、合格後は採血日から97日まで隔離（チップがなければ隔離施設到着後すぐ装着）。不合格なら手続を繰り返すか180日間隔離 |
| 輸出国検疫証明書の原本なし、チップ番号の記載漏れ・不一致 | 上の行と同じ。台湾から輸出されて1年以内に戻り、台湾の輸出検疫証明と、台湾出国前かつ輸入前1年以内の採血による合格報告書原本を出せば、接種・採血なしで30日間隔離 |
| 種・性別・年齢の記載漏れや不一致、臨床症状なしの記載漏れ | 返送・殺処分または30日間隔離 |
| ワクチン情報が要件に合わない | 返送・殺処分、または要件どおり接種し直し、その接種日から30日まで隔離 |
| 採血時期が要件に合わない | 返送・殺処分または採血日から97日まで隔離 |

日本からでも油断はできません。第9点も、返送・殺処分・隔離のいずれかで扱います。マイクロチップや証明書原本がない場合、チップ番号の記載漏れ・不一致、輸出前180日間（または出生以来）非疫區で飼育された旨の記載がない場合は、同じ97日の手続です。証明書原本とチップ番号の不備には、上の表の30日の特例が同じように付きます。ワクチン情報が合わなければ接種し直して30日、種・性別・年齢や臨床症状なしの記載の不備と疫區での乗り継ぎは7日間の隔離です。

補償の問題もあります。輸出入検疫で伝染病の疑いにより殺処分された動物と、隔離中に死亡した動物には補償金が支給されません（[第40條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=M0130003&flno=40)第3項）。

## 申告せずに持ち込んだ場合

検疫対象物が到着したら、輸入者は検疫機関に検疫を申請します。旅客が携帯する場合も入国時に申請が必要です（[第34條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=M0130003&flno=34)第1項・第2項）。郵送での輸入は禁止され、送られてきたものは返送、没入または廃棄となります（同條第3項）。

過料の額は違反の種類で変わります。旅客が検疫を申請しなかった場合は1万～100万台湾ドルです（[第45條之1](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=M0130003&flno=45-1)）。輸入者が到着した空港・港で検疫を申請しなかった場合は5万～100万台湾ドルで（[第43條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=M0130003&flno=43)第11款）、検疫機関は必要な措置も命じます（第35條第4項）。同意文書を事前に取らずに輸入した場合と、隔離施設を確保せずに輸入した場合は、それぞれ3万～15万台湾ドルです（[第45條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=M0130003&flno=45)第12款、第15款）。

隔離から勝手に連れ出すと、さらに重くなります。指示された期間内に動物を隔離施設へ送らなかったり、許可なく動物を移動させたりすると5万～100万台湾ドルの過料です。それによって疫病が広がった場合は、3年以下の懲役または拘役に処され、100万台湾ドル以下の罰金が併科されることがあります（[第42條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=M0130003&flno=42)）。

フードやおやつも検疫の対象になりえます。問答集によると、偶蹄類（豚・牛・羊など）や家禽の成分を含む犬猫用の食品・かむ製品は検疫が必要です。成分がわからなければ、未開封のまま持参して検疫カウンターで申告するよう案内されています。

## 輸入できない犬種

動物保護法[第8條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=M0060027&flno=8)に基づき、当時の行政院農業委員会は2021年10月26日付の農牧字第1100042728號公告で、2022年3月1日からピット・ブル・テリアの飼育と輸入を禁止しました。対象はアメリカン・ピット・ブル・テリアとアメリカン・スタッフォードシャー・テリアです。違反すると5万～25万台湾ドルの過料（[第26條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=M0060027&flno=26)第1項第2款）で、動物は没入されることがあります（[第32條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=M0060027&flno=32)第1項第5款）。防検署によれば、2022年2月28日以前から飼っているピット・ブルはこの輸入禁止の範囲外です。ただし動物保護法の主管機関（中央は農業部、地方は各直轄市・県市政府）に裏付け資料を出して確認を受けてから、輸入検疫の手続に進みます。

中国大陸から来る犬猫で、台湾からの輸出検疫の記録がないものは、経済部國際貿易署の専案輸入許可を先に取り、その許可文書を検疫申請のときに提出します。台湾での在留資格については[台湾のビザの選び方](/ja/columns/taiwan-visa-residence-work-study-family)で取り上げました。

## 台湾の弁護士に依頼できること

出発前であれば、台湾の弁護士は獣医師の接種証明書、抗体価の報告書、輸出国の検疫証明書が検疫条件の各項目に合っているかを突き合わせ、乗継経路と日程から隔離免除の要件を満たせるかを検討します。到着後に返送、殺処分、隔離延長、過料の処分を受けた場合、訴願は処分書が届いた日の翌日から30日以内に提起しなければなりません（[訴願法第14條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=A0030020&flno=14)第1項）。その期間内に、処分の根拠と事実関係を争う書面を準備します。ご相談は[wei@hoveringlaw.com.tw](mailto:wei@hoveringlaw.com.tw)で受け付けています（[民事・行政手続のご案内](/ja/services/civil)）。昊鼎国際法律事務所 台北事務所：103 臺北市大同區承德路一段35號7樓之2。台中事務所：40453 臺中市北區館前路19號6樓之1。

東京から猫を連れて行くなら、ワクチンは輸入の30日前までに打ち終え、同意文書は20日前までに申請します。韓国で乗り継ぐ便を選ぶ場合は、ケージの封印か乗継地の証明書の手配が必要です。
