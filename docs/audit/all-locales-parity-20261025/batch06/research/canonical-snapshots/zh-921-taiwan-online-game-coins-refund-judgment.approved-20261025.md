玩家把帳號內的剩餘金幣換算成新臺幣24萬3,548元，請求業者退還。法院沒有准許。帳號還有餘額，卻已沒有未使用的付費點數；這是該案兩造不爭執的事實（[行政院消保處收錄的判決全文](https://cpc.ey.gov.tw/File/343C8EEBB5F122CF/6abbfdf1-cf31-4198-9eec-7421dab07bb8?A=C)，紙本第140至153頁）。

臺灣基隆地方法院109年度消簡上字第1號判決，於2021年9月13日駁回玩家的上訴，並載明不得上訴。法院檢查的是該遊戲金幣的實際功能及退費條款，沒有把所有虛擬道具一概排除在消費者保護之外。

## 儲值後，金幣被拿來做什麼

本案契約讓玩家先購買點數，再用點數取得遊戲服務或商品。剩下的金幣則供玩家在遊戲中對局，具有籌碼的功能。法院認為，這些金幣已不屬於契約約定應退的未使用付費點數，也不是業者收取的遊戲費用，因而未准許換算成現金返還。

法院還指出，若允許玩家把這種對局籌碼向業者兌成現金，會涉及賭博。這段理由與本案玩法相連；用在另一款遊戲時，仍須查清楚金幣如何取得、能換什麼、是否已經用於遊戲，不能只因畫面寫著「金幣」就拒絕退費。完整理由見[判決第八點](https://cpc.ey.gov.tw/File/343C8EEBB5F122CF/6abbfdf1-cf31-4198-9eec-7421dab07bb8?A=C)，紙本第148至152頁。

契約終止了，為何沒有退款？在這件案件，玩家自己也已表示終止契約，所以法院可以確認終止效果，再處理剩餘金幣是否屬於退費客體。這不等於法院認定業者原先的全部停權或終止理由都合法。

## 今天的退費規則仍保障未使用點數

現行[網路連線遊戲服務定型化契約應記載及不得記載事項](https://www.ey.gov.tw/File/C27658C15073FF69?A=C)第十八點，允許消費者隨時通知業者終止契約。未使用的付費點數或遊戲費用，須於扣除必要成本後，在終止契約後三十日內退還，或由雙方同意其他處理方式。並沒有一律不退的規則。

「必要成本」也要有內容。收到退費計算時，可要求業者分別列出未使用餘額、扣除項目與計算依據，再核對契約，不能僅從業者設定的固定比例推知它一定合理。

這份現行規範的最近修正自2023年1月1日生效，時間在上述判決之後；本案是以當時契約及適用規範判斷。現行第四點另保留開始遊戲後七日內以書面解除契約，並請求退還未使用付費點數的安排。已超過七日，也仍可依第十八點處理終止與剩餘費用。

## 畫面餘額，少了哪一段紀錄

只有一張帳號截圖，很難分辨原始購買點數、兌換所得金幣與遊玩後餘額。紀錄可以這樣對照：

| 資料 | 可釐清的問題 |
| --- | --- |
| 付款憑證與儲值明細 | 實際付了多少錢，取得哪種點數或服務？ |
| 點數兌換及遊戲歷程 | 點數何時轉換，轉換後的金幣如何使用？ |
| 終止通知與退費明細 | 何時終止，業者認列的未使用餘額及扣款理由為何？ |

業者至少須保存三十日的個人遊戲歷程，並依規範受理查詢；收到申請後，須在七日內提供。資料有保存期限。發生爭議後儘早申請，可減少只剩最後餘額畫面的情況。現行規範同時禁止約定，糾紛只能以業者保存的歷程及電子資料為準（[應記載事項第九點、不得記載事項第六點](https://www.ey.gov.tw/File/C27658C15073FF69?A=C)）。

行政院消保處在2026年5月公布的2025年統計中，線上遊戲仍排在第一次消費申訴類型的第二位，案件數則較前一年減少。官方同時要求業者妥善處理帳號封鎖、停權及客服問題（[統計與提醒事項](https://cpc.ey.gov.tw/Page/6C059838CA9744A8/a3642311-5d66-4135-a8da-69c52279e930)）。

退費爭議可先向業者提出，再使用[政府消費申訴管道](https://appeal.cpc.ey.gov.tw/)。若爭點已涉及契約解釋或證據遭拒，可先寄信至[事務所信箱](mailto:wei@hoveringlaw.com.tw)，說明爭議項目與回覆期限，無須提供帳號密碼。要讓請求金額有依據，留下的是金錢如何進入帳號、又如何被使用的紀錄。

資料確認日：2026年10月25日。本文以特定遊戲退費判決說明契約與紀錄的判讀，其他遊戲的點數、道具及終止事由，須依其實際功能分別判斷。
