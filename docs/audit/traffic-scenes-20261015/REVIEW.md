# 611 교차로 스쿠터 좌회전 가상 재연 — Codex 직접 검수

2026-10-15. 한국어·번체중문·영어 칼럼 한 세트와 50초 영상을 직접 검수했다. 초판 영상의 마지막 측면 장면은 후속 검수에서 차량 방향 불일치로 반려되어 교체했다. 변호사, 원어민 또는 Fable의 검토를 받았다고 주장하지 않는다. 이 글과 영상은 실제 사건·판결을 토대로 하지 않으며, 식별 가능한 인물·번호판·회사·사고 장소를 설정하지 않았다.

## 주제와 법령

기존 073은 자동차 우회전과 직진 이륜차, 051은 자동차 좌회전과 직진 이륜차, 601은 승용차의 금지 유턴, 602는 빗길 추돌이다. 611은 바깥쪽에서 진행하던 스쿠터가 교차로에서 좌측으로 움직일 때 직진 승용차와 닿는 별도 상황이다. 최초 선택했던 자동차 우회전 상황은 073과 중복된다는 것을 발견해 폐기했다.

법무부 전국법규자료고의 현행 조문 페이지를 직접 열어 대조했다. [道路交通安全規則 제2조](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=K0040013&flno=2)의 자동차 정의, [제99조](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=K0040013&flno=99)의 현장 표지·표선 우선과 차로 변경·이단계 회전 조건, [제102조](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=K0040013&flno=102)의 신호·표선·회전차 양보, [제94조 제3항](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=K0040013&flno=94)의 전방·병행차 간격 주의, [민법 제184조](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=184)와 [제217조](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=217)의 민사 책임 및 과실상계를 확인했다. 각 조문 URL과 확인 사항은 제작 폴더 `SOURCES.md`에도 있다. 실제 표지와 차로를 모르므로 직접 좌회전이나 이단계 좌회전의 위반 여부를 단정하지 않는다. 속도·거리·과실 비율을 만들지 않았다.

세 언어는 스쿠터의 좌측 이동, 직진차 제동, 가벼운 접촉, 현장 통제의 필요성, 회전차 양보와 직진차의 주의, 민법상 손해배상·과실상계의 조건을 같이 다룬다. 실제 공개 판결을 확인해 넣은 부분은 없으므로 판결 인용도 없다.

## 영상 검수

Codex imagegen으로 기준 장면을 먼저 만들고 Grok CLI `--model grok-4.7 --tools reference_to_video`를 사용했다. Grok 4.7은 지시 모델이며 영상 생성 백엔드의 별도 모델명은 검증되지 않았다. 각 작업의 ndjson·stderr와 완료 receipt, 파일 해시 및 ffprobe는 실행 폴더의 `jobs/`, `qa/`에 있다. 침묵 재시도는 없었다.

처음 생성한 `turn-02-left-movement`와 별도 작업 `turn-02-left-movement-v2`는 둘 다 스쿠터가 우측으로 도는 장면이라 제외했다. 방향을 명확히 한 새 기준 이미지에서 `turn-02-left-crossing-v3`를 생성했고, 접촉 전에 해당 클립의 앞 5초만 채택했다. 최초 마지막 장면 `turn-04-side-aftermath`는 차와 스쿠터가 같은 방향을 향해 추돌처럼 보여 후속 검수에서 제외했다. 교체 장면 `turn-04-dashcam-crosswise-r1`은 직전 전방 영상의 마지막 프레임을 기준으로 Grok 4.7 `reference_to_video` 한 작업으로 생성했다. 최종 배열은 접근 10초, 좌측 이동 5초, 접촉 10초, 전방 사고 직후 10초, 같은 전방 시점의 직후 15초로 총 50초다. 이 시간은 편집 영상의 길이이며 실제 사고 시간이나 위치를 측정한 값이 아니다.

세 언어별 영상에 각 언어의 ‘AI 가상 재연·실측 아님’ 표기를 계속 올렸다. H.264, 1280×720, 24fps, 무음, faststart, 1200프레임이다. 최종 영상·포스터 해시와 작업 선택은 `media-manifest.json`에 있다. 최종 출력의 전환 전후 프레임과 마지막 프레임을 세 언어에서 다시 추출해 확인하고 전 프레임 디코딩을 반복했다. 검토한 프레임에서 읽을 수 있는 번호판·브랜드 로고·식별 가능한 얼굴은 확인되지 않았다. 생성된 신호의 색이나 장소 배치는 법적 판단 자료가 아니다.

후속 검수 수리본은 `runs/20261015-0340/fix-notes-r1.md`에 기록했다. 최종 `npm run typecheck` 및 `npx vitest run`은 통과했고(1424 파일, 14718 테스트 통과), 별도 출력 디렉터리의 프로덕션 빌드는 정적 페이지 2571개를 생성했다. 로컬 브라우저에서 세 언어의 1440px·390px 화면과 영상 재생을 확인했다. 모두 공개 전 검증이며 커밋·푸시·배포는 하지 않았다.
