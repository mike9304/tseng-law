# P2 KO 카드 문구 · r3 (5장, 1080×1350)

이전 c13-r3 레이아웃(core·restaurant·testimony·witnesses·formula)을 쓰고 문구를 고친다. 렌더는 승자 확정 뒤.

## 1 · 결론 (어두운 배경)
- 머리표: 대만 법원 1심 · 협의이혼
- 제목: 이혼 등록까지 했는데 / 법원은 ‘아직 부부’
- 그림: 이혼 합의서 + ‘이혼 등록 완료’ 도장 위에 ‘무효’
- 아래(열린 고리): 증인 한 명이 남편 뜻을 직접 확인한 적이 없었대요.

## 2 · 식당 (증언을 바탕으로 한 가상의 장면)
- 말풍선(아내 → 오래 알고 지낸 지인): 여기 증인란에 서명 좀 해 줘.
- 그림: 이혼 합의서, 부부 서명란 빈칸(점선)
- 아래 1: 식당에서 아내랑 단둘이 만났고, 남편은 그 자리에 없었어요.
- 아래 2: 부부 서명란은 그때 아직 비어 있었어요.

## 3 · 법정 증언 (판결에 적힌 증언 · 요약)
- 머리: 그 지인, 법정에서
- 제목: 남편분 연락처는 / 없어요.
- 목록: 서명 전에도 후에도 남편은 못 만남 / 남편한테 이혼할 건지 물어본 적 없음 / 이혼 등록하는 날도 안 감
- 아래 1: 부부 둘 다 이 증언엔 이의가 없었어요.
- 아래 2: 판사는 그 지인을 증인으로 안 쳤어요.

## 4 · 증인 자격 (판결 이유)
- 제목: 증인은 부부 둘 다 이혼하려는 걸 / 직접 보거나 들었어야 한대요.
- 그림: 남편·아내 / 그 지인(남편 확인 없음, 아내 얘기만 들음) / 다른 증인(판결이 따로 판단 안 함)
- 아래: 부부 중 한 사람한테 전해 들은 것만으론 안 된대요.

## 5 · 알아 둘 것 (대만 협의이혼 요건)
- 제목: 증인 칸은 / 이름만 채우는 자리가 아니었어요.
- 항목: ✓ 서면 합의서 / ✗ 증인 2명 이상 서명 / ✓ 호적 관청(戶政事務所)에 이혼 등록
- 결과 줄: 이 사건은 제대로 된 증인이 많아야 한 명 → 무효
- 아래: 다 같이 한자리에서 서명할 필요는 없지만, / 증인마다 부부 둘 다의 이혼 뜻을 직접 보거나 들어야 해요(판례).
