### M01 — 필수 의미 오류 종결

문제 문장: במחלוקת על עבודות בנייה או שירותים טכניים, אם הוועדה נתנה המלצה או הצעת הסדר לגבי המחלוקת והגישור נכשל משום שהרשות לא הסכימה לה, הרשות אינה יכולה לסרב להעברת אותה מחלוקת לבוררות ביוזמת הספק.

현재 수정: בגישור על עבודות בנייה או שירותים טכניים, הוועדה חייבת לתת המלצה או הצעת הסדר הנוגעת למחלוקת. אם הגישור נכשל משום שהרשות לא הסכימה להמלצה או להצעה, הרשות אינה יכולה לסרב להעברת אותה מחלוקת לבוררות ביוזמת הספק.

이유 및 의미 보존: 조건부로 추천이 있었다고만 쓰던 문장을 위원회가 권고 또는 조정안을 제시해야 한다는 의무로 명시했다. 건설 또는 기술용역 조정이라는 범위, 기관의 불동의 때문에 조정이 실패해야 한다는 인과관계, 공급자의 동일 분쟁 중재 회부와 기관의 거부 불가를 보존했다. [근거](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=A0030057&flno=85-1)

## 독립 실행 증거

`he-current-independent-r2-proof.py`를 직접 실행해 exit 0을 확인했다. 입력 69개 해시 관측(67개 고유 경로)은 시작과 끝에 모두 일치했다. 수정 7개를 Unicode 오프셋으로 정방향 및 역방향 재현했고 현재 파일 전체와 일치했다. 승인 범위 밖 변경은 없다.

원문과 현재 원고의 frontmatter 원문 바이트가 같아서 FAQ 17개와 모든 메타데이터가 동일하다. 숫자 토큰 순서, URL 순서, 출처 꼬리, 제목 배열과 목록 배열도 같다. 현재 문장 배열을 같은 SHA의 실제 CLI 기록과 대조했고, 6편 metrics를 현재 도구로 새로 계산해 기록과 전 항목 일치했다. 총 240문장 중 231개는 동일하고 9개가 교체됐다. 변경 7단락 및 현재 19문장, 앞뒤 문맥을 읽었다.

현재 5편 ReactMarkdown+remarkGfm 렌더 기록의 SHA·body·문단과 실제 원고를 대조했다. 문단 71개, FAQ 14개, 표 2개, 출처 19항목의 기존 실렌더 증거를 사용하며 렌더 구조·현재 구조검사 errors 0 기록의 해시도 검증했다. 원본과 동일한 918의 3 FAQ는 기존 증거로 합쳐 총 17개다. 브라우저의 RTL 화면·FAQ UI·JSON-LD·실배포 검사 주장은 아니다.

915 최초 R2 실제 CLI exit 1 / CV .442 기록을 덮어쓰지 않았다. A01 후 현재 원고의 실제 CLI exit 0 / CV .462 및 새 문장 배열과 연결했다. 다른 4개 수정 원고와 동일 SHA 918도 실제 exit 0이다. 성공한 전체 CLI·구조검사를 다시 돌리지는 않았고, 현재 SHA와 도구 SHA·새 계산 결과·문장 배열을 직접 확인했다.

## 문장 다양성 규칙 5절 재확인

1. 같은 현재 SHA의 실제 CLI 6개 FAIL 0 기록과 도구 바인딩을 확인했다. metrics/문장 배열은 현재 원고에서 독립 재계산했다.
2. 여섯 도입은 바뀌지 않았다. R1 감수의 장면·결과·금액·분쟁 중심 도입 판정을 재사용한다.
3. 현재 짧은 문장 비율 및 길이 배열이 검사 기록과 같다. A01의 24/8 분리는 서로 다른 법적 기능을 기준으로 했다. 긴 문장 반복이 추가되지 않았다.
4. 문단 첫 단어 배열을 다시 생성해 실제 기록과 대조했다. 수정으로 같은 시작 단어 반복 기준을 넘지 않았다.
5. 수정 단락은 의무·조건·사실을 직접 연결한다. 3연속 주장·단서 틀을 추가하지 않았고, 인용 없는 사실·결과 단락은 유지된다.
6. S02의 요청되지 않은 보장 논점 반박과 S01의 집필 지시를 제거했다. 추가적인 기계적 대비 틀은 없다.
7. 결말 단락은 6편 모두 변경하지 않았고 R1 개별 사건 맥락 판정을 재사용한다.
8. 메타데이터/본문의 굵은 강조·숨은 서식·RTL 제어 문자 검사 기록은 같은 SHA에 연결된다. 수정 7곳에 지어낸 1인칭이나 체크리스트 제목을 넣지 않았다.
9. 숫자·기한·URL·FAQ·허구 이미지 표시가 모두 보존됐다. M01/M02의 의무 및 실제 사실 오류만 승인된 방향으로 바로잡았다.

## 읽은 근거와 한계

R1 보고서, R2 저자 보고서, 수정 전 독립 원본·편집 기록·현재 변경 단락과 앞뒤 문맥, 해당 정본 단락을 읽었다. 조달법 85-1·회사법154 및 게임약관 공식 PDF의 제4점/제18점은 공식 웹 원문으로 직접 읽었다. 920 판결은 보존된 공식 반환 원문 L32–53을 읽었으며 새 HTTP 조회나 판결 확정 확인으로 표시하지 않는다. 출처 관측은 `he-current-independent-r2-sources.json`에 남겼다.

이 결과는 AI 독립 편집·의미 감수다. 원어민·변호사 승인 또는 배포 완료를 의미하지 않는다. 원고의 기존 확인일·게시일은 바꾸지 않았다. 921의 이유 불요·무비용 문구 채택은 root의 `release-20261029/921-scope-adjudication.md`에 따른 선택 정밀화이며, 다른 언어에 새 필수 누락 판정으로 전파하지 않는다.
