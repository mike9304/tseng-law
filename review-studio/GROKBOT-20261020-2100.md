# Grok Bot 검수 21:00 KST — KO r5 READY 3편 재검토: 아직 사용자 컨펌 보류 (필수 수정 4건)

KO r5 본문·첫 댓글·첨부·카드 17장 PNG를 직접 읽고 봤다. 사실·카드 디자인·마지막 장 정보·첫 댓글 질문은 통과. 다만 사용자가 "AI 말투"로 지적해 온 유형이 아직 남아 있어 READY로 올리지 않는다. 아래만 고친 r6를 내고, 같은 변경을 JA·EN에도 전파한다(JA·EN은 각 언어 자연 표현으로).

1. 세 편 본문이 같은 뼈대다. 모두 [사건 한 줄 → "1심 법원은 ~했어요" → "~거든요/~니까요" 이유] 로 시작하고, 셋째 문단을 판결문을 읽는 메타 문장으로 연다:
   - P1 "판결문에서 눈여겨볼 건, …"
   - P2 "판결문 속 증언을 따라가면, …"
   - P3 "판결 이유를 나란히 읽어 보면 두 항목의 근거가 달라요."
   매일 한 편씩 올라가면 같은 틀이 바로 보인다. 이 메타 문장 세 개는 빼거나 사건 자체로 바로 들어가는 문장으로 바꾼다. 도입부 구조도 세 편 중 최소 두 편은 서로 다르게 한다(예: 한 편은 장면부터, 한 편은 숫자부터). 500자 한도와 사건 경위·판결 이유 분량은 유지.

2. 법률 용어·판결문 직역 남은 곳을 사람 말로:
   - P3 "버스 쪽이 다투지 않은 금액"(본문·카드5·카드6·alt) → 뜻이 같은 쉬운 말(예: "버스 쪽도 이만큼은 인정한 금액"). 정확성은 FACTS와 대조해 유지.
   - P2 "법이 정한 요건을 못 갖춰 무효로 봤어요" → 더 평이하게(예: "그래서 이혼 자체가 무효라고 했어요").
   - P1 "생활 규칙·설비 목록까지 끝난 합의" → 어색함. "다 보고 맞춘" 식으로 자연스럽게.

3. P3 "이는 씹는 것뿐 아니라…"(본문), 카드4 "이는 생김새와도 관계있다" — '이는'이 '이것은'으로 먼저 읽힌다. "앞니는/치아는"으로 바꾼다. 카드4 PNG도 다시 렌더.

4. 바뀐 부분만 교차 비평(Opus↔Grok)과 Astra 최종 검수를 거쳐 STATUS를 갱신한다. 바뀌지 않은 카드는 바이트 동일 유지.
