표준 카탈루냐어의 법률 설명으로 읽히며 스페인어나 다른 국가법으로 바뀌지 않았다. `societat matriu`, `laude`, `cessament`, `apartat/punt`, `lliurament`은 각 문맥에서 이해된다. S01·S02의 지시 대상 개선은 선택 사항이다. 언어를 국적·거주국으로 가정하거나 카탈루냐어 상담을 보장하지 않았다. 장식용 굵은 글씨·공개 사람 저자/검수자·지어낸 일인칭·명령형 체크리스트 제목은 없다.

독립 읽기 확인으로 FAQ17, 공식 URL23개(편별4/3/4/4/4/4)의 원문 보존과 말미 목록 누락0,26일 발행·수정일, `ca` audience, 내부 AI author와 `Escena fictícia`를 확인했다. 금지 방향제어문자·손상 문자·굵은 강조0이다. 내부 링크는 실제 sourceLocale을 가진 저자의 오류0 구조 기록과 같은 SHA다. `/en/contact`는 영어 링크임을 표시하고,916의 CA 회사·지점 칼럼은 존재한다.

법적 정보는 제공된 동결 공식 자료를 기준으로 검토했으며 여기서 별도 웹 전수 조회를 수행하지 않았다. 성공한25일 법원 조회와26일 현행법·정책 확인, 실패한 판결 재접근을 구별한다. 정부 판례집 전체를 새로 열어 읽었다고 주장하지 않으며, 후속 재판이나 협정 전체의 발효까지 새로 보증하지 않는다. 도구 통과와 모델 의미 검토는 사람 원어민·변호사 승인, 브라우저·피드·JSON-LD 또는 실제 배포 확인을 대체하지 않는다.

원고·저자 기록·R·공유 도구는 수정하지 않았다. 끝의 동일 SHA 확인과 이 보고서·독립 증거는 `checks/ca-independent-final-manifest.json`에 연결한다. 선택 수정을 채택할 경우 기존 R1 기록을 보존하고 영향 파일의 새 SHA와 변경분만 후속 확인하면 된다.
