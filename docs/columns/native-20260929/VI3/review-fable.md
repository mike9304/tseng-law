## 안전(DV 독자) 점검
- 110 우선 → 휴대폰 열람 대비(별도 기기·시크릿 모드·관련 페이지만 삭제) → 113(24h·통역·문자) → 1990(베트남어 평일 9–17) 순서가 맞고, 긴급보호령은 피해자가 직접 못 내니 110/113에 "긴급보호령"을 요구하라는 안내가 정확하다.
- 주소 비공개(§12), 조회 금지(§14 I(12)), 증거 사본을 신뢰인·별도 계정에 보관, CTA의 안전한 연락 수단 질문 모두 실용적이고 피해자 탓하는 문장 없음. 결과 보장·공포 조장 표현 없음.
- "ký sau cùng"(합의서는 마지막에) 조언은 §31 IV(2)가 "因遭受家庭暴力離婚"을 요구하므로 독립 증거 확보와 결합돼 있어 독자 권리를 지키는 방향이다.
