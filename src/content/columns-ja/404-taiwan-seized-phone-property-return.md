# 台湾で押収された携帯電話を、事件終結前に返してもらうには

押収された携帯電話は、事件が終わるまで戻らないのでしょうか。台湾刑事訴訟法の[第142条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0010001&flno=142)は、留置の必要がない押収物を、事件終結を待たずに裁判所の決定または検察官の命令で還付すると定めています。終結だけが基準ではありません。

## 受領書で携帯電話を特定します

[第139条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0010001&flno=139)では、押収物の名称を詳しく記載した受領書を、所有者・所持者・保管者へ渡す必要があります。機種や識別番号は合っていますか。複数の端末が押収されているなら、どれが自分の物かを示す手掛かりになります。

自分の所有物でも、直ちに戻るとは限りません。証拠となり得る物や没収の対象となる物の押収を認める[第133条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0010001&flno=133)は、追徴を保全するための財産の押収も別に定めています。仕事で使うという事情だけで、これらの目的がなくなるわけではありません。

還付の請求では、対象物と自分の立場、留置を続ける必要がないと考える理由を示します。帰国予定も伝えてください。ただし、日本行きの航空券があるというだけで還付義務が生じるものではありません。

## 保管責任を負う一時的な還付

第142条第2項は、所有者・所持者・保管者の請求により、保管責任を負わせて一時的に還付する方法を認めています。許可が必要です。返してもらえるかだけでなく、どのような状態で保管すべきかも決定の内容で確かめます。

端末そのものが必要なのか、保存されている写真や業務資料が必要なのかも分けて説明します。同条第3項の写しの交付は、正当な理由のある所有者・所持者・保管者が、公判中に費用を予納して請求する場合の規定です。捜査中にすべてのデータを自由に複製してもらえるという意味ではありません。

## 検察官の処分に対する申立て

検察官による押収や押収物の還付処分に不服がある被処分者は、[第416条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0010001&flno=416)に基づき、その検察官の所属する裁判所に取消しや変更を申し立てられます。対象は検察官の処分です。警察の措置や裁判所の決定は、発行者と文書の性質を別途確認します。

期間は10日です。処分日から起算し、送達する処分の場合は送達後から起算するという区別があります。[第417条](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=C0010001&flno=417)により、不服の理由を書いた書面を管轄裁判所へ提出します。返却の相談を繰り返している間も、この期間が止まるとは考えないでください。

還付を認めない文書が届いたら、全ページと受領日の記録を押収時の受領書と一緒に残します。誰の、どの物に関する処分かを確認してから、残る申立方法と期限を判断します。
