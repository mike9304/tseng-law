## 1. 리드 확인 필요: F-008 문장의 「應」→「得」 (한 글자)
지시문은 「…不能於六個月內完結時，應申敘理由向法院聲請展期」인데 公司法§87③ 원문(2026-10-06 law.moj.gov.tw 조회)은 「清算人應於六個月內完結清算；不能於六個月內完結清算時，清算人得申敘理由，向法院聲請展期」 — 연장 신청은 의무가 아니라 "得"이다(FINDINGS F-008도 "得申敘理由"). 의무로 쓰면 법적 강도가 올라가는 오류라 draft에는 「得」을 썼다. 지시문 그대로가 필요하면 draft 해당 문장에서 「得」→「應」 한 글자만 바꾸면 된다. 불이행 시 과태료(§87④ 1만~5만)는 문장에 없어서 넣지 않았다.

## 2. 확인한 것 (2026-10-06 원문 페이지 직접 조회)

- 公司法 §334: 「第八十三條至第八十六條、第八十七條第三項、第四項、第八十九條及第九十條之規定，於股份有限公司之清算準用之」 — 지시문 "股份有限公司依第334條" 일치.
- 公司法 §113 第2項: 「除前項規定外，公司變更章程、合併、解散及清算，準用無限公司有關之規定」 — "有限公司依第113條第2項準用" 일치. §113 第1項 3분의 2 일치.
- 公司法 §9(형량 5년 이하·50~250만), §89①, §90(1년 이하·6萬), §316(출석 3분의 2·과반수 동의, 公開發行 예외) — 본문과 일치.
- 公司登記辦法 §3 (law.moj.gov.tw J0080020): 1項 본문+但書 「停止營業前或停止營業之日起十五日內…但已依加值型及非加值型營業稅法規定申報核備者，不在此限」, 3項 「每次最長不得超過一年」 — §5 첫 문단과 일치(원문의 "第3條第1項但書" 표기도 맞음). §4 第1項 15日 일치.
