# 分居多年仍離不了婚？民法第1052條與有責配偶的離婚請求

分居多年，不會讓婚姻自動消滅；配偶不同意離婚，也不代表法院一定不能判離。在適用台灣法的案件中，法院須依[民法第1052條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=1052)，判斷有沒有法定離婚事由。若主張婚姻已經破裂，還要釐清造成破裂的原因，以及誰應對這些原因負責。

與外籍配偶離婚，適用哪一國法律，須依[涉外民事法律適用法第50條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000007&flno=50)，按協議時或起訴時的共同本國法、共同住所地法、與婚姻關係最切地的法律，依序決定。一方是台灣人，並不足以直接認定適用民法第1052條。

## 十款具體事由，和十款以外的婚姻破綻

[第1052條第1項](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=1052)列出十款情形。夫妻一方有其中情形時，他方得向法院請求離婚。各款的要件不同，起訴時要對照具體款次：

| 款次 | 法條所定情形 |
| --- | --- |
| 第1款 | 重婚。 |
| 第2款 | 與配偶以外之人合意性交。 |
| 第3款 | 夫妻一方對他方為不堪同居之虐待。 |
| 第4款 | 夫妻一方虐待他方的直系親屬，或夫妻一方的直系親屬虐待他方，致不堪為共同生活。 |
| 第5款 | 夫妻一方惡意遺棄他方，且仍在繼續狀態中。 |
| 第6款 | 夫妻一方意圖殺害他方。 |
| 第7款 | 有不治之惡疾。 |
| 第8款 | 有重大不治之精神病。 |
| 第9款 | 生死不明已逾三年。 |
| 第10款 | 因故意犯罪，經判處有期徒刑逾六個月確定。 |

第7、8款在此沿用法條用語，不表示任何疾病或精神科診斷都足以構成離婚原因。第9款的「生死不明」也不同於知道對方人在國外，只是對方不回訊息。第10款要三個條件都具備：故意犯罪、判處有期徒刑超過六個月、判決確定。

第2項的「難以維持婚姻之重大事由」讓法院得以處理十款以外的婚姻破綻。例如，長期失去互信、共同生活與相互扶持，可能需要從整段婚姻的經過判斷。法院審查的是婚姻是否客觀上已經破裂、無法回復，不只是起訴的一方現在想不想離婚。最高法院在[112年度台上字第1612號判決，理由四㈡](https://judgment.judicial.gov.tw/FJUD/printData.aspx?id=TPSV,112,%E5%8F%B0%E4%B8%8A,1612,20231222,1)即以此為判斷基礎。

兩項也不必然只能擇一。最高法院[112年度台上字第930號判決，理由四㈠](https://judgment.judicial.gov.tw/FJUD/printData.aspx?id=TPSV,112,%E5%8F%B0%E4%B8%8A,930,20240103,1)說明，同一事實若同時涉及不同法定離婚事由，可以請求法院分別審查。起訴時仍須說清楚：哪些行為符合具體款次，哪些事實顯示婚姻已難以維持。

## 分居的原因，可能比搬出去的日期更有爭議

跨國夫妻分開居住，可能出於工作、照顧家人或雙方同意的生活安排。以下是說明用的假設：一方在海外工作，仍固定與配偶聯繫、分擔家用，並共同安排團聚；另一對夫妻則在衝突後斷絕聯繫，對回復共同生活也沒有共識。即使兩對夫妻分居的時間相同，法院仍須連同分居原因、聯繫及共同生活的安排一起判斷。

[最高法院112年度台上字第930號民事判決（2024年1月3日）](https://judgment.judicial.gov.tw/FJUD/printData.aspx?id=TPSV,112,%E5%8F%B0%E4%B8%8A,930,20240103,1)就呈現了「誰不願同住」的爭議。一方以配偶搬離住處為由，主張遭惡意遺棄；判決記載的原審認定卻是，請求離婚的一方更換門鎖、不提供鑰匙，後來又不提供新設的門鎖密碼，使配偶無法返家。依原審的認定，拒絕同居的反而是請求離婚的一方。

本案原審另認定婚姻已有重大破綻、雙方均有責，卻以請求離婚者責任較重而駁回。最高法院指出，雙方有責的情況不應再用責任輕重比較排除請求，並要求進一步調查個案衡平事項，將案件廢棄發回。這份判決本身沒有直接准予離婚。

整理分居資料時，可以把搬離前的衝突、雙方是否同意分居、是否提出返家或另覓住所的安排，以及對方如何回應，整理成同一份時間表。住址、往來訊息與生活費紀錄各自只能說明一部分；租約證明住在哪裡，未必證明為什麼離家。

## 「冷暴力」需要還原成具體行為

「對方一直冷暴力」可以表達當事人的感受，但不是第1052條中獨立的一款離婚事由。若要依[民法第1052條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=1052)第1項第3款主張虐待，須說明哪些行為達到不堪同居的程度；依第2項主張婚姻破綻，則須說明這些行為如何使婚姻難以維持。

譬如，所謂不理人，是爭執後暫停交談，還是長期拒絕處理共同生活中的事情？對方有沒有說明原因？要求討論時如何回應？是否伴隨貶抑、威嚇或其他行為？這些是整理事實的方向，不是法院規定的一張固定清單。若保留訊息，完整對話通常比單張截圖更能呈現前後關係；自己的紀錄也最好分清楚哪些是親身經歷、哪些是推測。

在前述[最高法院112年度台上字第1612號判決（2023年12月22日），理由一至三](https://judgment.judicial.gov.tw/FJUD/printData.aspx?id=TPSV,112,%E5%8F%B0%E4%B8%8A,1612,20231222,1)中，請求離婚的一方主張配偶長期鮮少關心，另一方則否認精神虐待，並指出對方外遇。法院並非接受「冷淡」這個形容詞就判離；判決記載的原審認定包括外遇、分居後雙方消極放任關係惡化，以及另一方不當跟蹤、查閱私人資料等具體情事。

這個案件也提醒蒐證的界線：查出對方的行為，並不使自己的跟蹤或擅自查閱資料當然正當。可以先保存自己合法持有的往來資料；若需要取得不在自己手上的資料，最好先弄清楚合法的取得方式。

## 雙方有責，已不再以誰錯得比較多決定能否請求

民法第1052條第2項但書，限制的是重大事由應由夫妻一方負責的情形。至於雙方都應負責，最高法院在[112年度台上字第1612號判決，理由四㈠、㈡](https://judgment.judicial.gov.tw/FJUD/printData.aspx?id=TPSV,112,%E5%8F%B0%E4%B8%8A,1612,20231222,1)經徵詢程序統一見解：夫妻均得依第2項本文請求離婚，毋須再比較雙方責任的輕重。

該案原審已認定婚姻有重大破綻、沒有回復希望，且雙方均應負責，卻因請求人有外遇、責任較重而不准離婚。最高法院依原審認定的事實，直接改判准予離婚；子女權利義務與扶養費部分則發回另行審理。

因此，面對有責配偶的離婚請求，不能只沿用「你比較有錯，所以不能告離婚」的說法。但「雙方有責」也須有事實根據，不是把兩人都曾發脾氣、都不願退讓列出來，就必然成立。責任必須與造成婚姻難以維持的重大事由相連。

## 唯一有責的一方，112年憲判字第4號留下什麼空間？

[憲法法庭112年憲判字第4號判決（2023年3月24日）](https://cons.judicial.gov.tw/docdata.aspx?fid=38&id=310013)處理的是另一層問題：如果婚姻難以維持的重大事由，只應由請求離婚的一方負責，法律能否一直不讓這個人請求離婚？

憲法法庭並未將第1052條第2項但書全部宣告違憲。判決認為，優先保障無責配偶維持婚姻的權利、限制唯一有責配偶請求離婚，原則上並未違憲。問題在於，若完全不考慮重大事由發生後是否已過相當期間，或已持續相當期間，一律剝奪唯一有責配偶的離婚機會，可能使個案顯然過苛；在這個範圍內，限制不符合憲法保障婚姻自由的意旨。見判決主文及理由第34至39段。

判決要求相關機關在宣示後兩年內修法，並明定逾期未完成修法，法院應依判決意旨處理這類個案。這個期限已在2025年3月24日到期；截至2026年10月3日，[第1052條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=1052)的但書仍未修改。法院仍須依憲法判決的要求，審查個案是否顯然過苛。

這裡的「兩年」是修法期限，不是夫妻只要分居兩年就能離婚。憲法法庭也沒有替所有案件訂出統一的分居年數。唯一有責的請求人，仍須提出婚姻破綻如何發生、持續多久、是否已無回復可能，以及繼續限制離婚為何在本案顯然過苛的具體事實；不是只附上憲法判決，就能省略這些說明。

法務部曾於[2025年2月20日公布行政院通過的修正草案說明](https://www.moj.gov.tw/2204/2795/2796/233937/)，其中包含以分居一定期間作為離婚事由的設計。截至查核日，第1052條還沒有依這份草案修正，法院仍須依現行條文及上述憲法判決處理。

## 具體離婚事由，還有各自的時間限制

若主張第1項的特定事由，除了證明發生什麼事，也要核對何時發生、何時知悉。依[民法第1053條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=1053)，對重婚或與配偶以外之人合意性交的情事，有請求權的一方若事前同意、事後宥恕，或知悉後已逾六個月，或自情事發生後已逾兩年，就不得依該情事請求離婚。「宥恕」指原諒該情事，是否確有原諒，仍須依實際經過判斷。

對第6款意圖殺害配偶及第10款故意犯罪受刑確定的情事，[第1054條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=1054)另定：知悉後已逾一年，或自情事發生後已逾五年者，不得依該情事請求離婚。也就是說，六個月、兩年只適用於第1、2款；一年、五年只適用於第6、10款。

至於具體事由受到期間限制後，相關事實能否另支持第2項的婚姻破綻，仍要審查第2項自己的要件，不能只換一個法條名稱就認為一定成立。就個案提出請求前，可把事件日期、發現日期、之後的互動及現有證據一併整理，判斷是否符合要件。

## 配偶在海外，準據法與送達仍須另外處理

離婚事由回答的是能否請法院結束婚姻。法院有無管轄權、適用哪一國法律、如何將文件送達海外配偶，是另外要確認的問題。一般離婚事件原則上須先經法院調解；[家事事件法第23條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0010048&flno=23)對直接請求裁判視為調解聲請的規則，也明列應為公示送達或於外國送達的例外。配偶人在國外時，台灣法院能否受理、文件如何送達，要依個案情形另行確認。

人在海外的聯繫與文件準備，可參考[從海外處理台灣離婚案件](/zh-hant/columns/taiwanese-spouse-divorce-from-abroad)。婚後財產怎麼分，要另外依[夫妻財產制與剩餘財產分配](/zh-hant/columns/taiwan-marital-property-regime-international-couples)的規則判斷，和誰對婚姻破裂有責是分開的問題。
