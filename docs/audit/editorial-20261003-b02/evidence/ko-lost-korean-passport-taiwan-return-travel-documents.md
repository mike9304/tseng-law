## 문체 자체 검수와 수정 기록

제목·요약·소제목·첫 두 문단·마지막 문단을 별도로 읽었다. 장식용 굵은 강조, 글의 전개 예고, 상담 경험, 가상 변호사 경력, 통계·유행 주장, 결과 보장 문구를 넣지 않았다. 준비물 목록 외에 기계적 3단계 목록을 만들지 않았다. 여권 업무에 별도 법률상담을 권할 이유가 부족해 영업 CTA를 넣지 않았다.

수정 전 → 문제와 이유 → 수정 후·보존한 사실:

1. 도입의 ‘경찰에 분실 사실을 알리는 일과 새 여권을 신청하는 일은 담당 기관과 서류가 다릅니다.’ → 기관·서류의 구별을 예고하고 바로 다음 소제목에서 다시 설명해 정보가 늘지 않음 → 삭제. 실제 경찰·이민서·대표부 구별과 출처는 관련 본문에 보존.
2. 둘째 문단의 ‘새 여권을 받았다고 대만의 출국 절차까지 끝나는 것은 아닙니다.’ → 다음 제11조 설명과 같은 결론을 반복 → 삭제하고 조문상 조건부터 시작. 새 유효 서류와 출국 절차의 AND 조건 보존.
3. ‘함께 고려해야 합니다.’ → 무엇을 누구에게 확인할지 흐림 → 대표부 발급 일정·이민서 출국 절차·운항 항공사 수속으로 행동과 주체를 구체화. 개별 시한은 만들지 않음.
4. ‘한 곳에 제출한 사진이 다른 기관으로 자동 전달된다고 생각하지 말고’ → 독자에게 근거 없는 오해를 가정하고 훈계하는 어감. 부모 에이전트가 독립 문체검수 MUST로 전달 → ‘이민서에 제출할 사진과 대표부의 여권용 사진은 각 기관의 규격과 수량에 맞춰 따로 준비합니다.’로 수정. NIA 2인치 2장과 대표부 여권용 1장 규격은 앞 본문에 보존.
5. ‘긴급여권과 여행증명서는 이름만 다른 서류가 아닙니다’ → 불필요한 대비형 소제목 → ‘긴급여권과 여행증명서의 발급 대상’. 두 제도의 실질 차이·기간·조건 보존.
6. ‘확인한 조문과 이민서의 분실 안내만으로는 … 단정할 수 없습니다.’ 및 ‘다른 항공사의 절차까지 같다고 일반화하지 않습니다.’ → 작성자 검수 과정을 독자용 문장에 노출 → 해당 여행자의 출국 서류·처리 시간 문의와 이용 항공사의 기준 확인으로 수정. 일률적 출국허가증·항공사 공통 기준을 약속하지 않는 범위는 유지.
7. ‘분실 신고 후 원래 여권을 찾더라도 … 사용할 수 없다’ → 대만 경찰·이민서 신고에도 한국 여권의 즉시 무효가 자동 적용된다는 오독 가능 → 한국 여권기관 분실 신고의 무효화와 현지 경찰 신고 후 출입국 불이익 가능성을 따로 서술. S8 직접 본문 재확인.
