## A. 규칙 B 치환 — 링크 없는 짧은 귀속 (건수 11)
괄호의 판결 링크가 그 문단의 유일한 귀속이라 링크 없는 짧은 괄호로 바꿨다.
- `（一審判決）` 8곳: 원문 L50, L52, L72, L76, L84, L88, L109, L119 (draft L68, L70, L90, L94, L102, L106, L127, L133)
- `（高院判決）` 2곳: 원문 L54 s1, L121 s2 (draft L72, L135)
- `（112年度調院偵字第1177號；一審判決）` 1곳: 원문 L38. 원문 「（112年度調院偵字第1177號）（J2）」의 두 괄호를 하나로 합침(괄호 연속을 피함, 案號 문구 그대로)
- 그 밖의 괄호 링크 28곳(원문 L24·L28·L30·L32·L34·L36×2·L42·L48·L58·L60·L68·L74·L78·L86·L92·L94·L96·L103·L107·L111·L113·L117×2 등)은 문단 안에 「一審/高院/兩份判決」가 이미 귀속을 말해 링크만 지웠다
- 판결 링크 개수: 원문 47 = 본문 43 + 審級 표 2 + 출처 2 → draft 8 = 본문 4(L20 高院 첫 인용, L22 一審 첫 인용, L44 블록 인용 도입, L66 블록 인용 직후) + 審級 표 2 + 출처 2. 본문 링크 39개 제거 = 짧은 귀속으로 치환 11 + 링크만 삭제 28(삭제한 문장·문단 안의 링크 포함). 판결 링크 라벨 글자 1,595(45개, 출처 제외) → 214(6개)

## B. 표 (새로 쓴 표시)
- 표 머리글 `畫面時間｜A車｜B車`(3칸). 모든 행의 시각·동작 문구는 원문 L30·L32·L34의 어구다. 바뀐 것은 아래뿐:
  - 「22時15分8秒…又向右變換車道，換到B車前方的車道，7秒後第二次驟然減速」은 원문 문장 그대로 한 칸(22時15分15秒라는 값을 새로 계산해 넣지 않음)
  - 「6秒時還在倒車推擠B車」 → 칸 「還在倒車推擠B車」, 「8秒才停止倒車」 → 「停止倒車」(시각은 시각 칸으로 이동, 「才」 생략)
  - 마지막 행: A車 「向右轉彎，沒有再出現在畫面中」(원문 「A車向右轉彎，B車直走，A車沒有再出現在畫面中」에서 주어별로 나눔), B車 「直走」
  - 「第一次倒車撞擊」 같은 순번은 원문에 없는 곳에 붙이지 않았다(15:44–45는 「往後倒車，撞上B車」, 15:52는 「又驟然停車」)
- 이동한 문장(글자 변경 없음): 「合計驟然減速2次、驟然停車5次、倒車撞擊3次。」(원문 L36 s1), 「高院的歸納是，…」(L36 s2, 끝 링크만 삭제) → draft L28 문단 끝
