## 2. zh-hans 특별 규칙
- 코드 `zh-hans`. autonym '简体中文', englishName 'Simplified Chinese', region asia-pacific. hreflang **'zh-Hans'**(`hreflangTagForPublicLocale`·`publicDocumentLanguage`·`PublicDocumentLanguage` 타입에 'zh-Hans' 추가), og:locale **zh_SG**(간체 독자 1차 시장이 싱가포르·말레이시아 화인 — 자사 GSC 실측), `<html lang="zh-Hans">`.
- **중국어 상담은 실제로 가능**(사이트 상담 언어 4개에 中文 포함). 따라서 zh-hans 언어 FAQ는 **긍정**: 질문 '可以用中文咨询吗？' 답 '可以。律师咨询以英语、中文、日语和韩语进行。本页面以简体中文撰写，咨询时使用的中文包括普通话与书面中文。' 수준으로 — 통역·응답시간·예약 약속은 여전히 금지. **다른 로케일용 "부정 답" 테스트가 zh-hans에 적용되지 않도록** 테스트에 예외 명시(`GUIDANCE_CONSULTATION_LANGUAGE_LOCALES` 같은 상수로 zh-hans만 예외 처리; 하드코딩 if 금지).
- 번역 원본: **zh-hant 사이트가 아니라 de 팩 구조**를 따르되, 용어는 대만 법률 용어의 간체 표기(公司登記→公司登记, 投資審議→投资审议, 居留證→居留证 등). 대륙식 법률 용어(营业执照·工商局 등)로 바꾸지 말 것 — 대만 절차이므로 대만 용어 간체화. 표점은 간체 관례(“” 대신 “”/‘’ 그대로, 句号 。).
- 폰트: `Noto_Sans_SC`·`Noto_Serif_SC` 로더 추가(TC 로더와 동일 패턴), CSS 변수 `--font-noto-sans-sc-loaded` 등, `fonts.test.ts` 갱신.
- 정치적 표기 금지: '中国台湾'·'台湾省'·'大陆' 류 사용 금지. '台湾'만. 국가 열거 시 ISO 명칭 사용.
- 언어 전환기·hreflang에서 zh-hant↔zh-hans는 서로 alternate(둘 다 같은 클러스터, 기존 로직으로 자동).
