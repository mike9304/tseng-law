## FAQ·표제·출처·공개 문구

FAQ 9개는 첫 신청의 기산·비용·근로, 적격 입국 전환·어학 요건·가족 후원, 연장창·변경등록·재입국 문서에 각각 답한다. 질문보다 답의 적용 범위가 무제한으로 확대되는 사례는 발견하지 못했다. 706 FAQ의 신청기한은 처리 완료기한이 아니며 APRC 예외도 포함한다. 제목과 요약은 대만의 신청·변경 문제를 설명하고 결과 보장이나 모든 에스토니아 국민의 권리를 약속하지 않는다.

발행일과 lastmod는 2026-10-26, 표시일은 `26. oktoober 2026`, audience는 et다. 캡션은 정확히 `Väljamõeldud stseen`이며 이미지 v2 경로·내부 `legal-ai-assistant`를 유지했다. 본문에 공개 저자/AI/변호사 승인 표기, 굵은 강조 우회, 허구의 의뢰인 경험, 전화번호, 에스토니아어 상담 약속은 없다. 연락처는 706 중간에 있고 상담 언어는 EN/ZH/JA/KO로 한정된다.

[독립 URL 검사](../checks/et-independent-url-audit.json)의 고유 외부 URL은 704 12개, 705 15개, 706 14개다. EN 정본 URL 누락 0, 본문의 공식 URL이 말미 출처에서 빠진 경우 0이다. 추가 링크는 F02/F08/F24와 F23의 지정 보강 근거이며 다른 이름의 비슷한 기관 자료로 바꾸지 않았다. 영어 spouse/Gold Card/APRC 링크 네 곳에는 `ingliskeelne/ingliskeelses` 표시가 있고 현재 ET에 같은 슬러그가 없는 점을 확인했다. 독립 구조검사는 [현재 SHA의 별도 결과](../checks/et-independent-content-audit.json)에서 errors 0 / automated PASS였다. `semanticStatus: REVIEW_REQUIRED`, `publicationReady: false`, 수동 항목 23개는 도구 원형대로 유지했다. 이 보고서에서 원고의 의미·문체·출처 연결을 검토했지만 실제 페이지·카드·JSON-LD·피드 렌더 및 저자 노출 여부는 root의 통합 검사로 남는다.

## §5 재확인

1. 실제 공유 ET 검사 FAIL 0. 저자 결과를 복사하지 않고 직접 실행했다.
2. 704 공식 기산 규칙, 705 학생 질문, 706 이사 결과로 시작하며 정형 가상 장면은 없다. 최근 ET3편의 오프닝을 국적명만 바꿔 재사용하지 않았다.
3. 아주 짧은 문장이 각각 충분히 있고 법정 AND/OR를 숫자만 나눠 단문으로 만들지 않았다. 705의 34단어·32단어 조건 문장은 서로 다른 문단에 있으며 뒤에 짧은 설명이 있다.
4. 문단 시작 단어를 전부 세로로 읽었다. 최다 `nia`/`kas`/`elamise`는 각각 2회, 동일 문장 시작 연속은 0/0/0이다. 706의 연접 `Elamise` 두 문단은 같은 단어 3회 반복에 해당하지 않는다.
5. 주장–조문–단서 틀을 세 문단 연속 사용하지 않는다. 조문 주어·중간 링크·절차 문장과 증빙 설명 문단이 섞여 있다. 가족의 두 항목은 실제 법정 OR를 드러내는 목록이다.
6. 자동 대비 0/0/0만으로 반박형 문장이 없다고 단정하지 않았다. `mitte`, `ei asenda`, `ei anna`가 쓰인 문장을 직접 읽었고 근로허가, 적용 대상, 영수증 효력의 법적 한정을 불필요한 점수 조정 대상으로 삼지 않았다. 필수 반려 수준의 반복은 발견하지 못했다.
7. 구조적 적용 범위 고지 직전 실제 결말을 따로 평가했다. 704는 새 주소·직장·여행의 다음 서류와 기한, 705는 실제 활동 시작과 허가 유효기간, 706은 귀국 당일 사용할 수 있는 문서로 끝난다. 문의나 추상적인 주의 촉구를 세 편 동일하게 붙이지 않았다.
8. 표준 에스토니아어 설명체가 유지된다. 한국어/일본어 존대 규칙을 억지로 적용하지 않았다. 704 본문 질문 0은 날짜·신청 설명 중심이라는 저자 사유를 수용하며 FAQ를 본문 질문 수에 포함하지 않았다. 705/706에는 질문 2개씩 있다.
