# TERMS — MULTILINGUAL-INTERNATIONAL-v2

| term | note |
|---|---|
| 会社設立 / 公司設立 / 회사설립 | Taiwan company formation, not a Japan or Korea Companies Act procedure |
| 売掛金回収 / 應收帳款 / 미수금 | commercial payment dispute intake, not a promised recovery |
| 就業許可 / 工作許可 / 취업허가 | separate from company registration |
| 台湾・韓国所得税協定 | Korea–Taiwan DTA only (in force 2023-12-27, applies 2024-01-01) |
| guidance vs consultation | page language vs the four office consultation languages |
| 相談案内 / 상담 안내 / 諮詢說明 | engagement/intake label, not a search-engine “guide” |
